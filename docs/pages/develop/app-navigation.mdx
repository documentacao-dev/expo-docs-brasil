A biblioteca principal do React Native não inclui uma solução de navegação embutida, então você pode escolher a biblioteca que melhor atende às suas necessidades. Em apps Expo e React Native, normalmente a escolha é entre o [React Navigation](https://reactnavigation.org/) ou o [Expo Router](/router/introduction/).

## Por que apps React Native precisam de uma biblioteca de navegação \{#why-react-native-apps-need-a-navigation-library}

O núcleo do React Native inclui componentes de UI básicos, tratamento de toque, APIs do dispositivo e rede, mas deixa de fora, entre outras coisas, armazenamento, câmera, mapas, a maioria dos sensores do aparelho e a **navegação**! A ideia é que esses itens fiquem a cargo de bibliotecas da comunidade.

## React Navigation \{#react-navigation}

O React Navigation é uma biblioteca de navegação baseada em componentes, muito usada no ecossistema React Native. Ela permite montar navegadores de pilha, de abas e de gaveta inteiramente em código, para implementar fluxos complexos, transições personalizadas e padrões de UX específicos do app.

A biblioteca oferece aparência específica de cada plataforma, com animações e gestos suaves, roteamento unificado para mobile e web, deep links automáticos, rotas tipadas com configuração estática e é altamente personalizável.

## Expo Router (recomendado para projetos Expo) \{#expo-router-recommended-for-expo-projects}

O Expo Router é uma biblioteca de roteamento baseado em arquivos para projetos Expo e React Native. Seguindo a convenção do diretório **app**, ele transforma arquivos em rotas e se integra ao [Expo CLI](/more/expo-cli/) e ao bundling sem configuração adicional. A biblioteca também traz recursos como rotas tipadas, rotas dinâmicas, bundling sob demanda em desenvolvimento, renderização estática para a web e deep linking automático.

Projetos Expo novos criados com `npx create-expo-app@latest` já incluem o Expo Router por padrão.
