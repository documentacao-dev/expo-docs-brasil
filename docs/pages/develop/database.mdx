A maioria dos apps precisa guardar dados além de uma única sessão. Você pode usar um banco de dados hospedado na nuvem para armazenar os dados do app e sincronizá-los entre aparelhos e usuários.

## Convex

O [Convex](https://www.convex.dev/) é um banco de dados baseado em TypeScript que não exige gerenciamento de cluster, SQL ou ORMs. Ele oferece atualizações em tempo real por WebSocket, o que o torna ideal para apps reativos.

## Supabase

O [Supabase](https://supabase.com/) é uma plataforma de desenvolvimento de apps que oferece serviços de backend hospedados, como banco de dados Postgres, autenticação de usuários, armazenamento de arquivos, edge functions, sincronização em tempo real e um kit de vetores e IA.

## Firebase

O [Firebase](https://firebase.google.com/) é uma plataforma de desenvolvimento de apps que oferece serviços de backend hospedados, como banco de dados em tempo real, armazenamento na nuvem, autenticação, relatórios de falhas, analytics e muito mais. Ele roda na infraestrutura do Google e escala automaticamente.
