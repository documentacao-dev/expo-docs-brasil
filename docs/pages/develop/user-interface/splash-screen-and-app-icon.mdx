A splash screen e o ícone do app são elementos fundamentais de um app mobile. Eles têm um papel importante na experiência do usuário e na identidade visual do app. Este guia mostra o passo a passo para criá-los e adicioná-los ao seu app.

---

## Splash screen \{#splash-screen}

A splash screen, também conhecida como launch screen, é a primeira tela que o usuário vê ao abrir o app. Ela continua visível enquanto o app carrega. Você também pode controlar quando a splash screen desaparece usando a [API SplashScreen](/versions/latest/sdk/splash-screen) nativa.

O [`expo-splash-screen`](/versions/latest/sdk/splash-screen) tem um [config plugin](/config-plugins/introduction) integrado que permite configurar propriedades como o ícone e a cor de fundo da splash screen.

> **warning** **Não use o Expo Go nem um development build para testar sua splash screen**. O Expo Go mostra o ícone do app enquanto a splash screen está visível, o que pode atrapalhar o teste. Development builds incluem o `expo-dev-client`, que tem a própria splash screen e pode causar conflitos. **Use um [preview build](/build/eas-json/#preview-builds) ou um [production build](/build/eas-json/#production-builds)**.

<Step label="1">

### Crie o ícone da splash screen \{#create-a-splash-screen-icon}

Para criar o ícone da splash screen, você pode usar este [template do Figma](https://www.figma.com/community/file/1637141012732584189). Ele traz um design mínimo para o ícone e imagens de splash para Android e iOS.

**Recomendado:**

- Use uma imagem de 1024x1024.
- Use um arquivo **.png**.
- Use um fundo transparente.

</Step>

<Step label="2">

### Exporte o ícone da splash como .png \{#export-the-splash-icon-as-a-png}

Depois de criar o ícone da splash screen, exporte-o como **.png** e salve-o no diretório **assets/images**. Por padrão, o Expo usa **splash-icon.png** como nome do arquivo. Se você decidir mudar o nome do arquivo da splash screen, use esse nome no próximo passo.

> **Note:** **Por enquanto, só imagens .png são aceitas** como ícone da splash screen em um projeto Expo. Se você usar outro formato de imagem, o production build do seu app vai falhar.

</Step>

<Step label="3">

### Configure o ícone da splash screen \{#configure-the-splash-screen-icon}

Abra o arquivo de app config e, em plugins, defina as seguintes propriedades:

```json app.json
{
  "expo": {
    "plugins": [
      [
        "expo-splash-screen",
        {
          /* @info The background color of the splash screen. */
          "backgroundColor": "#232323",
          /* @end */
          /* @info The path to the splash screen icon. */
          "image": "./assets/images/splash-icon.png",
          /* @end */
          /* @info The path to the splash screen icon for dark mode (optional). */
          "dark": {
            "image": "./assets/images/splash-icon-dark.png",
            /* @end */
            /* @info The background color of the splash screen for dark mode. */
            "backgroundColor": "#000000"
            /* @end */
          },
          /* @info The width of the splash screen icon. */
          "imageWidth": 200
          /* @end */
        }
      ]
    ]
  }
}
```

Para testar a nova splash screen, faça o build do seu app para [distribuição interna](/tutorial/eas/internal-distribution-builds) ou para produção. Veja os guias para [Android](/tutorial/eas/android-production-build/) e [iOS](/tutorial/eas/ios-production-build/).

<Collapsible summary={<>Configurando as propriedades do <CODE>expo-splash-screen</CODE> separadamente para Android e iOS</>}>

O [`expo-splash-screen`](/versions/latest/sdk/splash-screen) também aceita as propriedades `android` e `ios` para configurar a splash screen de uma plataforma específica. Veja o exemplo a seguir:

```json app.json
{
  "expo": {
    "plugins": [
      [
        "expo-splash-screen",
        {
          "ios": {
            "backgroundColor": "#ffffff",
            "image": "./assets/images/splash-icon.png",
            "resizeMode": "cover"
          },
          "android": {
            "backgroundColor": "#0c7cff",
            "image": "./assets/images/splash-android-icon.png",
            "imageWidth": 150
          }
        }
      ]
    ]
  }
}
```

</Collapsible>

<Collapsible summary="Não está usando prebuild?">

Se o app não usa o [Expo Prebuild](/more/glossary-of-terms/#prebuild) para gerar as pastas nativas **android** e **ios**, as mudanças no app config não terão efeito. Para mais informações, veja [como personalizar a configuração manualmente](https://github.com/expo/expo/tree/main/packages/expo-splash-screen#-installation-in-bare-react-native-projects).

</Collapsible>

<Collapsible summary="Solução de problemas: nova splash screen não aparece no iOS">

Nas versões do SDK 52 e anteriores, em development builds para iOS, as launch screens às vezes ficam em cache entre os builds, o que dificulta testar novas imagens. A Apple recomenda limpar o diretório _derived data_ antes de recompilar. Isso pode ser feito com o Expo CLI executando:

<Terminal
  cmd={{
    npm: ['$ npx expo run:ios --no-build-cache'],
    yarn: ['$ yarn expo run:ios --no-build-cache'],
    pnpm: ['$ pnpm expo run:ios --no-build-cache'],
    bun: ['$ bun expo run:ios --no-build-cache'],
  }}
/>

Veja o [guia da Apple sobre como testar launch screens](https://developer.apple.com/documentation/technotes/tn3118-debugging-your-apps-launch-screen) para mais informações.

</Collapsible>

## Ícone do app \{#app-icon}

O ícone do app é o que os usuários veem na tela inicial do dispositivo e nas lojas de apps. Android e iOS têm requisitos diferentes e rigorosos.

<Step label="1">

### Crie o ícone do app \{#create-an-app-icon}

Para criar o ícone do app, você pode usar este [template do Figma](https://www.figma.com/community/file/1637141012732584189). Ele traz um design mínimo para o ícone e imagens de splash para Android e iOS.

</Step>

<Step label="2">

### Exporte a imagem do ícone como .png \{#export-the-icon-image-as-a-png}

Depois de criar o ícone do app, exporte-o como **.png** e salve-o no diretório **assets/images**. Por padrão, o Expo usa **icon.png** como nome do arquivo. Se você decidir usar outro nome, use esse nome no próximo passo.

</Step>

<Step label="3">

### Adicione o ícone no app config \{#add-the-icon-in-app-config}

Abra o app config e adicione o caminho local como valor da propriedade [`icon`](/versions/latest/config/app/#icon) para apontar para o novo ícone do app:

```json app.json
{
  "icon": "./assets/images/icon.png"
}
```

<Collapsible summary="Dicas de configuração personalizada para Android e iOS">

#### Android \{#android}

É possível personalizar ainda mais o ícone do Android usando a propriedade [`android.adaptiveIcon`](/versions/latest/config/app/#adaptiveicon), que sobrescreve as duas configurações mencionadas anteriormente.

O Adaptive Icon do Android é formado por duas camadas separadas: uma imagem de foreground e uma cor ou imagem de background. Isso permite que o sistema aplique máscaras para deixar o ícone com formatos diferentes e também oferece suporte a efeitos visuais. A partir do Android 13, o sistema também aceita um ícone temático, que usa o papel de parede e o tema para definir as cores de acordo com o tema do dispositivo.

O design que você fornecer deve seguir as [diretrizes de Adaptive Icon do Android](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive) para ícones de launcher. Siga também estas orientações:

- Use arquivos **.png**.
- Use a propriedade `android.adaptiveIcon.foregroundImage` para indicar o caminho da imagem de foreground.
- Use a propriedade `android.adaptiveIcon.monochromeImage` para indicar o caminho da imagem monocromática.
- A cor de fundo padrão é branca. Para usar outra cor, use a propriedade `android.adaptiveIcon.backgroundColor`. Você também pode usar uma imagem de fundo com a propriedade `android.adaptiveIcon.backgroundImage`. Garanta que ela tenha as mesmas dimensões da imagem de foreground.

Também é possível fornecer um ícone separado para dispositivos Android mais antigos que não aceitam Adaptive Icons. Para isso, use a propriedade `android.icon`. Esse ícone único deve combinar as camadas de foreground e background.

> Veja as [boas práticas da Apple](https://developer.apple.com/design/human-interface-guidelines/app-icons/#Best-practices) para garantir que seu ícone tenha uma aparência profissional, como testar o ícone em diferentes papéis de parede e evitar texto ao lado do logotipo do produto. Forneça um ícone de pelo menos 512x512 pixels.

#### iOS \{#ios}

No iOS, o ícone do app deve seguir as [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/app-icons/). Você pode usar o app [Icon Composer](https://developer.apple.com/icon-composer/) para criar o ícone. Ele gera um diretório **.icon** que pode ser adicionado à pasta **assets** do projeto. Depois, informe o caminho desse diretório no app config. O suporte ao modo escuro é feito no Icon Composer, então você não precisa fornecer variantes ao usar essa abordagem.

> **info** **Nota:** fornecer um diretório **.icon** do Icon Composer por meio de `ios.icon` é compatível **a partir do SDK 54**.

```json app.json
{
  "expo": {
    "ios": {
      "icon": "./assets/app.icon"
    }
  }
}
```

Como alternativa, a abordagem anterior, de fornecer uma imagem, ainda é compatível. Siga estas orientações:

- Use um arquivo **.png**.
- 1024x1024 é um bom tamanho. Se você tem um projeto Expo criado com `npx create-expo-app`, o [Expo Build](/build/setup/) gera os outros tamanhos para você. No caso de um [projeto React Native existente](/bare/overview/), gere os ícones por conta própria. O maior tamanho que o Expo Build gera é 1024x1024.
- O ícone precisa ser exatamente quadrado. Por exemplo, um ícone de 1023x1024 não é válido.
- Garanta que o ícone preencha o quadrado inteiro, sem cantos arredondados nem outros pixels transparentes. O sistema operacional aplicará a máscara no ícone quando for o caso.
- Use `ios.icon` para fornecer ícones diferentes para as variações de aparência do sistema (por exemplo, escuro e tonalizado). Quando definido, ele substitui a chave `icon` do nível superior no app config. Veja o exemplo abaixo:

```json app.json
{
  "expo": {
    "ios": {
      "icon": {
        "dark": "./assets/images/ios-dark.png",
        "light": "./assets/images/ios-light.png",
        "tinted": "./assets/images/ios-tinted.png"
      }
    }
  }
}
```
