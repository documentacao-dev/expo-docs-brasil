As barras do sistema são os elementos da UI nas bordas da tela que exibem informações essenciais do dispositivo e controles de navegação. Dependendo do sistema operacional móvel, elas incluem a barra de status ([Android](https://developer.android.com/design/ui/mobile/guides/foundations/system-bars) e [iOS](https://developer.apple.com/design/human-interface-guidelines/status-bars)), a barra de legendas ([somente Android](https://medium.com/androiddevelopers/insets-handling-tips-for-android-15s-edge-to-edge-enforcement-872774e8839b#:~:text=or%20SHORT_EDGES.-,Caption%20bars,-When%20your%20app)), a barra de navegação ([Android](https://developer.android.com/design/ui/mobile/guides/foundations/system-bars#navigation-bar) e [iOS](https://developer.apple.com/design/human-interface-guidelines/navigation-bars)) e o indicador de página inicial (somente iOS).

Esses componentes exibem informações do dispositivo, como nível da bateria, horário e alertas de notificação, e permitem interação direta com o dispositivo a partir de qualquer ponto da interface. Por exemplo, o usuário pode puxar a barra de status para acessar as configurações rápidas e as notificações, independentemente do app que estiver usando.

As barras do sistema são fundamentais para a experiência mobile, e entender como trabalhar bem com elas é importante na hora de criar o seu app.

## Lidando com sobreposições usando áreas seguras

Parte do conteúdo do seu app pode ser desenhado por trás das barras do sistema. Para lidar com isso, você precisa posicionar o conteúdo corretamente, evitando a sobreposição e garantindo que os controles das barras do sistema continuem visíveis.

O guia a seguir mostra como usar o `SafeAreaView` ou um hook para aplicar os insets diretamente em cada borda da tela.

### Áreas seguras e layout edge-to-edge no Android

Antes do [edge-to-edge no Android](https://expo.dev/blog/edge-to-edge-display-now-streamlined-for-android), era comum ter uma barra de status e uma barra de navegação translúcidas. Com essa abordagem, o conteúdo desenhado por trás dessas barras já ficava embaixo delas, e normalmente não era necessário considerar as áreas seguras.

Agora, [com o edge-to-edge no Android](https://expo.dev/blog/edge-to-edge-display-now-streamlined-for-android), você precisa usar áreas seguras para garantir que o conteúdo não se sobreponha às barras do sistema.

## Personalizando as barras do sistema

As barras do sistema podem ser personalizadas para combinar com o design do seu app e oferecer melhor visibilidade em diferentes cenários. Ao usar a Expo, há duas bibliotecas disponíveis para isso: `expo-status-bar` e `expo-navigation-bar` (somente Android).

### Configuração da barra de status

A barra de status aparece no topo da tela, tanto no Android quanto no iOS. Você pode personalizá-la usando o [`expo-status-bar`](/versions/latest/sdk/status-bar). Ele oferece um componente `StatusBar` que você pode usar para controlar a aparência da barra de status enquanto o app está em execução, pela propriedade [`style`](/versions/latest/sdk/status-bar/#style) ou pelo método [`setStatusBarStyle`](/versions/latest/sdk/status-bar/#statusbarsetstatusbarstylestyle-animated):

```tsx src/app/_layout.tsx
import { StatusBar } from 'expo-status-bar';

export default function RootLayout() {
  return (
    <>
      {/* Use light text instead of dark text in the status bar to provide more contrast with a dark background. */}
      <StatusBar style="light" />
    </>
  );
}
```

> **Note:** No template padrão da Expo, a propriedade `style` vem definida como `auto`. Ela escolhe automaticamente o estilo adequado de acordo com o esquema de cores (modo claro ou escuro) que o app está usando no momento.

Para controlar a visibilidade do `StatusBar`, você pode definir a propriedade [`hidden`](/versions/latest/sdk/status-bar/#hidden) como `true` ou usar o método [`setStatusBarHidden`](/versions/latest/sdk/status-bar/#statusbarsetstatusbarhiddenhidden-animation).

### Configuração da barra de navegação (somente Android)

Em dispositivos Android, a barra de navegação aparece na parte inferior da tela. Você pode personalizá-la usando a biblioteca [`expo-navigation-bar`](/versions/latest/sdk/navigation-bar). Ela oferece um componente `NavigationBar` que você pode usar para definir o estilo da barra de navegação pelo método [`setStyle`](/versions/latest/sdk/navigation-bar/#navigationbarsetstylestyle):

```tsx src/app/_layout.tsx
import { NavigationBar } from 'expo-navigation-bar';

export default function RootLayout() {
  return (
    <>
      {/* Set the navigation bar style */}
      <NavigationBar style="dark" />
    </>
  );
}
```

Para controlar a visibilidade do `NavigationBar`, você pode usar a prop [`hidden`](/versions/latest/sdk/navigation-bar/#hidden) ou o método [`NavigationBar.setHidden`](/versions/latest/sdk/navigation-bar/#sethiddenhidden).
