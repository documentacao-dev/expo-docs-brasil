## Configuração

> **info** Para projetos Android e iOS, é preciso uma configuração adicional para alternar entre o modo claro e o modo escuro. Para a web, não é necessária nenhuma configuração adicional.

Para configurar os estilos de aparência disponíveis, use a propriedade [`userInterfaceStyle`](/versions/latest/config/app/#userinterfacestyle) no [app config](/versions/latest/config/app) do seu projeto. Por padrão, essa propriedade vem definida como `automatic` quando você cria um novo projeto com o [template padrão](/get-started/create-a-project/).

Veja um exemplo de configuração:

```json app.json
{
  "expo": {
    "userInterfaceStyle": "automatic"
  }
}
```

Você também pode configurar a propriedade `userInterfaceStyle` para plataformas específicas, definindo [`android.userInterfaceStyle`](/versions/latest/config/app/#userinterfacestyle-2) ou [`ios.userInterfaceStyle`](/versions/latest/config/app/#userinterfacestyle-1) com o valor desejado.

> **info** O app usa o estilo `light` por padrão se essa propriedade não estiver presente.

Ao criar um development build, você precisa instalar o [`expo-system-ui`](/versions/latest/sdk/system-ui/#installation) para habilitar os estilos de aparência no Android. Caso contrário, a propriedade `userInterfaceStyle` é ignorada.

<Terminal
  cmd={{
    npm: ['$ npx expo install expo-system-ui'],
    yarn: ['$ yarn expo install expo-system-ui'],
    pnpm: ['$ pnpm expo install expo-system-ui'],
    bun: ['$ bun expo install expo-system-ui'],
  }}
/>

Se o projeto estiver mal configurado e não tiver o `expo-system-ui` instalado, o aviso a seguir será exibido no terminal:

<Terminal
  cmd={[
    '» android: userInterfaceStyle: Install expo-system-ui in your project to enable this feature.',
  ]}
/>

Você também pode usar o comando a seguir para verificar se o projeto está mal configurado:

<Terminal

    yarn: ['$ yarn expo config --type introspect'],
    pnpm: ['$ pnpm expo config --type introspect'],
    bun: ['$ bun expo config --type introspect'],
  }}

### Android

Garanta que a flag `uiMode` esteja presente na sua `MainActivity` (e em qualquer outra activity em que esse comportamento seja desejado) no **AndroidManifest.xml**:

```xml
<activity android:configChanges="keyboard|keyboardHidden|orientation|screenSize|uiMode">
```

Implemente o método `onConfigurationChanged` no **MainActivity.java**:

```java
/* @info Import the `Intent` and `Configuration` classes. */
import android.content.Intent;
import android.content.res.Configuration;
/* @end */
public class MainActivity extends ReactActivity {
  /* @hide ... */ /* @end */

  @Override
  public void onConfigurationChanged(Configuration newConfig) {
    super.onConfigurationChanged(newConfig);
    Intent intent = new Intent("onConfigurationChanged");
    intent.putExtra("newConfig", newConfig);
    sendBroadcast(intent);
  }
  /* @hide ... */ /* @end */
}
```

### iOS

Você pode configurar os estilos disponíveis com a chave [`UIUserInterfaceStyle`](https://developer.apple.com/documentation/bundleresources/information_property_list/uiuserinterfacestyle) no **Info.plist** do seu app. Use `Automatic` para oferecer os modos claro e escuro.

### Estilos de aparência disponíveis

A propriedade `userInterfaceStyle` aceita os valores a seguir:

- `automatic`: Segue as configurações de aparência do sistema e acompanha qualquer mudança feita pelo usuário.
- `light`: Restringe o app ao tema claro.
- `dark`: Restringe o app ao tema escuro.

## Detecte o esquema de cores

Para detectar o esquema de cores no seu projeto, use `Appearance` ou `useColorScheme` do `react-native`:

```tsx src/app/index.tsx
import { Appearance, useColorScheme } from 'react-native';
```

Depois, você pode usar o hook `useColorScheme()`, como mostrado abaixo:

```tsx src/app/index.tsx
function MyComponent() {
  let colorScheme = useColorScheme();

  if (colorScheme === 'dark') {
    // render some dark thing
  } else {
    // render some light thing
  }
}
```

Em alguns casos, pode ser útil obter o esquema de cores atual de forma imperativa com [`Appearance.getColorScheme()` ou ouvir as mudanças com `Appearance.addChangeListener()`](https://reactnative.dev/docs/appearance).

### Exemplo mínimo

<SnackInline label="Exemplo de useColorScheme" dependencies={['expo-status-bar']}>

```tsx
import { Text, StyleSheet, View, /* @info Import `useColorScheme` from react-native */ useColorScheme /* @end */ } from 'react-native';
/* @info Automatically switches bar style based on theme. */
import { StatusBar } from 'expo-status-bar';
/* @end */

export default function App() {
  const colorScheme = useColorScheme();

  const themeTextStyle = colorScheme === 'light' ? styles.lightThemeText : styles.darkThemeText;
  const themeContainerStyle =
    colorScheme === 'light' ? styles.lightContainer : styles.darkContainer;

  return (
    <View style={[styles.container, themeContainerStyle]}>
      <Text style={[styles.text, themeTextStyle]}>Color scheme: {colorScheme}</Text>
      <StatusBar />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    alignItems: 'center',
    justifyContent: 'center',
  },
  text: {
    fontSize: 20,
  },
  lightContainer: {
    backgroundColor: '#d0d0c0',
  },
  darkContainer: {
    backgroundColor: '#242c40',
  },
  lightThemeText: {
    color: '#242c40',
  },
  darkThemeText: {
    color: '#d0d0c0',
  },
});
```

### Dicas

Enquanto desenvolve o projeto, você pode mudar a aparência do simulador ou do dispositivo usando os atalhos a seguir:

- Se estiver usando um emulador Android, execute `adb shell "cmd uimode night yes"` para ativar o modo escuro e `adb shell "cmd uimode night no"` para desativá-lo.
- Se estiver usando um dispositivo Android físico ou um emulador Android, alterne a configuração de modo escuro do sistema nas configurações do dispositivo.
- Se estiver trabalhando com um simulador iOS localmente, use o atalho <kbd>Cmd ⌘</kbd> + <kbd>Shift</kbd> + <kbd>A</kbd> para alternar entre os modos claro e escuro.
