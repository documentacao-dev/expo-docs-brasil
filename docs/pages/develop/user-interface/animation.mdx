Animações são uma ótima forma de melhorar e oferecer uma experiência melhor ao usuário. No seu projeto Expo, você pode usar a [Animated API](https://reactnative.dev/docs/next/animations) do React Native. Porém, se você quiser animações mais avançadas e com melhor desempenho, pode usar a biblioteca [`react-native-reanimated`](https://docs.swmansion.com/react-native-reanimated/). Ela oferece uma API que simplifica a criação de animações fluidas, poderosas e fáceis de manter.

## Instalação

Você pode pular a instalação do `react-native-reanimated` se criou o projeto com [o template padrão](/get-started/create-a-project/). Essa biblioteca já vem instalada. Caso contrário, instale-a executando o comando a seguir:

<Terminal
  cmd={{
    npm: ['$ npx expo install react-native-reanimated'],
    yarn: ['$ yarn expo install react-native-reanimated'],
    pnpm: ['$ pnpm expo install react-native-reanimated'],
    bun: ['$ bun expo install react-native-reanimated'],
  }}
/>

## Uso

### Exemplo mínimo

O exemplo a seguir mostra como usar a biblioteca `react-native-reanimated` para criar uma animação simples. Para mais informações sobre a API e o uso avançado, veja a [documentação do `react-native-reanimated`](https://docs.swmansion.com/react-native-reanimated/docs/fundamentals/your-first-animation).

<SnackInline label="Usando react-native-reanimated" dependencies={['react-native-reanimated']}>

```tsx
import Animated, {
  useSharedValue,
  withTiming,
  useAnimatedStyle,
  Easing,
} from 'react-native-reanimated';
import { View, Button, StyleSheet } from 'react-native';

export default function AnimatedStyleUpdateExample() {
  const randomWidth = useSharedValue(10);

  const config = {
    duration: 500,
    easing: Easing.bezier(0.5, 0.01, 0, 1),
  };

  const style = useAnimatedStyle(() => {
    return {
      width: withTiming(randomWidth.value, config),
    };
  });

  return (
    <View style={styles.container}>
      <Animated.View style={[styles.box, style]} />
      <Button
        title="toggle"
        onPress={() => {
          randomWidth.value = Math.random() * 350;
        }}
      />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    alignItems: 'center',
    justifyContent: 'center',
  },
  box: {
    width: 100,
    height: 80,
    backgroundColor: 'black',
    margin: 30,
  },
});
```

</SnackInline>
