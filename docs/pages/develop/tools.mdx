Quando você cria um novo projeto com a Expo, conhecer as ferramentas e sites essenciais a seguir pode ajudar bastante durante o desenvolvimento do seu app. Esta página traz uma visão geral da lista de ferramentas recomendadas.

## Expo CLI \{#expo-cli}

A Expo CLI é uma ferramenta de desenvolvimento e é instalada automaticamente com o pacote `expo` quando você cria um novo projeto. Você pode usá-la com o `npx` (um executor de pacotes do Node.js).

Ela foi feita para ajudar você a ganhar velocidade na fase de desenvolvimento do app. Por exemplo, o primeiro contato com a Expo CLI é iniciar o servidor de desenvolvimento com o comando: `npx expo start`.

A seguir, uma lista dos comandos mais comuns que você vai usar com a Expo CLI enquanto desenvolve o seu app:

| Comando                         | Descrição                                                                                                                                                         |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `npx expo start`                | Inicia o servidor de desenvolvimento (tanto se você estiver usando um development build quanto o Expo Go).                                                        |
| `npx expo prebuild`             | Gera os diretórios nativos do Android e do iOS usando o [Prebuild](/workflow/continuous-native-generation/).                                                      |
| `npx expo run:android`          | Compila o app nativo do Android localmente.                                                                                                                        |
| `npx expo run:ios`              | Compila o app nativo do iOS localmente.                                                                                                                            |
| `npx expo install package-name` | Usado para instalar uma nova biblioteca ou para validar e atualizar bibliotecas específicas do projeto. Adicione a opção `--fix` a este comando para corrigi-las.   |
| `npx expo lint`                 | [Configura](/guides/using-eslint/) o ESLint. Se o ESLint já estiver configurado, este comando [faz o lint dos arquivos do projeto](/guides/using-eslint/#usage). |

Em resumo, a Expo CLI permite desenvolver, compilar, iniciar o seu app e muito mais. Veja a [referência da Expo CLI](/more/expo-cli/) para mais opções e ações disponíveis pela ferramenta.

## EAS CLI \{#eas-cli}

A EAS CLI é usada para fazer login na sua conta Expo e compilar o seu app usando os diferentes serviços da Expo, como Build, Update ou Submit. Você também pode usar essa ferramenta para:

- Publicar o seu app nas lojas
- Criar um development, preview ou production build do seu app
- Criar atualizações over-the-air (OTA)
- Gerenciar as credenciais do seu app
- Criar um perfil de provisionamento ad hoc para um dispositivo iOS

Para usar a EAS CLI, você precisa instalá-la globalmente na sua máquina, executando o comando:

<Terminal
  cmd={{
    npm: ['$ npm install --global eas-cli'],
    yarn: ['$ yarn global add eas-cli'],
    pnpm: ['$ pnpm add --global eas-cli'],
    bun: ['$ bun add --global eas-cli'],
  }}
/>

Use `eas --help` no seu terminal para saber mais sobre os comandos disponíveis. Para a referência completa, veja a [página da `eas-cli` no npm](https://www.npmjs.com/package/eas-cli).

## Expo Doctor \{#expo-doctor}

O Expo Doctor é uma ferramenta de linha de comando usada para diagnosticar problemas no seu projeto Expo. Para usá-la, execute o comando a seguir na raiz do seu projeto:

<Terminal
  cmd={{
    npm: ['$ npx expo-doctor'],
    yarn: ['$ yarn dlx expo-doctor'],
    pnpm: ['$ pnpm dlx expo-doctor'],
    bun: ['$ bunx expo-doctor'],
  }}
/>

Esse comando faz verificações e analisa o código do seu projeto em busca de problemas comuns nas propriedades de [app config](/workflow/configuration/) e nos arquivos **package.json**, na compatibilidade de dependências, nos arquivos de configuração e na saúde geral do projeto. Quando a verificação termina, o Expo Doctor mostra os resultados.

Se o Expo Doctor encontrar um problema, ele descreve o que aconteceu e dá dicas de como corrigir ou de onde buscar ajuda.

Por padrão, o Expo Doctor valida os pacotes do seu projeto contra o [diretório do React Native](https://reactnative.directory/) e verifica se as propriedades do app config estão sincronizadas quando os diretórios nativos existem. Você pode configurar essas verificações no arquivo **package.json** do seu projeto. Veja [`reactNativeDirectoryCheck`](/versions/latest/config/package-json/#reactnativedirectorycheck) e [`appConfigFieldsNotSyncedCheck`](/versions/latest/config/package-json/#appconfigfieldsnotsyncedcheck) para mais detalhes.

Você também pode usar `npx expo-doctor --help` para exibir as informações de uso.

## Orbit \{#orbit}

O Orbit é um app para macOS, Windows e Linux que permite:

- Instalar e abrir builds do Expo Build em dispositivos físicos e emuladores.
- Instalar e abrir updates do Expo Update em emuladores Android ou simuladores iOS.
- Abrir projetos do snack em emuladores Android ou simuladores iOS.
- Usar arquivos locais para instalar e abrir apps. O Orbit aceita qualquer **.apk** do Android, **.app** compatível com o simulador iOS ou apps assinados ad hoc.
- Ver uma lista de projetos fixados do seu painel Expo.

## Expo Tools para VS Code \{#expo-tools-for-vs-code}

O Expo Tools é uma extensão do VS Code que melhora a sua experiência de desenvolvimento ao trabalhar com arquivos de app config. Ele oferece recursos como autocomplete e intellisense para arquivos como o app config, o **eas.json**, os arquivos de configuração das lojas e os arquivos de configuração de módulos Expo.

<BoxLink

Você também pode usá-la para depurar o seu app com o depurador integrado do VS Code, definindo breakpoints, inspecionando variáveis, executando código pelo console de depuração e muito mais. Veja [Depuração com VS Code](/debugging/tools/#debugging-with-vs-code) para saber como usar essa extensão na depuração.

## Teste protótipos com Snack e Expo Go \{#test-prototypes-with-snack-and-expo-go}

### Snack \{#snack}

O Snack é um ambiente de desenvolvimento no navegador que funciona de forma parecida com o Expo Go. É uma ótima maneira de compartilhar trechos de código e experimentar o React Native sem instalar nenhuma ferramenta no seu computador.

Para usar, acesse [snack.expo.dev](https://snack.expo.dev/), edite o componente `<Text>` no **App.js**, escolha uma plataforma (Android, iOS ou web) no painel da direita e veja as mudanças em tempo real.

### Expo Go \{#expo-go}

O [Expo Go](https://expo.dev/go) é um playground gratuito e de código aberto para estudantes e quem está aprendendo a usar o React Native. Ele funciona com Android e iOS.

Para saber mais sobre como usá-lo:

- Clique [neste link](/get-started/set-up-your-environment/?mode=expo-go) para ir ao guia Configure seu ambiente
- Selecione uma plataforma em **Onde você quer desenvolver?**
- Selecione Expo Go em **Como você quer desenvolver?**
- Siga as instruções descritas nesse guia

> **Note:** O Expo Go é limitado e não serve para criar projetos de produção. Use os [development builds](/get-started/set-up-your-environment/?mode=development-build) no lugar.

#### CLI `expo-go` \{#expo-go-cli}

A [CLI `expo-go`](https://www.npmjs.com/package/expo-go) é uma ferramenta independente que baixa o binário do Expo Go para uma plataforma e uma versão específica do SDK, ou mostra a URL de download. Passe a versão do SDK para fixar uma versão específica ou omita-a para usar a versão mais recente, e informe a plataforma para baixar o binário correto.

<Terminal
  cmd={{
    npm: [
      '# Download Expo Go for a platform',
      '$ npx expo-go download android latest',
      '',
      '# Print the download URL instead of downloading',
      '$ npx expo-go url ios latest',
    ],
    yarn: [
      '# Download Expo Go for a platform',
      '$ yarn dlx expo-go download android latest',
      '',
      '# Print the download URL instead of downloading',
      '$ yarn dlx expo-go url ios latest',
    ],
    pnpm: [
      '# Download Expo Go for a platform',
      '$ pnpm dlx expo-go download android latest',
      '',
      '# Print the download URL instead of downloading',
      '$ pnpm dlx expo-go url ios latest',
    ],
    bun: [
      '# Download Expo Go for a platform',
      '$ bunx expo-go download android latest',
      '',
      '# Print the download URL instead of downloading',
      '$ bunx expo-go url ios latest',
    ],
  }}
/>

Esse comando baixa o app Expo Go para o diretório atual e o guarda em cache dentro de **~/.expo**.

> **warning** A CLI `expo-go` funciona para dispositivos Android, emuladores Android e simuladores iOS. Por causa das políticas da Apple, um iPhone em geral não aceita a instalação de versões antigas de apps por sideload, e a CLI `expo-go` não oferece suporte a isso.

<Collapsible summary="E se eu abrir um projeto com uma versão de SDK sem suporte?">

Ao executar um projeto criado para uma versão de SDK sem suporte no Expo Go, você verá o seguinte erro:

```text
"Project is incompatible with this version of Expo Go"
```

A correção depende de você estar usando um dispositivo Android, um dispositivo iOS físico ou um simulador. Veja [Resolva a incompatibilidade de versão do Expo Go](/troubleshooting/expo-go-version-mismatch/) para instalar uma versão compatível ou atualizar o seu projeto.

</Collapsible>

Veja o [guia de atualização do Expo SDK](/workflow/upgrading-expo-sdk-walkthrough) com as instruções para atualizar para uma versão específica do SDK.

## Diretório do React Native \{#react-native-directory}

Qualquer biblioteca compatível com o React Native funciona em um projeto Expo quando você usa um development build para criar o projeto.

[reactnative.directory](https://reactnative.directory/) é um banco de dados pesquisável de bibliotecas do React Native. Se a biblioteca que você procura não estiver incluída no Expo SDK, use o diretório para encontrar uma biblioteca compatível com o seu projeto.
