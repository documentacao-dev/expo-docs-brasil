O Expo é um [framework open source](https://github.com/expo/expo/) para apps que rodam nativamente no Android, no iOS e na web. Ele reúne o melhor do mobile e da web e oferece muitos recursos importantes para criar e escalar um app.

O pacote npm `expo` traz um conjunto de recursos incríveis para apps React Native. Ele pode ser instalado em quase **qualquer projeto React Native**.

> **info** Todos os recursos são gratuitos, opcionais e podem ser usados de forma independente uns dos outros. Recursos não usados não aumentam o tamanho do seu app.

## Serviços

A equipe por trás do Expo também oferece os **Expo Services**, serviços de nuvem profundamente integrados para fazer build, enviar e atualizar seu app React Native. Os Expo Services podem ser usados com **qualquer app React Native**, esteja ou não usando o `expo`.
