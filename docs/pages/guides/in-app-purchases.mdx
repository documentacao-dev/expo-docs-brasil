Compras dentro do app (IAP, na sigla em inglês) são transações em um app para dispositivos móveis ou desktop nas quais o usuário compra bens digitais ou recursos adicionais. Este guia traz uma lista de bibliotecas populares e tutoriais para implementar compras dentro do app no seu app Expo.

> As bibliotecas de compras dentro do app exigem a configuração de código nativo customizado. O código nativo não pode ser configurado no Expo Go. Em vez disso, crie um [development build](/develop/development-builds/introduction/), que permite usar uma biblioteca nativa no seu projeto.

## Bibliotecas \{#libraries}

As bibliotecas a seguir oferecem suporte a compras dentro do app e funcionam direto em apps Expo que usam [CNG](/workflow/continuous-native-generation/) e [Config Plugins](/config-plugins/introduction/), para uma integração sem complicações no seu app.

<BoxLink
  title={
    <>
      <CODE>react-native-purchases</CODE>
    </>
  }
  description="Um framework de código aberto que fornece um wrapper para as APIs do Google Play Billing e do StoreKit, e integração com os serviços do RevenueCat para compras dentro do app. Ele permite gerenciar produtos, acessar analytics e simplificar workflows para requisitos de compras dentro do app que podem ir além do código do cliente, como validar compras no backend do app."
  href="https://github.com/RevenueCat/react-native-purchases"
  Icon={GithubIcon}
/>

  Icon={GithubIcon}
