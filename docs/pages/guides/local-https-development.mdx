Ao desenvolver apps Expo para web localmente, você pode precisar usar HTTPS no seu ambiente de desenvolvimento local para testar APIs de navegador que exigem conexão segura. Este guia mostra como configurar HTTPS local para apps Expo na web.

<Prerequisites>
  <Requirement
    title={
      <>
        <CODE>mkcert</CODE> instalado
      </>
    }>
    `mkcert` é uma ferramenta para criar certificados de desenvolvimento. Para as instruções de instalação, veja o
    [repositório do `mkcert` no GitHub](https://github.com/FiloSottile/mkcert#installation).
  </Requirement>
</Prerequisites>

## Benefícios \{#benefits}

- **Escalabilidade para o time**: a mesma configuração funciona para todos
- **Suporte a autenticação**: cookies HTTP-Only e contextos seguros
- **Paridade com produção**: use o mesmo ambiente HTTPS da sua produção
- **Compartilhamento fácil**: URLs de desenvolvimento consistentes entre o time

## Configure seu projeto \{#set-up-your-project}

<Step label="1">

Crie ou acesse seu projeto Expo:

<Terminal
  cmd={{
    npm: [
      '# Create a new project (if needed)',
      '$ npx create-expo-app@latest example-app',
      '$ cd example-app',
      '',
      '# Or navigate to existing project',
      '$ cd your-expo-project',
    ],
    yarn: [
      '# Create a new project (if needed)',
      '$ yarn create expo-app example-app',
      '$ cd example-app',
      '',
      '# Or navigate to existing project',
      '$ cd your-expo-project',
    ],
    pnpm: [
      '# Create a new project (if needed)',
      '$ pnpm create expo-app example-app',
      '$ cd example-app',
      '',
      '# Or navigate to existing project',
      '$ cd your-expo-project',
    ],
    bun: [
      '# Create a new project (if needed)',
      '$ bun create expo example-app',
      '$ cd example-app',
      '',
      '# Or navigate to existing project',
      '$ cd your-expo-project',
    ],
  }}
/>

</Step>

<Step label="2">

Inicie o servidor de desenvolvimento do Expo:

<Terminal
  cmd={{
    npm: ['$ npx expo start --web'],
    yarn: ['$ yarn expo start --web'],
    pnpm: ['$ pnpm expo start --web'],
    bun: ['$ bun expo start --web'],
  }}
/>

Seu app vai rodar em `http://localhost:8081`. Mantenha esta janela do terminal aberta.

</Step>

<Step label="3">

Use o `mkcert` para gerar um certificado para o localhost. Execute o comando a seguir em uma nova janela do terminal, a partir da raiz do seu projeto:

<Terminal cmd={['$ mkcert localhost']} />

> **info** **Tip**: depois de instalar o `mkcert`, execute `mkcert -install` para instalar a autoridade certificadora (CA) local.

Isso vai gerar dois arquivos de certificado assinados: `localhost.pem` (certificado) e `localhost-key.pem` (chave privada), na raiz do seu projeto.

</Step>

<Step label="4">

Na raiz do projeto, execute o comando a seguir para iniciar o proxy:

<Terminal
  cmd={{
    npm: [
      '$ npx local-ssl-proxy --source 443 --target 8081 --cert localhost.pem --key localhost-key.pem',
    ],
    yarn: [
      '$ yarn dlx local-ssl-proxy --source 443 --target 8081 --cert localhost.pem --key localhost-key.pem',
    ],
    pnpm: [
      '$ pnpm dlx local-ssl-proxy --source 443 --target 8081 --cert localhost.pem --key localhost-key.pem',
    ],
    bun: [
      '$ bunx local-ssl-proxy --source 443 --target 8081 --cert localhost.pem --key localhost-key.pem',
    ],
  }}
/>

> **info** **Tip**: o [`local-ssl-proxy`](https://github.com/cameronhunter/local-ssl-proxy) é uma ferramenta que cria um servidor proxy que encaminha o tráfego HTTPS da porta 443 para o seu servidor de desenvolvimento do Expo na porta 8081.

Isso cria um proxy que encaminha o tráfego HTTPS da porta 443 para o seu servidor de desenvolvimento do Expo na porta 8081.

</Step>

<Step label="5">

Abra `https://localhost` no navegador para acessar seu app. Agora seu app Expo está rodando com HTTPS.

</Step>
