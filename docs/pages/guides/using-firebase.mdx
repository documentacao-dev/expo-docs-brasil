[Firebase](https://firebase.google.com/) é uma plataforma de desenvolvimento de apps do tipo Backend-as-a-Service (BaaS) que oferece serviços de backend hospedados, como banco de dados em tempo real, armazenamento em nuvem, autenticação, relatórios de falhas, analytics e outros.
Ela é construída sobre a infraestrutura do Google e escala automaticamente.

Existem duas formas de usar o Firebase nos seus projetos:

- Usando o [Firebase JS SDK](#using-firebase-js-sdk)
- Usando o [React Native Firebase](#using-react-native-firebase)

O React Native oferece suporte tanto ao JS SDK quanto ao SDK nativo. As seções a seguir explicam quando usar cada SDK e todas as etapas de configuração necessárias para usar o Firebase nos seus projetos Expo.

<Prerequisites>
  <Requirement title="Um projeto Firebase">
    Crie um projeto Firebase novo ou use um existente no [Firebase
    Console](https://console.firebase.google.com/).
  </Requirement>
</Prerequisites>

## Usando o Firebase JS SDK \{#using-firebase-js-sdk}

O [Firebase JS SDK](https://firebase.google.com/docs/web/setup) é uma biblioteca JavaScript que permite interagir com os serviços do Firebase no seu projeto.
Ele oferece suporte a serviços como [Authentication](https://firebase.google.com/docs/auth), [Firestore](https://firebase.google.com/docs/firestore), [Realtime Database](https://firebase.google.com/docs/database) e [Storage](https://firebase.google.com/docs/storage) em um app React Native.

### Quando usar o Firebase JS SDK \{#when-to-use-firebase-js-sdk}

Você pode considerar usar o Firebase JS SDK quando quiser:

- Usar serviços do Firebase, como Authentication, Firestore, Realtime Database e Storage, no seu app, e desenvolver esse app com o [**Expo Go**](/get-started/set-up-your-environment/).
- Começar rapidamente com os serviços do Firebase.
- Criar um app universal para Android, iOS e web.

#### Limitações \{#caveats}

O Firebase JS SDK não oferece suporte a todos os serviços para apps mobile. Alguns deles são Analytics, Dynamic Links e Crashlytics. Veja a seção [React Native Firebase](#using-react-native-firebase) se quiser usar esses serviços.

### Instale e inicialize o Firebase JS SDK \{#install-and-initialize-firebase-js-sdk}

> **warning** O Expo SDK só oferece suporte ao `firebase@12.0.0` e versões superiores. Versões anteriores causam erros de resolução de módulos ES.

<Step label="1">
#### Instale o SDK \{#install-the-sdk}

Depois de criar o seu [projeto Expo](/get-started/create-a-project/), você pode instalar o Firebase JS SDK com o comando a seguir:

<Terminal
  cmd={{
    npm: ['$ npx expo install firebase'],
    yarn: ['$ yarn expo install firebase'],
    pnpm: ['$ pnpm expo install firebase'],
    bun: ['$ bun expo install firebase'],
  }}
/>

</Step>

<Step label="2">
#### Inicialize o SDK no seu projeto \{#initialize-the-sdk-in-your-project}

Para inicializar a instância do Firebase no seu projeto Expo, crie um objeto de configuração e passe-o para o método `initializeApp()`, importado do módulo `firebase/app`.

O objeto de configuração exige uma chave de API e outros identificadores exclusivos. Para obter esses valores, você precisa registrar um app web no seu projeto Firebase. Essas instruções estão na [documentação do Firebase](https://firebase.google.com/docs/web/setup#register-app).

Depois de ter a chave de API e os outros identificadores, cole o trecho de código a seguir criando um novo arquivo **firebaseConfig.js** na raiz do projeto ou em qualquer outro diretório onde você guarde os arquivos de configuração.

```js firebaseConfig.js
import { initializeApp } from 'firebase/app';

// Optionally import the services that you want to use
// import {...} from 'firebase/auth';
// import {...} from 'firebase/database';
// import {...} from 'firebase/firestore';
// import {...} from 'firebase/functions';
// import {...} from 'firebase/storage';

// Initialize Firebase
const firebaseConfig = {
  apiKey: 'api-key',
  authDomain: 'project-id.firebaseapp.com',
  databaseURL: 'https://project-id.firebaseio.com',
  projectId: 'project-id',
  storageBucket: 'project-id.appspot.com',
  messagingSenderId: 'sender-id',
  appId: 'app-id',
  measurementId: 'G-measurement-id',
};

const app = initializeApp(firebaseConfig);
// For more information on how to access Firebase in your project,
// see the Firebase documentation: https://firebase.google.com/docs/web/setup#access-firebase
```

Você não precisa instalar outros plugins ou configurações para usar o Firebase JS SDK.

O Firebase versão 9 e superiores oferece uma API modular. Você pode importar diretamente qualquer serviço que quiser do pacote `firebase`. Por exemplo, se quiser usar um serviço de autenticação no projeto, importe o módulo `auth` do pacote `firebase/auth`.

> **info** **Dica de solução de problemas:** se você encontrar problemas relacionados à persistência de autenticação com o Firebase JS SDK, veja o guia para [configurar a persistência e manter os usuários conectados entre recarregamentos](https://expo.fyi/firebase-js-auth-setup).

</Step>

## Usando o React Native Firebase \{#using-react-native-firebase}

O [React Native Firebase](https://rnfirebase.io/) dá acesso ao código nativo ao encapsular os SDKs nativos para Android e iOS em uma API JavaScript.
Cada serviço do Firebase está disponível como um módulo que pode ser adicionado como dependência do projeto. Por exemplo, o módulo `auth` dá acesso ao serviço Firebase Authentication.

### Quando usar o React Native Firebase \{#when-to-use-react-native-firebase}

Você pode considerar usar o React Native Firebase quando:

- O seu app precisar de serviços do Firebase que não são compatíveis com o Firebase JS SDK, como Dynamic Links, [Crashlytics](https://rnfirebase.io/crashlytics/usage) e outros.
  Para mais informações sobre os recursos adicionais oferecidos pelos SDKs nativos, veja a [documentação do React Native Firebase](https://rnfirebase.io/faqs-and-tips#why-react-native-firebase-over-firebase-js-sdk).
- Você quiser usar SDKs nativos no seu app.
- Você tiver um [projeto React Native existente](/bare/overview/) com o React Native Firebase já configurado, mas estiver migrando para usar o Expo SDK.
- Você quiser usar o [Firebase Analytics](https://rnfirebase.io/analytics/usage) no seu app.

<Collapsible summary="Migrando dos pacotes Firebase do Expo?">

Se o seu projeto já usava os pacotes `expo-firebase-analytics` e `expo-firebase-recaptcha`, você pode migrar para a biblioteca React Native Firebase. Para mais informações, veja o [guia de migração do Firebase](https://expo.fyi/firebase-migration-guide).

</Collapsible>

#### Limitações \{#caveats-1}

O React Native Firebase exige [código nativo personalizado e não pode ser usado com o Expo Go](/workflow/customizing/).

### Instale e inicialize o React Native Firebase \{#install-and-initialize-react-native-firebase}

<Step label="1">
#### Instale o expo-dev-client \{#install-expo-dev-client}

Como o React Native Firebase exige código nativo personalizado, você precisa instalar a biblioteca `expo-dev-client` no seu projeto.
Ela permite configurar qualquer código nativo exigido pelo React Native Firebase usando [Config plugins](/config-plugins/introduction/), sem que você precise escrever código nativo por conta própria.

Para instalar o [`expo-dev-client`](/develop/development-builds/introduction/#how-would-you-like-to-build-your-development-build), execute o comando a seguir no seu projeto:

<Terminal
  cmd={{
    npm: ['$ npx expo install expo-dev-client'],
    yarn: ['$ yarn expo install expo-dev-client'],
    pnpm: ['$ pnpm expo install expo-dev-client'],
    bun: ['$ bun expo install expo-dev-client'],
  }}
/>
</Step>

<Step label="2">
#### Instale o React Native Firebase \{#install-react-native-firebase}

Para usar o React Native Firebase, é necessário instalar o módulo `@react-native-firebase/app`. Esse módulo fornece a funcionalidade principal para todos os outros módulos.
Ele também adiciona código nativo personalizado ao seu projeto por meio de um config plugin. Você pode instalá-lo com o comando a seguir:

<Terminal
  cmd={{
    npm: ['$ npx expo install @react-native-firebase/app'],
    yarn: ['$ yarn expo install @react-native-firebase/app'],
    pnpm: ['$ pnpm expo install @react-native-firebase/app'],
    bun: ['$ bun expo install @react-native-firebase/app'],
  }}
/>

**Neste ponto, siga as instruções da [documentação do React Native Firebase](https://rnfirebase.io/#installation-for-expo-projects)**, pois ela cobre todas as etapas necessárias para configurar o seu projeto com a biblioteca.

Depois de configurar a biblioteca React Native Firebase no seu projeto, volte a este guia para aprender a executar o projeto na próxima etapa.

</Step>

<Step label="3">
#### Execute o projeto \{#run-the-project}

Se você estiver usando o **[Expo Build](/build/introduction/), pode criar e instalar um development build** nos seus dispositivos. Você não precisa executar o projeto localmente antes de criar um development build.
Para mais informações sobre como criar um development build, veja a seção sobre [instalar um development build](/develop/development-builds/introduction/#how-would-you-like-to-build-your-development-build).

<Collapsible summary="Executar o projeto localmente?">

Se quiser executar o projeto localmente, você precisa ter o Android Studio e o Xcode instalados e configurados na sua máquina. Veja o guia [Desenvolvimento local de apps](/guides/local-app-development/) para mais informações.

Se um módulo específico do React Native Firebase exigir etapas de configuração nativa, adicione-o como um `plugin` no arquivo de [app config](/workflow/configuration/). Depois, para executar o projeto localmente, rode o comando `npx expo prebuild --clean` para aplicar as mudanças nativas antes dos comandos `npx expo run`.

</Collapsible>
</Step>
