Você pode aproveitar seu ambiente de desenvolvimento local para fazer o build do app localmente, usando o Android Studio e o Xcode. Esse processo pode ser feito tanto para builds de debug quanto para builds de release. Esta página oferece uma visão geral das diferentes formas de fazer o build do app na sua própria máquina e traz links para outros guias que podem ser necessários nesse workflow.

## Quando fazer o build do app localmente \{#when-to-build-your-app-locally}

Há diferentes cenários em que você quer fazer o build do app na sua máquina de desenvolvimento:

- Você quer fazer iterações rápidas em mudanças de código nativo ou testar mudanças específicas de plataforma no seu build de debug
- Você quer gerar o código nativo manualmente para testar seu build de debug
- Qualquer cenário em que você precise criar builds em um ambiente com acesso restrito à rede
- Você quer gerenciar suas próprias credenciais localmente (como a chave de upload, entre outras)
- Você quer testar ou integrar seu próprio provedor de cache de builds
- Você quer desativar os Expo Modules pré-compilados para Android e compilá-los a partir do código-fonte, localmente, uma vez

> **Note**: fazer o build do app localmente complementa o Expo Build. Você pode continuar usando o serviço de build para automação na nuvem e recorrer aos builds locais no desenvolvimento.

## Criar seu build de debug localmente \{#creating-your-debug-build-locally}

Para fazer o build e iterar rapidamente em um build de debug, use os comandos `npx expo run:[android|ios]` da Expo CLI. Esses comandos compilam seu projeto, usando o Android SDK ou o Xcode instalados localmente, em um build de debug do app.

## Criar seu build de release localmente \{#creating-your-release-build-locally}

Para criar um build de release (também conhecido como build de produção) do seu app, você gera as credenciais de assinatura usando as ferramentas fornecidas pelo Android Studio e pelo Xcode. Depois, pode gerar o build de release e seguir o processo de envio manual do app para a Google Play Store ou para a Apple App Store.

## Reutilizar builds de um provedor \{#reuse-previous-builds-from-a-provider}

Você pode acelerar seu desenvolvimento local armazenando em cache e reutilizando builds de um provedor. Você pode usar o Expo Build como provedor de builds ou criar seu próprio provedor personalizado.

## Expo Modules pré-compilados para Android \{#prebuilt-expo-modules-for-android}

O Expo distribui Expo Modules pré-compilados para Android, que reduzem o trabalho que o Gradle faz em cada build. Você pode continuar usando o padrão ou desativá-los seletivamente quando precisar modificar o código-fonte de um módulo.
