O [LogRocket](https://logrocket.com) grava as sessões dos usuários e identifica bugs enquanto eles usam o seu app. Você pode filtrar as sessões por IDs de update e também conectar a sua conta do LogRocket no dashboard do Expo para ter acesso rápido aos dados de sessão do seu app.

## Instalar e configurar o LogRocket \{#install-and-configure-logrocket}

Você pode instalar o SDK do LogRocket com o comando a seguir:

<Terminal
  cmd={{
    npm: ['$ npx expo install @logrocket/react-native expo-build-properties'],
    yarn: ['$ yarn expo install @logrocket/react-native expo-build-properties'],
    pnpm: ['$ pnpm expo install @logrocket/react-native expo-build-properties'],
    bun: ['$ bun expo install @logrocket/react-native expo-build-properties'],
  }}
/>

Depois, no seu [app config](/workflow/configuration/), inclua o config plugin do LogRocket:

```json app.json
{
  "plugins": [
    [
      "expo-build-properties",
      {
        "android": {
          "minSdkVersion": 25
        }
      }
    ],
    "@logrocket/react-native"
  ]
}
```

Por fim, inicialize o LogRocket no seu app, em um arquivo de nível superior, como **src/app/\_layout.tsx**:

```tsx src/app/_layout.tsx
import { useEffect } from 'react';
import * as Updates from 'expo-updates';
import LogRocket from '@logrocket/react-native';

const App = () => {
  useEffect(() => {
    LogRocket.init('<App ID>', {
      updateId: Updates.isEmbeddedLaunch ? null : Updates.updateId,
      expoChannel: Updates.channel,
    });
  }, []);
};
```

No código acima, substitua `<App ID>` pelo seu [App ID do LogRocket](https://app.logrocket.com/r/settings/setup).

## Conectar o LogRocket no dashboard do Expo \{#connecting-logrocket-on-the-expo-dashboard}

Você pode vincular a sua conta e o seu projeto do LogRocket à sua conta e ao seu projeto do Expo no dashboard do Expo, para ver as últimas sessões do seu app nos dashboards de deployments e updates.

Acesse **Account settings** > [**Overview**](https://expo.dev/accounts/%5Baccount%5D/settings) > **Connections** e clique em **Connect** para autenticar com o LogRocket:

<ContentSpotlight
  alt="Conecte a conta do LogRocket à conta do Expo."
  src="/static/images/monitoring/monitor-your-app/logrocket-connect-account.webp"
/>

Depois, acesse o seu projeto, em **Project settings** > [**General**](https://expo.dev/accounts/%5Baccount%5D/projects/%5BprojectName%5D/settings), e clique em **Connect** para vincular o seu projeto do LogRocket ao seu projeto no Expo:

<ContentSpotlight
  alt="Conecte o projeto do LogRocket ao projeto do Expo."
  src="/static/images/monitoring/monitor-your-app/logrocket-connect-project.webp"
/>

Então você vai ver os botões **View on LogRocket** no dashboard do Expo, nos dashboards de Native Deployments e Updates, junto com as últimas sessões do seu app.

<ContentSpotlight
  alt="Botão View on LogRocket e sessões no dashboard de deployments."
  src="/static/images/monitoring/monitor-your-app/logrocket-view-on-logrocket.webp"
/>
