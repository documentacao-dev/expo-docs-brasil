Autenticação em apps mobile é a forma como você identifica quem é o usuário, gerencia os fluxos de cadastro ou login e mantém a sessão autenticada entre aberturas do app e em vários dispositivos. SDKs e bibliotecas de autenticação ajudam a adicionar esses fluxos, para que você não precise criar um backend de autenticação do zero. Os guias abaixo destacam SDKs e provedores populares para projetos Expo e React Native.

> **warning** Alguns provedores exigem código nativo personalizado e não têm suporte no Expo Go. Use um [development build](/develop/development-builds/introduction/) quando for necessário.
