A minificação é uma etapa de otimização do build. Ela remove caracteres desnecessários do código-fonte, como espaços em branco excedentes e comentários, e encurta operações estáticas. Esse processo reduz o tamanho final e melhora o tempo de carregamento.

## Minificação na Expo CLI \{#minification-in-expo-cli}

Na Expo CLI, a minificação é feita nos arquivos JavaScript durante o export de produção (quando você executa `npx expo export`, `npx expo export:embed`, `eas build` e comandos semelhantes).

Por exemplo, considere o trecho de código a seguir em um projeto:

```js Input
// This comment will be stripped
console.log('a' + ' ' + 'long' + ' string' + ' to ' + 'collapse');
```

A Expo CLI vai minificar o código assim:

```js Output
console.log('a long string to collapse');
```

> **info** **Dica:** Você pode preservar comentários usando a diretiva `/** @preserve */`.

A minificação padrão da Expo CLI atende à maioria dos projetos. No entanto, você pode personalizar o minificador para otimizar a velocidade ou remover recursos extras, como logs.

## Remover logs do console \{#remove-console-logs}

Você pode remover os logs do console do seu build de produção. Use a opção `drop_console` na configuração do minificador Terser.

```js metro.config.js
const { getDefaultConfig } = require('expo/metro-config');

const config = getDefaultConfig(__dirname);

config.transformer.minifierConfig = {
  compress: {
    // The option below removes all console logs statements in production.
    drop_console: true,
  },
};

module.exports = config;
```

Você também pode passar um array com os tipos de console a remover, se quiser preservar alguns logs. Por exemplo: `drop_console: ['log', 'info']` remove `console.log` e `console.info`, mas preserva `console.warn` e `console.error`.

## Personalizar o minificador \{#customizing-the-minifier}

Cada minificador tem compromissos entre velocidade e compressão. Você pode personalizar o minificador usado pela Expo CLI alterando o arquivo **metro.config.js** do seu projeto.

### Terser \{#terser}

> [`terser`](https://github.com/terser/terser) é o minificador padrão ([changelog do Metro@0.73.0](https://github.com/facebook/metro/releases/tag/v0.73.0)).

<Step label="1">

Para instalar o Terser no projeto, execute o comando:

<Terminal
  cmd={{
    npm: ['$ npm install --save-dev metro-minify-terser'],
    yarn: ['$ yarn add --dev metro-minify-terser'],
    pnpm: ['$ pnpm add --save-dev metro-minify-terser'],
    bun: ['$ bun add --dev metro-minify-terser'],
  }}
/>

</Step>

<Step label="2">

Defina o Terser como minificador com `transformer.minifierPath` e passe as [opções do `terser`](https://github.com/terser/terser#compress-options) para `transformer.minifierConfig`.

```js metro.config.js
const { getDefaultConfig } = require('expo/metro-config');

const config = getDefaultConfig(__dirname);

config.transformer.minifierPath = 'metro-minify-terser';
config.transformer.minifierConfig = {
  // Terser options...
};

module.exports = config;
```

</Step>

### Opções unsafe do Terser \{#unsafe-terser-options}

Para obter compressão adicional, que pode não funcionar em todas as engines de JavaScript, ative as opções [`unsafe` do `compress`](https://terser.org/docs/miscellaneous/#the-unsafe-compress-option):

```js metro.config.js
const { getDefaultConfig } = require('expo/metro-config');

const config = getDefaultConfig(__dirname);

config.transformer.minifierPath = 'metro-minify-terser';

config.transformer.minifierConfig = {
  compress: {
    // Enable all unsafe optimizations.
    unsafe: true,
    unsafe_arrows: true,
    unsafe_comps: true,
    unsafe_Function: true,
    unsafe_math: true,
    unsafe_symbols: true,
    unsafe_methods: true,
    unsafe_proto: true,
    unsafe_regexp: true,
    unsafe_undefined: true,
    unused: true,
  },
};

module.exports = config;
```

### esbuild \{#esbuild}

O [`esbuild`](https://esbuild.github.io/) minifica código muito mais rápido do que o `uglify-es` e o `terser`. Para mais informações, veja o uso do [`metro-minify-esbuild`](https://github.com/EvanBacon/metro-minify-esbuild#usage).

### Uglify \{#uglify}

Para usar o [`uglify-es`](https://github.com/mishoo/UglifyJS), siga os passos abaixo:

<Step label="1">

Para instalar o Uglify no projeto, execute o comando:

<Terminal
  cmd={{
    npm: ['$ npm install --save-dev metro-minify-uglify'],
    yarn: ['$ yarn add --dev metro-minify-uglify'],
    pnpm: ['$ pnpm add --save-dev metro-minify-uglify'],
    bun: ['$ bun add --dev metro-minify-uglify'],
  }}
/>

> Confirme que a versão do `metro-minify-uglify` seja a mesma do `metro` no seu projeto.

</Step>

<Step label="2">

Defina o Uglify como minificador com `transformer.minifierPath` e passe as [opções](https://github.com/mishoo/UglifyJS#compress-options) para `transformer.minifierConfig`.

```js metro.config.js
const { getDefaultConfig } = require('expo/metro-config');

const config = getDefaultConfig(__dirname);

config.transformer.minifierPath = 'metro-minify-uglify';
config.transformer.minifierConfig = {
  // Options: https://github.com/mishoo/UglifyJS#compress-options
};

module.exports = config;
```

</Step>
