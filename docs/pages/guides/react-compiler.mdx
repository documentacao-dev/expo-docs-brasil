O novo [React Compiler](https://react.dev/learn/react-compiler) memoiza automaticamente componentes e hooks para habilitar uma reatividade refinada. Isso pode trazer melhorias significativas de desempenho no app. Para ativá-lo, siga as instruções abaixo.

## Ativando o React Compiler \{#enabling-react-compiler}

<Step label="1">

[Verifique a compatibilidade](https://react.dev/learn/react-compiler#checking-compatibility) do projeto com o React Compiler.

<Terminal
  cmd={{
    npm: ['$ npx react-compiler-healthcheck@latest'],
    yarn: ['$ yarn dlx react-compiler-healthcheck@latest'],
    pnpm: ['$ pnpm dlx react-compiler-healthcheck@latest'],
    bun: ['$ bunx react-compiler-healthcheck@latest'],
  }}
/>

Em geral, essa verificação confirma se o app segue as [**regras do React**](https://react.dev/reference/rules).

</Step>

<Step label="2">

Instale o `babel-plugin-react-compiler` e o runtime do React Compiler no projeto:

<Tabs tabs={['SDK 54 and later', 'SDK 53', 'SDK 52 and earlier']}>
  <Tab>

    O Babel é configurado automaticamente no Expo SDK 54 e versões posteriores.

  </Tab>
  <Tab>
    <Terminal
      cmd={{
        npm: ['$ npx expo install babel-plugin-react-compiler@beta'],
        yarn: ['$ yarn expo install babel-plugin-react-compiler@beta'],
        pnpm: ['$ pnpm expo install babel-plugin-react-compiler@beta'],
        bun: ['$ bun expo install babel-plugin-react-compiler@beta'],
      }}
    />
  </Tab>
  <Tab>
    <Terminal
      cmd={{
        npm: ['$ npx expo install babel-plugin-react-compiler@beta react-compiler-runtime@beta'],
        yarn: ['$ yarn expo install babel-plugin-react-compiler@beta react-compiler-runtime@beta'],
        pnpm: ['$ pnpm expo install babel-plugin-react-compiler@beta react-compiler-runtime@beta'],
        bun: ['$ bun expo install babel-plugin-react-compiler@beta react-compiler-runtime@beta'],
      }}
    />
  </Tab>
</Tabs>

</Step>

<Step label="3">

Ative o experimento do React Compiler no arquivo de configuração do app:

```json app.json
{
  "expo": {
    "experiments": {
      "reactCompiler": true
    }
  }
}
```

</Step>

### Ativando o linter \{#enabling-the-linter}

Execute o [`npx expo lint`](/guides/using-eslint/#eslint) para configurar o ESLint no app e, depois, siga as instruções da sua versão do SDK:

<Tabs tabs={['SDK 55 and later', 'SDK 54 and earlier']}>
  <Tab>

    As regras de lint do React Compiler já vêm incluídas por padrão no `eslint-config-expo` a partir do SDK 55.

    Se você instalou antes o `eslint-plugin-react-compiler`, pode desinstalá-lo e removê-lo da configuração do ESLint.

  </Tab>
  <Tab>

    Instale o plugin do ESLint para o React Compiler:

    <Terminal
      cmd={{
        npm: ['$ npx expo install eslint-plugin-react-compiler -- -D'],
        yarn: ['$ yarn expo install eslint-plugin-react-compiler -- -D'],
        pnpm: ['$ pnpm expo install eslint-plugin-react-compiler -- -D'],
        bun: ['$ bun expo install eslint-plugin-react-compiler -- -D'],
      }}
    />

    Atualize a [configuração do ESLint](/guides/using-eslint/) para incluir o plugin:

    ```js eslint.config.js
    // https://docs.expo.dev/guides/using-eslint/
    const { defineConfig } = require('eslint/config');
    const expoConfig = require('eslint-config-expo/flat');
    const reactCompiler = require('eslint-plugin-react-compiler');

    module.exports = defineConfig([
      expoConfig,
      reactCompiler.configs.recommended,
      {
        ignores: ['dist/*'],
      },
    ]);
    ```

  </Tab>
</Tabs>

## Adoção incremental \{#incremental-adoption}

Você pode adotar o React Compiler de forma incremental no app usando algumas estratégias:

<Step label="1">

Configure o plugin do Babel para rodar apenas em arquivos ou componentes específicos. Para isso:

1. Se o projeto não tiver um [**babel.config.js**](/versions/latest/config/babel/), crie um executando `npx expo customize babel.config.js`.
2. Adicione a seguinte configuração ao **babel.config.js**:

```js babel.config.js
module.exports = function (api) {
  api.cache(true);

  return {
    presets: [
      [
        'babel-preset-expo',
        {
          'react-compiler': {
            sources: filename => {
              // Match file names to include in the React Compiler.
              return filename.includes('src/path/to/dir');
            },
          },
        },
      ],
    ],
  };
};
```

Sempre que você alterar o **babel.config.js**, reinicie o bundler Metro para aplicar as mudanças:

<Terminal
  cmd={{
    npm: ['$ npx expo start --clear'],
    yarn: ['$ yarn expo start --clear'],
    pnpm: ['$ pnpm expo start --clear'],
    bun: ['$ bun expo start --clear'],
  }}
/>

</Step>

<Step label="2">

Use a diretiva `"use no memo"` para desativar o React Compiler em componentes ou arquivos específicos.

```jsx
function MyComponent() {
  'use no memo';

  return <Text>Will not be optimized</Text>;
}
```

</Step>

## Uso \{#usage}

> Para entender melhor como o React Compiler funciona, confira o [React Playground](https://playground.react.dev/).

As melhorias são, em sua maioria, automáticas. Você pode remover instâncias de `useCallback`, `useMemo` e `React.memo` em favor da memoização automática. Componentes de classe não são otimizados. Em vez disso, migre para componentes de função.

A implementação do React Compiler no Expo roda apenas no código do app (sem node modules) e apenas ao fazer o bundle para o cliente (desativada na renderização no servidor).

## Configuração \{#configuration}

Você pode passar configurações adicionais para o plugin do Babel do React Compiler usando o objeto `react-compiler` na configuração do Babel:

```js babel.config.js
module.exports = function (api) {
  api.cache(true);

  return {
    presets: [
      [
        'babel-preset-expo',
        {
          'react-compiler': {
            // Passed directly to the React Compiler Babel plugin.
            compilationMode: 'all',
            panicThreshold: 'all_errors',
          },
          web: {
            'react-compiler': {
              // Web-only settings...
            },
          },
        },
      ],
    ],
  };
};
```
