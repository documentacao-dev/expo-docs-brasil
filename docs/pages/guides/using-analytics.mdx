Um serviço de analytics permite acompanhar como os usuários interagem com o seu app. Com esses dados, você pode melhorar o app com base em medições concretas.

A lista a seguir reúne provedores de analytics comuns no ecossistema Expo e React Native.

> A maioria dos SDKs de analytics exige a configuração de código nativo personalizado. O código nativo não é configurável ao usar o Expo Go. No entanto, você pode criar um [development build](/develop/development-builds/introduction/), que permite usar qualquer um dos serviços abaixo.
