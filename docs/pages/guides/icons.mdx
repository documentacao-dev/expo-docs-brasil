Você pode usar conjuntos de ícones populares por meio de fontes de ícones, como FontAwesome, Glyphicons ou Ionicons, ou escolher PNGs no [The Noun Project](https://thenounproject.com/). Este guia explica as várias formas de usar ícones no app Expo.

## `@expo/vector-icons` \{#expovector-icons}

> **warning** O `@expo/vector-icons` será descontinuado e não é recomendado. [Saiba mais sobre a migração para o `@react-native-vector-icons`](https://expo.dev/blog/moving-away-from-expo-vector-icons).

A biblioteca `@expo/vector-icons` é construída sobre a [`react-native-vector-icons`](https://github.com/oblador/react-native-vector-icons) e usa uma API semelhante. Ela inclui conjuntos de ícones populares, que você pode consultar em [icons.expo.fyi](https://icons.expo.fyi).

No exemplo a seguir, o componente carrega a fonte `Ionicons` e renderiza um ícone de check:

<SnackInline label='Ícones vetoriais' dependencies={['@expo/vector-icons']}>

```jsx collapseHeight=350
import { View, StyleSheet } from 'react-native';
import Ionicons from '@expo/vector-icons/Ionicons';

export default function App() {
  return (
    <View style={styles.container}>
      /* @info */
      <Ionicons name="checkmark-circle" size={32} color="green" />
      /* @end */
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    justifyContent: 'center',
    alignItems: 'center',
  },
});
```

</SnackInline>

> Assim como [qualquer fonte personalizada](/develop/user-interface/fonts/#use-a-local-font-file) no Expo, você pode pré-carregar as fontes de ícones antes de renderizar o app. O objeto da fonte está disponível como propriedade estática do componente de fonte. Assim, no exemplo acima, ele é `Ionicons.font`, que resulta em `{ionicons: require('path/to/ionicons.ttf')}`.

## Fontes de ícones personalizadas \{#custom-icon-fonts}

Para usar uma fonte de ícones personalizada, primeiro importe-a para o projeto. Só depois que a fonte tiver sido carregada você pode criar um conjunto de ícones. [Saiba mais sobre como carregar fontes personalizadas](/develop/user-interface/fonts/#handle-expovector-icons-initial-load).

O `@expo/vector-icons` expõe três métodos para ajudar a criar um conjunto de ícones:

### `createIconSet` \{#createiconset}

O método `createIconSet` retorna uma fonte personalizada com base no `glyphMap`, em que a chave é o nome do ícone e o valor é um caractere UTF-8 ou o código do caractere.

No exemplo abaixo, o objeto `glyphMap` é definido e depois passado como primeiro argumento para o método `createIconSet`. O segundo argumento, `fontFamily`, é o nome da fonte (não o nome do arquivo). Opcionalmente, você pode passar o terceiro argumento para suporte no Android, que é o nome do arquivo da fonte personalizada.

```jsx createIconSet example
import createIconSet from '@expo/vector-icons/createIconSet';

const glyphMap = { 'icon-name': 1234, test: '∆' };
const CustomIcon = createIconSet(glyphMap, 'fontFamily', 'custom-icon-font.ttf');

export default function CustomIconExample() {
  return <CustomIcon name="icon-name" size={32} color="red" />;
}
```

### `createIconSetFromIcoMoon` \{#createiconsetfromicomoon}

O método `createIconSetFromIcoMoon` é usado para criar uma fonte personalizada com base em um arquivo de configuração do [IcoMoon](https://icomoon.io/). Salve o **selection.json** e o **.ttf** no projeto, de preferência no diretório **assets**, e depois carregue a fonte usando o hook `useFonts` ou o método `Font.loadAsync` do `expo-font`.

> **Versões do app IcoMoon:** O [novo app IcoMoon](https://icomoon.io/new-app) exporta um formato JSON diferente do [app IcoMoon antigo](https://icomoon.io/app). A função `createIconSetFromIcoMoon` atual só oferece suporte à saída do app antigo. Veja o [Pull Request no GitHub](https://github.com/expo/vector-icons/pull/356), que adiciona suporte ao novo formato. Esse suporte vai funcionar quando for lançado no `@expo/vector-icons`.

Veja o exemplo abaixo, que usa o hook `useFonts` para carregar a fonte:

```jsx
import React from 'react';
import { View, StyleSheet } from 'react-native';
import { useFonts } from 'expo-font';
import createIconSetFromIcoMoon from '@expo/vector-icons/createIconSetFromIcoMoon';

/* @info */
const Icon = createIconSetFromIcoMoon(
  require('./assets/icomoon/selection.json'),
  'IcoMoon',
  'icomoon.ttf'
);
/* @end */

export default function App() {
  /* @info Load the icon font before using it */
  const [fontsLoaded] = useFonts({
    IcoMoon: require('./assets/icomoon/icomoon.ttf'),
  });
  /* @end */

  // See the "Waiting for fonts to load" section at /develop/user-interface/fonts/#wait-for-fonts-to-load for more information on how to display a splash screen when fonts are loaded.
  if (!fontsLoaded) {
    return null;
  }

  return (
    <View style={styles.container}>
      /* @info */
      <Icon name="pacman" size={50} color="red" />/* @end */
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    justifyContent: 'center',
    alignItems: 'center',
  },
});
```

</SnackInline>

### `createIconSetFromFontello` \{#createiconsetfromfontello}

O método `createIconSetFromFontello` é usado para criar uma fonte personalizada com base em um arquivo de configuração do [Fontello](https://fontello.com/). Salve o **config.json** e o **.ttf** em um lugar conveniente do projeto, de preferência no diretório **assets**, e depois carregue a fonte usando o hook `useFonts` ou o método `Font.loadAsync` do `expo-font`.

Ele segue uma configuração semelhante à de `createIconSetFromIcoMoon`, como mostrado no exemplo:

```js Fontello Icons
// Import the createIconSetFromFontello method
import createIconSetFromFontello from '@expo/vector-icons/createIconSetFromFontello';

// Import the config file
import fontelloConfig from './config.json';

// Both the font name and files exported from Fontello are most likely called "fontello".
// Ensure this is the `fontname.ttf` and not the file path.
const Icon = createIconSetFromFontello(fontelloConfig, 'fontello', 'fontello.ttf');
```

## Componente de botão \{#button-component}

Você pode criar um botão com ícone usando a sintaxe `Font.Button`, em que `Font` é o conjunto de ícones importado de `@expo/vector-icons`.

No exemplo abaixo, um botão de login usa o conjunto de ícones `FontAwesome`. Repare que o componente `FontAwesome.Button` aceita props para tratar a ação quando o botão é pressionado e pode quebrar o texto do botão em linhas.

<SnackInline label='Componente de botão com ícone' dependencies={['@expo/vector-icons']}>

```jsx
import React from 'react';
import { View, StyleSheet } from 'react-native';
import FontAwesome from '@expo/vector-icons/FontAwesome';

export default function App() {
  const loginWithFacebook = () => {
    console.log('Button pressed');
  };

  return (
    <View style={styles.container}>
      <FontAwesome.Button name="facebook" backgroundColor="#3b5998" onPress={loginWithFacebook}>
        Login with Facebook
      </FontAwesome.Button>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    justifyContent: 'center',
    alignItems: 'center',
  },
});
```

</SnackInline>

### Propriedades \{#properties}

Qualquer propriedade de [`Text`](https://reactnative.dev/docs/text), [`TouchableHighlight`](https://reactnative.dev/docs/touchablehighlight) ou [`TouchableWithoutFeedback`](https://reactnative.dev/docs/touchablewithoutfeedback), além destas:

| Prop              | Descrição                                                                                                                                              | Padrão              |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------- |
| `color`           | Cor do texto e do ícone. Use `iconStyle` ou aninhe um componente `Text` se precisar de cores diferentes.                                               | `white`             |
| `size`            | Tamanho do ícone.                                                                                                                                      | `20`                |
| `iconStyle`       | Estilos aplicados somente ao ícone, úteis para definir margens ou uma cor diferente. _Observação: use `iconStyle` para margens, ou o comportamento pode ficar instável._ | `{marginRight: 10}` |
| `backgroundColor` | Cor de fundo do botão.                                                                                                                                 | `#007AFF`           |
| `borderRadius`    | Raio da borda do botão. Defina como `0` para desativar.                                                                                                | `5`                 |
| `onPress`         | Função chamada quando o botão é pressionado.                                                                                                           | _Nenhum_            |
