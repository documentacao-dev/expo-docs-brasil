O [Sentry](https://getsentry.com/) é uma plataforma de relatório de falhas que oferece **visibilidade em tempo real sobre os deploys de produção, com informações para reproduzir e corrigir as falhas**.

Ele avisa sobre as exceções e os erros que os usuários encontram ao usar seu app e os organiza em um painel web. As exceções reportadas incluem stack traces, informações do dispositivo, versão e outros contextos relevantes, automaticamente. Você também pode fornecer contexto adicional específico do seu app, como a rota atual e o ID do usuário.

## O que você vai aprender \{#what-youll-learn}

Este guia cobre três aspectos principais da integração do Sentry com seus projetos Expo:

- [Instalar e configurar o Sentry](#install-and-configure-sentry) no seu app React Native

- Usando o Sentry com os Expo Services:
  - [Expo Build](#usage-with-expo-build) para gerar o seu app
  - [Expo Update](#usage-with-expo-update) para updates over-the-air (OTA)

- [Configurar a integração Sentry-Expo](#sentry-integration-with-expo-dashboard) para ver relatórios de falhas e Session Replays diretamente no seu dashboard do Expo

## Instalar e configurar o Sentry \{#install-and-configure-sentry}

<Step label="1">

### Crie uma conta no Sentry e um projeto \{#sign-up-for-a-sentry-account-and-create-a-project}

Antes de instalar o Sentry, você precisa ter uma conta e um projeto no Sentry:

<Step label="1.1">

[Crie uma conta no Sentry](https://sentry.io/signup/) (o plano gratuito suporta até 5.000 eventos por mês) e crie um projeto no seu
Dashboard. Anote o seu **organization slug**, o **nome do projeto** e o **DSN**, pois você vai
precisar deles depois:

- O **organization slug** fica na aba **Organization settings**
- O **nome do projeto** fica em **Settings** > **Projects** nas configurações do seu projeto (procure-o na lista)
- O **DSN** fica em **Settings** > **Projects** > **Nome do projeto** > na seção **SDK Setup**, na aba **Client Keys (DSN)**.

</Step>

<Step label="1.2">

Acesse a página [Developer Settings > Auth Tokens](https://sentry.io/settings/auth-tokens/) e crie um novo [Organization Auth Token](https://docs.sentry.io/account/auth-tokens/#organization-auth-tokens). O token já vem com escopo para upload de source maps e criação de releases. Salve-o.

</Step>

Quando você tiver todos estes itens: **organization slug**, **nome do projeto**, **DSN** e **auth token**, está tudo pronto para continuar.

</Step>

<Step label="2">

### Use o assistente do Sentry para configurar o projeto \{#use-the-sentry-wizard-to-set-up-your-project}

A forma mais fácil de configurar o Sentry no seu projeto Expo é usar o assistente do Sentry. Essa ferramenta configura o seu projeto automaticamente com as definições certas.

Execute o comando a seguir no diretório do seu projeto:

<Terminal
  cmd={{
    npm: ['$ npx @sentry/wizard@latest -i reactNative'],
    yarn: ['$ yarn dlx @sentry/wizard@latest -i reactNative'],
    pnpm: ['$ pnpm dlx @sentry/wizard@latest -i reactNative'],
    bun: ['$ bunx @sentry/wizard@latest -i reactNative'],
  }}
/>

O assistente vai:

- Instalar as dependências necessárias
- Configurar o seu projeto para usar o Sentry
- Configurar o Metro automaticamente
- Adicionar o código de inicialização necessário ao seu app

Siga as instruções do assistente para concluir a configuração. Ele vai orientar você a fazer login na sua conta do Sentry e buscar todas as informações corretas sobre o seu projeto.

</Step>

<Step label="3">

### Verifique a configuração \{#verify-the-configuration}

Crie um novo release build do seu app e confirme que ele envia os source maps corretamente. Talvez você queira adicionar um botão no app para testar se tudo está funcionando e se os sourcemaps estão configurados como esperado, por exemplo:

```jsx

```

</Step>

## Uso com o Expo Build \{#usage-with-expo-build}

Confirme que `SENTRY_AUTH_TOKEN` esteja definido no ambiente de build com [visibilidade sensível](/eas/environment-variables/#visibility-settings-for-environment-variables). O Sentry vai enviar os source maps automaticamente. Se você usa variáveis de ambiente em vez de propriedades no app config, confirme que elas também estão definidas.

Seguindo as instruções acima, nenhum trabalho adicional é necessário para integrar o Sentry ao seu projeto ao usar o Expo Build.

## Uso com o Expo Update \{#usage-with-expo-update}

Depois de executar `eas update`, envie os source maps para o Sentry:

<Terminal
  cmd={{
    npm: [
      '# Pass in the "dist" directory generated by `eas update` to the upload script',
      '$ npx sentry-expo-upload-sourcemaps dist',
    ],
    yarn: [
      '# Pass in the "dist" directory generated by `eas update` to the upload script',
      '$ yarn dlx sentry-expo-upload-sourcemaps dist',
    ],
    pnpm: [
      '# Pass in the "dist" directory generated by `eas update` to the upload script',
      '$ pnpm dlx sentry-expo-upload-sourcemaps dist',
    ],
    bun: [
      '# Pass in the "dist" directory generated by `eas update` to the upload script',
      '$ bunx sentry-expo-upload-sourcemaps dist',
    ],
  }}
/>

O script de upload lê o slug da organização e o nome do projeto das propriedades `organization` e `project` do plugin `@sentry/react-native/expo` no seu app config, ou das variáveis de ambiente `SENTRY_ORG` e `SENTRY_PROJECT`. Ele também precisa de `SENTRY_AUTH_TOKEN`. Ao executá-lo no Expo Workflows ou em outro CI, confirme que esses valores estão disponíveis por lá.

Pronto! Os erros dos seus updates agora vão aparecer com os nomes de arquivo e de linha originais no Sentry.

<Collapsible summary="Quer publicar um update e os source maps em um único comando?">

Você pode encadear os comandos com `&&` para publicar um update e enviar os source maps em um só passo:

<Terminal cmd={['$ eas update --branch <branch> && npx sentry-expo-upload-sourcemaps dist']} />

</Collapsible>

<Collapsible summary="Quer adicionar metadados do update aos relatórios de erro?">

Configurar o Sentry para marcar o escopo com informações sobre o seu update permite ver os erros que acontecem em determinados updates no dashboard do Sentry.

Adicione o trecho a seguir no escopo global, o mais cedo possível no ciclo de vida do seu app.

```js
import * as Sentry from '@sentry/react-native';
import * as Updates from 'expo-updates';

const manifest = Updates.manifest;
const metadata = 'metadata' in manifest ? manifest.metadata : undefined;
const extra = 'extra' in manifest ? manifest.extra : undefined;
const updateGroup = metadata && 'updateGroup' in metadata ? metadata.updateGroup : undefined;

Sentry.init({
  // dsn, release, dist, etc...
});

const scope = Sentry.getGlobalScope();

scope.setTag('expo-update-id', Updates.updateId);
scope.setTag('expo-is-embedded-update', Updates.isEmbeddedLaunch);

if (typeof updateGroup === 'string') {
  scope.setTag('expo-update-group-id', updateGroup);

  const owner = extra?.expoClient?.owner ?? '[account]';
  const slug = extra?.expoClient?.slug ?? '[project]';
  scope.setTag(
    'expo-update-debug-url',
    `https://expo.dev/accounts/${owner}/projects/${slug}/updates/${updateGroup}`
  );
} else if (Updates.isEmbeddedLaunch) {
  // This will be `true` if the update is the one embedded in the build, and not one downloaded from the updates server.
  scope.setTag('expo-update-debug-url', 'not applicable for embedded updates');
}
```

Depois de configurar, as informações sobre o update associado aparecem na seção de tags do erro:

<ContentSpotlight alt="Tags de update no Sentry" src="/static/images/guides/sentry-tags.webp" />

</Collapsible>

## Integração do Sentry com o dashboard do Expo \{#sentry-integration-with-expo-dashboard}

A integração do Sentry com o Expo permite ver relatórios de falhas e Session Replays dos deploys do seu app Expo diretamente no dashboard do Expo. Essa integração oferece um link direto para os stack traces do Sentry, com contexto completo, Session Replays e recursos de debug.

### Instalar \{#install}

> **info** É necessário ter permissões de owner, manager ou admin no Sentry para instalar esta integração.

1. Faça login na sua conta do Expo e abra [**Account settings > Overview**](https://expo.dev/accounts/[your-account]/settings).
2. Em **Connections**, clique em **Connect** ao lado de Sentry.
3. Faça login na sua conta do Sentry e aceite a integração na sua organização. Você será redirecionado de volta para **Account settings**.

### Vincular o seu projeto \{#link-your-project}

Depois de conectar suas contas, você precisa vincular o seu projeto dos Expo Services ao seu projeto no Sentry:

1. Abra **Projects > [Seu projeto] > Configuration > Project settings** no dashboard do Expo.
2. Clique em **Link** e selecione o seu projeto do Sentry na lista suspensa.

### Uso \{#usage}

Para ver os seus dados do Sentry no dashboard do Expo, abra **Projects > [Seu projeto] > Updates > Deployments > [Deployment]** para ver os dados do Sentry de uma release.

Com essa integração, você pode:

- Ver relatórios de falhas diretamente no dashboard do Expo
- Acessar Session Replays para ver exatamente o que aconteceu antes de um erro
- Obter stack traces detalhados com contexto completo
- Navegar facilmente entre o dashboard do Expo e o Sentry para fazer debug
