Para criar o build de release (também chamado de build de produção) do app localmente, você precisa seguir etapas separadas no computador e usar as ferramentas necessárias para criar qualquer app nativo. Este guia traz as etapas necessárias para Android e iOS.

## Android \{#android}

Criar um build de release localmente para Android exige assiná-lo com uma [chave de upload](https://developer.android.com/studio/publish/app-signing#certificates-keystores) e gerar um Android Application Bundle (**.aab**). Siga as etapas abaixo:

<Prerequisites>
  <Requirement title="OpenJDK instalado">
    Instale uma [distribuição do OpenJDK](/get-started/set-up-your-environment/?mode=development-build&buildEnv=local#install-jdk)
    para ter acesso ao comando `keytool`.
  </Requirement>
  <Requirement title="Diretório android gerado">
    Se você estiver usando o [Continuous Native Generation (CNG)](/workflow/continuous-native-generation/),
    execute `npx expo prebuild` para gerá-lo.
  </Requirement>
</Prerequisites>

<Step label="1">

### Crie uma chave de upload \{#create-an-upload-key}

<Collapsible summary="Já criou um build com o Expo Build? Baixe as credenciais e pule para a próxima etapa.">

Se você já criou um build com o Expo Build, siga as etapas abaixo para baixar as credenciais, que incluem a chave de upload e a senha dela, o alias da chave e a senha da chave:

1. No terminal, execute `eas credentials -p android` e selecione o perfil de build.
2. Selecione **credentials.json** > **Download credentials from EAS to credentials.json**.
3. Mova o arquivo **keystore.jks** baixado para o diretório **android/app**.
4. Copie os valores da senha do keystore de upload, do alias da chave e da senha da chave, do **credentials.json**, pois você vai precisar deles na próxima etapa.

</Collapsible>

Dentro do diretório do projeto Expo, execute o comando `keytool` a seguir para criar uma chave de upload:

<Terminal
  cmd={[
    '$ sudo keytool -genkey -v -keystore my-upload-key.keystore -alias my-key-alias -keyalg RSA -keysize 2048 -validity 10000',
  ]}
/>

Depois de executar esse comando, será solicitado que você informe uma senha para o keystore. Essa senha vai proteger a chave de upload. Guarde a senha que você digitar aqui, porque vai precisar dela na próxima etapa.

Esse comando também gera o arquivo de keystore chamado **my-upload-key.keystore** no diretório do projeto. Mova-o para o diretório **android/app**.

> **warning** Se você versionar o diretório **android** em um sistema de controle de versão como o Git, não faça commit deste arquivo de keystore. Ele contém sua chave de upload e deve ser mantido em sigilo.

</Step>

<Step label="2">

### Atualize as variáveis do gradle \{#update-gradle-variables}

Abra o arquivo **android/gradle.properties** e adicione as variáveis do gradle a seguir no final do arquivo. Substitua os `*****` pela senha do keystore e pela senha da chave corretas, que você informou na etapa anterior.

Essas variáveis contêm informações sobre sua chave de upload:

```ruby android/gradle.properties
# If you've downloaded the credentials from `eas credentials` command, see comments below for each value.

# Path to the "keystore" file
MYAPP_UPLOAD_STORE_FILE=my-upload-key.keystore
# Replace with value of the `keystore.keyAlias` field in the credentials.json file
MYAPP_UPLOAD_KEY_ALIAS=my-key-alias
# Replace with value of the `keystore.password` field in the credentials.json file
MYAPP_UPLOAD_STORE_PASSWORD=*****
# Replace with value of the `keystore.keyPassword` field in the credentials.json file
MYAPP_UPLOAD_KEY_PASSWORD=*****
```

> **warning** Se você versionar o diretório **android** com o Git, não faça commit das informações acima. Em vez disso, crie um arquivo **~/.gradle/gradle.properties** no computador e adicione as variáveis acima a esse arquivo.

</Step>

<Step label="4">

### Gere o Android Application Bundle (aab) de release \{#generate-release-android-application-bundle-aab}

Entre no diretório **android** e crie um build de release no formato **.aab** executando o comando `bundleRelease` do Gradle:

<Terminal
  cmd={['$ cd android', '', '$ ./gradlew app:bundleRelease']}
  cmdCopy="cd android && ./gradlew app:bundleRelease"
/>

Esse comando vai gerar o arquivo app-release.aab dentro do diretório **android/app/build/outputs/bundle/release**.

</Step>

<Step label="5">

### Envio do app para o Google Play Console \{#app-submission-to-google-play-console}
