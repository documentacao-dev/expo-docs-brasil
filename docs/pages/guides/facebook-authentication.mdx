A biblioteca [`react-native-fbsdk-next`](https://github.com/thebergamo/react-native-fbsdk-next/) oferece um wrapper para os SDKs nativos do Facebook para Android e iOS. Ela permite integrar a autenticação do Facebook ao projeto Expo e acessar componentes nativos.

Este guia traz informações adicionais sobre como configurar a biblioteca com o Expo para Android.

<Prerequisites>
  <Requirement title="Um development build">
    A biblioteca `react-native-fbsdk-next` não pode ser usada no Expo Go porque exige código nativo personalizado. Saiba mais sobre [como adicionar código nativo personalizado ao seu app](/workflow/customizing/).
  </Requirement>
</Prerequisites>

## Configuração para Android \{#configuration-for-android}

Para adicionar o Android como plataforma no seu projeto do Facebook, é preciso que o app tenha sido aprovado pela Google Play Store, para ter uma URL válida da loja e o [`package`](/versions/latest/config/app/#package) associado ao app. Caso contrário, você vai ver o seguinte erro:

<ContentSpotlight
  alt="Projeto do Facebook não reconhece o package de um app Android não publicado, que não tem uma URL válida da Google Play Store."
  src="/static/images/guides/android-package-error.webp"
  className="max-w-[720px]"
/>

Veja os guias a seguir para saber mais sobre como gerar o build do projeto para as lojas de apps:

<BoxLink
  title="Gere o build do projeto para as lojas de apps"
  href="/deploy/build-project/"
  Icon={Rocket01Icon}
/>

<BoxLink
  title="Envie para a Google Play Store com o Expo Submit"
  href="/submit/android/"
  Icon={EasSubmitIcon}
/>

Depois de enviar o app para a Play Store, você pode enviar o app para revisão. Quando ela for aprovada, o projeto do Facebook poderá acessá-lo em uma URL da Play Store.

Depois disso, vá em **Settings** > **Basic** do seu projeto do Facebook e adicione a plataforma **Android**. Você vai precisar informar o Key hash, o Package name e o Class name.

<ContentSpotlight
  alt="Campos obrigatórios para adicionar a plataforma Android no projeto do Facebook."
  src="/static/images/guides/android-required-fields.webp"
  className="max-w-[720px]"
/>

- Para adicionar o Key hash, acesse o console da Play Store para obter a impressão digital do certificado SHA-1 em **Release** > **Setup** > **App Integrity** > **App signing key certificate**. Depois, [converta o valor hexadecimal do certificado para Base64](https://base64.guru/converter/encode/hex) e adicione-o em **Android** > **Key hashes** no seu projeto do Facebook.
- Você pode encontrar o Package name no seu [app config](/versions/latest/config/app) no campo [`android.package`](/versions/latest/config/app/#package).
- O Class name é `MainActivity` por padrão, e você pode usar `package.MainActivity`, em que `package` é o `android.package` no app config do projeto. Por exemplo, `com.myapp.example.MainActivity`, em que `com.myapp.example` é o `package` do seu app.
- Depois, clique em **Save changes** para salvar a configuração.

Agora você pode usar o projeto do Facebook em development builds, release builds e apps em produção.
