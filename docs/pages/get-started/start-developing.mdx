## Iniciar o servidor de desenvolvimento \{#start-a-development-server}
Para iniciar o servidor de desenvolvimento, execute o comando a seguir:

<Terminal
  cmd={{
    npm: ['$ npx expo start'],
    yarn: ['$ yarn expo start'],
    pnpm: ['$ pnpm expo start'],
    bun: ['$ bun expo start'],
  }}
/>

</Step>

<Step label="2">
## Abra o app no seu aparelho \{#open-the-app-on-your-device}

Depois de executar o comando acima, você verá um QR code no terminal. Escaneie esse QR code para abrir o app no seu aparelho.

Se você estiver usando um Android Emulator ou um iOS Simulator, pressione <kbd>A</kbd> ou <kbd>I</kbd>, respectivamente, para abrir o app.

> **info** **Usando o Expo Go em um aparelho iOS físico?** O Expo Go só abre seu projeto quando o Expo CLI e o Expo Go estão conectados à mesma conta Expo. Execute `npx expo login` no seu computador e depois entre no Expo Go com a mesma conta. Veja [Configurar seu ambiente](/get-started/set-up-your-environment/?platform=ios&device=physical&mode=expo-go).

<Collapsible summary="Está com problemas?">

Verifique se o computador e o aparelho estão na mesma rede Wi-Fi.

Se aparecer um erro sobre contas em um aparelho iOS físico, a mensagem indica o que corrigir. Para entrar no Expo CLI, execute `npx expo login` no seu computador. Para entrar no Expo Go, toque no ícone de conta no canto superior direito. Use a mesma conta nos dois, depois toque em **Try Again**. Veja [Login necessário no Expo Go](/troubleshooting/expo-go-sign-in-required/) para todas as mensagens.

Se ainda não funcionar, pode ser por causa da configuração do roteador, o que é comum em redes públicas. Você pode contornar isso escolhendo o tipo de conexão **Tunnel** ao iniciar o servidor de desenvolvimento e escaneando o QR code de novo.

<Terminal
  cmd={{
    npm: ['$ npx expo start --tunnel'],
    yarn: ['$ yarn expo start --tunnel'],
    pnpm: ['$ pnpm expo start --tunnel'],
    bun: ['$ bun expo start --tunnel'],
  }}
/>

> Usar o tipo de conexão **Tunnel** deixa os recarregamentos do app bem mais lentos do que em **LAN** ou **Local**, então evite o tunnel sempre que possível. Se for necessário usar o **Tunnel** para acessar seu computador a partir de outro aparelho da rede, talvez seja bom instalar e usar um emulador ou simulador para acelerar o desenvolvimento.

</Collapsible>

</Step>

<Collapsible summary="As mudanças não aparecem no seu aparelho?">

O Expo Go já vem configurado para recarregar o app automaticamente sempre que um arquivo muda. Mesmo assim, vamos revisar os passos para ativar isso, caso algo não esteja funcionando.

- Verifique se o [modo de desenvolvimento está ativado no Expo CLI](/workflow/development-mode#development-mode).
- Feche o app Expo e abra-o de novo.
- Com o app aberto de novo, sacuda o aparelho para abrir o menu do desenvolvedor. Pressione <kbd>Cmd ⌘</kbd> + <kbd>D</kbd>.
- Se o **Fast Refresh** estiver ativado, alterne a opção. Se aparecer **Disable Fast Refresh**, feche o menu do desenvolvedor. Depois, tente fazer outra alteração.
