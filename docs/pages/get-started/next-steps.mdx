Estes são os próximos passos para continuar desenvolvendo seu app:

### Redefinir seu projeto \{#reset-your-project}

Você pode remover o código de exemplo e começar do zero com um projeto novo. Execute o comando a seguir para redefinir seu projeto:

<Terminal
  cmd={{
    npm: ['$ npm run reset-project'],
    yarn: ['$ yarn run reset-project'],
    pnpm: ['$ pnpm run reset-project'],
    bun: ['$ bun run reset-project'],
  }}
/>

Esse comando pergunta se você quer mover os diretórios **src** e **scripts** existentes para **example** ou excluí-los. Em seguida, ele cria um novo diretório **src/app** com os arquivos **index.tsx** e **\_layout.tsx**.

### Desenvolver, revisar e publicar \{#develop-review-and-deploy}

Aprenda a desenvolver lendo a documentação da seção Develop. Você vai aprender a criar [elementos de UI](/develop/user-interface/splash-screen-and-app-icon/), adicionar [testes unitários](/develop/unit-testing/), incluir [módulos nativos](/config-plugins/introduction/) e muito mais.

Depois de desenvolver seu app, você pode compartilhá-lo com sua equipe para [revisão](/review/overview).

Por fim, você pode fazer o [build](/deploy/build-project/) e [enviar](/deploy/submit-to-app-stores/) seu projeto para as lojas de apps.

### Guia passo a passo \{#step-by-step-guide}

Para um passo a passo guiado de como criar um app com Expo do início ao fim, confira o [tutorial](/tutorial/introduction/).
