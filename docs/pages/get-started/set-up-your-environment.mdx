## Onde você quer desenvolver?

Recomendamos desenvolver em um aparelho real, já que você vai ver exatamente o que seus usuários vão ver.

## Como você quer desenvolver?

O Expo Go é um playground para estudantes e iniciantes testarem o Expo rapidamente. Um development build é uma versão do seu próprio app que inclui as ferramentas de desenvolvimento do Expo.
