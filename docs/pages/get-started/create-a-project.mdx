O Expo é um framework React Native que facilita o desenvolvimento de apps para Android e iOS. Nosso framework oferece roteamento baseado em arquivos, uma biblioteca padrão de módulos nativos e muito mais. O Expo é open source e tem uma comunidade ativa no [GitHub](https://github.com/expo/expo) e no [Discord](https://chat.expo.dev).

Também oferecemos os [Expo Services](https://expo.dev/services), um conjunto de serviços que complementam o framework Expo em cada etapa do processo de desenvolvimento.

> **info** **Está começando a programar?** Você pode criar seu primeiro app Expo pedindo a um agente de IA de programação, em vez de escrever código. Siga o [tutorial Build with AI](/tutorial/build-with-ai/introduction/). Ele cobre a configuração do zero.

## Requisitos do sistema \{#system-requirements}

- [Node.js (LTS)](https://nodejs.org/en/).
- macOS, Windows (PowerShell e [WSL 2](https://expo.fyi/wsl)) e Linux são compatíveis.

## Começar com o projeto padrão \{#start-with-a-default-project}

Recomendamos começar com o projeto padrão criado pelo [`create-expo-app`](/more/create-expo/). O projeto padrão inclui código de exemplo para ajudar você a começar.

Para criar um novo projeto, execute o comando a seguir:

<Terminal
  cmd={{
    npm: ['$ npx create-expo-app@latest'],
    yarn: ['$ yarn create expo-app'],
    pnpm: ['$ pnpm create expo-app'],
    bun: ['$ bun create expo'],
  }}
/>

> Você pode escolher outro template adicionando a [opção `--template`](/more/create-expo/#--template).

## Começar a partir de um exemplo \{#start-from-an-example}

Em vez do projeto padrão, você pode começar a partir de um dos [exemplos do Expo](https://github.com/expo/examples). São apps pequenos, cada um demonstrando um recurso ou integração específica, como Expo Router, Expo Widgets ou uma tela de câmera.

Para ver a lista completa e escolher um exemplo de forma interativa, execute `create-expo-app` com a opção [`--example`](/more/create-expo/#--example) e sem nome:

<Terminal
  cmd={{
    npm: ['$ npx create-expo-app@latest --example'],
    yarn: ['$ yarn create expo-app --example'],
    pnpm: ['$ pnpm create expo-app --example'],
    bun: ['$ bun create expo --example'],
  }}
/>

Para criar um exemplo específico diretamente, informe o nome dele:

<Terminal
  cmd={{
    npm: ['$ npx create-expo-app@latest --example with-widgets'],
    yarn: ['$ yarn create expo-app --example with-widgets'],
    pnpm: ['$ pnpm create expo-app --example with-widgets'],
    bun: ['$ bun create expo --example with-widgets'],
  }}
/>

> **info** Os demais guias desta seção **"Primeiros passos"** seguem o projeto padrão. Um app de exemplo pode ser organizado de outra forma, mas os conceitos são os mesmos.

## Configurar um agente de IA \{#set-up-an-ai-agent}

Um projeto novo inclui o **AGENTS.md**, com o contexto do projeto para agentes de IA. Quando o Claude Code está instalado, o projeto também inclui o **.claude/settings.json**, que ativa o plugin do Expo. Claude Code e Codex têm um plugin oficial do Expo. Com um único comando, você instala as [Expo Skills](/skills/) e registra o [servidor Expo Model Context Protocol (MCP)](/mcp/):

<Tabs>

<Tab label="Claude Code">

<Terminal cmd={['$ claude plugin install expo@claude-plugins-official']} />

Depois, execute `/mcp` dentro da sessão do Claude Code para entrar na sua conta Expo.

</Tab>

<Tab label="Codex">

<Terminal cmd={['$ codex plugin add expo@openai-curated']} />

Depois, entre na sua conta Expo:

<Terminal cmd={['$ codex mcp login expo']} />

</Tab>

</Tabs>

O plugin também instala a skill que ensina ao agente onde ficam os arquivos em um projeto Expo novo:

<RelatedSkills names={['expo-project-structure']} />

Para o Cursor e outros agentes, instale separadamente as [Expo Skills](/skills/) e o [servidor MCP do Expo](/mcp/). A visão geral [Agentes de IA e Expo](/agents/) explica a configuração de cada agente.
