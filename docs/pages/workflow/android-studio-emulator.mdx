## Solução de problemas

### Várias versões do `adb`

Ter várias versões do `adb` no sistema pode resultar no seguinte erro:

<Terminal cmd={["$ adb server version (xx) doesn't match this client (xx); killing..."]} />

Isso acontece porque a versão do `adb` no seu sistema é diferente da versão do `adb` nas platform-tools do Android SDK.

<Step label="1">
Abra o terminal e verifique a versão do `adb` no sistema:

<Terminal cmd={['$ adb version']} />
</Step>

<Step label="2">
Em seguida, no diretório platform-tools do Android SDK:

<Terminal cmd={[
  '$ cd ~/Library/Android/sdk/platform-tools',
  '$ ./adb version'
]} cmdCopy="cd ~/Library/Android/sdk/platform-tools && ./adb version" />
</Step>

<Step label="3">
Copie o `adb` do diretório do Android SDK para o diretório `usr/bin`:

<Terminal cmd={['$ sudo cp ~/Library/Android/sdk/platform-tools/adb /usr/bin']} />
</Step>

### Como instalo uma versão específica do Expo Go?

Você pode criar um projeto com a versão de SDK desejada e abri-lo em um simulador para instalar a versão correspondente do Expo Go.

<Terminal
  cmd={{
    npm: [
      '# Bootstrap an SDK 58 project',
      '$ npx create-expo-app --template blank@58',
      '',
      '# Open the app on a simulator to install the required Expo Go app',
      '$ npx expo start --android',
    ],
    yarn: [
      '# Bootstrap an SDK 58 project',
      '$ yarn create expo-app --template blank@58',
      '',
      '# Open the app on a simulator to install the required Expo Go app',
      '$ yarn expo start --android',
    ],
    pnpm: [
      '# Bootstrap an SDK 58 project',
      '$ pnpm create expo-app --template blank@58',
      '',
      '# Open the app on a simulator to install the required Expo Go app',
      '$ pnpm expo start --android',
    ],
    bun: [
      '# Bootstrap an SDK 58 project',
      '$ bun create expo --template blank@58',
      '',
      '# Open the app on a simulator to install the required Expo Go app',
      '$ bun expo start --android',
    ],
  }}
/>

Como alternativa, você pode baixar uma versão específica do Expo Go com a [CLI `expo-go`](https://www.npmjs.com/package/expo-go), passando uma versão de SDK, ou usar `latest` para a versão mais recente do SDK. Esse comando baixa o app Expo Go para o diretório atual e o guarda em cache em **~/.expo**.

<Terminal
  cmd={{
    npm: ['$ npx expo-go download android latest'],
    yarn: ['$ yarn dlx expo-go download android latest'],
    pnpm: ['$ pnpm dlx expo-go download android latest'],
    bun: ['$ bunx expo-go download android latest'],
  }}
/>
