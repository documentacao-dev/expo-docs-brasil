O Expo tem suporte de primeira classe para criar sites full-stack com React. Os sites Expo podem ser [renderizados estaticamente](/router/web/static-rendering) para SEO e desempenho, ou renderizados no cliente para uma experiência mais parecida com a de um app no navegador.

<Tabs>

<Tab label="Universal">

    Renderize texto em qualquer plataforma com o componente `<Text>` do [React Native for web](https://github.com/necolas/react-native-web).

    ```jsx app/index.js
    import { Text } from 'react-native';

    export default function Page() {
      return <Text>Home page</Text>;
    }
    ```

    O React Native for web (RNW) é um conjunto de bibliotecas de componentes, como `<View>` e `<Text>`, que envolvem primitivas do `react-dom`, como `<div>`, `<p>` e `<img>`. O RNW é opcional no desenvolvimento para web, já que você pode usar o React DOM diretamente, mas costumamos recomendá-lo ao criar para várias plataformas, pois ele maximiza o reaproveitamento de código.

    > O React Native for web é usado para alimentar todo o site do [X](https://x.com/).

</Tab>

<Tab label="Somente web">

    Como alternativa, você pode escrever componentes do React DOM somente para web, como `<div>`, `<p>` e assim por diante. No entanto, esses componentes não serão renderizados em plataformas nativas.

    ```jsx app/index.js
    export default function Page() {
      return <p>Home page</p>;
    }
    ```

    O Expo oferece suporte completo à criação de componentes somente para web. Porém, você pode querer organizar o seu código para dar suporte melhor à criação simultânea para web e plataformas nativas. Saiba mais em [módulos específicos de plataforma](/router/advanced/platform-specific-modules).

</Tab>

</Tabs>

Todas as bibliotecas do SDK do Expo são criadas para oferecer suporte a ambientes de renderização no navegador e no servidor (quando aplicável). As bibliotecas também são otimizadas para as plataformas individuais às quais se destinam.

Recursos de desenvolvimento como Fast Refresh, depuração, variáveis de ambiente e [bundling](/guides/customizing-metro) também são totalmente universais, o que proporciona uma experiência de desenvolvimento unificada. A CLI do Expo **otimiza automaticamente o código** para cada plataforma quando você faz o build para produção, usando técnicas como o [platform shaking](/guides/tree-shaking#platform-shaking).

## Primeiros passos

### Instale as dependências da web

<Terminal
  cmd={{
    npm: ['$ npx expo install react-dom react-native-web @expo/metro-runtime'],
    yarn: ['$ yarn expo install react-dom react-native-web @expo/metro-runtime'],
    pnpm: ['$ pnpm expo install react-dom react-native-web @expo/metro-runtime'],
    bun: ['$ bun expo install react-dom react-native-web @expo/metro-runtime'],
  }}
/>

<Collapsible summary={<>Not using the <CODE>expo</CODE> package in your app yet?</>}>

Se você ainda não adicionou o Expo ao seu app React Native, pode [instalar os módulos do Expo](/bare/installing-expo-modules/) (recomendado) ou apenas instalar o pacote `expo` e configurar o arquivo de entrada do app. Isso permitirá que você tenha como alvo a web, mas não incluirá suporte ao SDK do Expo.

1. Instale a [CLI do Expo](/more/expo-cli/) no seu projeto:

<Terminal
  cmd={{
    npm: ['$ npm install expo'],
    yarn: ['$ yarn add expo'],
    pnpm: ['$ pnpm add expo'],
    bun: ['$ bun add expo'],
  }}
/>

2. Modifique o arquivo de entrada para usar o [`registerRootComponent`](/versions/latest/sdk/expo/#registerrootcomponentcomponent) em vez de `AppRegistry.registerComponent`:

<DiffBlock
  raw={`diff --git a/index.js b/index.js
--- a/index.js
+++ b/index.js
@@ -1,5 +1,4 @@
-import {AppRegistry} from 'react-native';
-import {name as appName} from './app.json';
+import {registerRootComponent} from 'expo';
import App from './App';

-AppRegistry.registerComponent(appName, () => App);
+registerRootComponent(App);`}
/>

</Collapsible>

### Inicie o servidor de desenvolvimento

Agora você pode iniciar o servidor de desenvolvimento e desenvolver no navegador com:

<Terminal
  cmd={{
    npm: ['$ npx expo start --web'],
    yarn: ['$ yarn expo start --web'],
    pnpm: ['$ pnpm expo start --web'],
    bun: ['$ bun expo start --web'],
  }}
/>

O app pode ser exportado como um site de produção com:

<Terminal
  cmd={{
    npm: ['$ npx expo export --platform web'],
    yarn: ['$ yarn expo export --platform web'],
    pnpm: ['$ pnpm expo export --platform web'],
    bun: ['$ bun expo export --platform web'],
  }}
/>
