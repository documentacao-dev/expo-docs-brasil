> **info** Recomendamos atualizar as versões do SDK de forma incremental, uma por vez. Assim, fica mais fácil identificar as quebras e os problemas que surgem durante o processo de atualização.

Com o lançamento de um novo SDK, a versão mais recente passa a ter o status de versão atual. Isso vale para o Expo Go, que só oferece suporte à versão mais recente do SDK, e as versões anteriores deixam de ter suporte. Recomendamos usar [development builds](/develop/development-builds/introduction/) para apps em produção, porque a compatibilidade com versões antigas do SDK nos Serviços do Expo tende a durar bem mais, mas não para sempre.

Se você quiser instalar uma versão específica do Expo Go em um dispositivo Android, no Emulador Android ou no Simulador do iOS, acesse [expo.dev/go](https://expo.dev/go) ou use a [CLI `expo-go`](/develop/tools/#expo-go-cli). Veja [Solucione uma incompatibilidade de versão do Expo Go](/troubleshooting/expo-go-version-mismatch/) para mais informações.

## Como atualizar para a versão mais recente do SDK

### Atualize com um agente de IA de programação

Se você usa um agente de IA de programação, instale as [Skills do Expo](/skills/) e use a skill [`expo-upgrade`](/skills/#available-expo-skills). A skill oferece diretrizes para atualizar as versões do SDK do Expo e corrigir problemas de dependências. Revise todas as alterações propostas e consulte o changelog do SDK para instruções específicas de cada versão.

### Atualize manualmente

<Step label="1">

#### Atualize o SDK do Expo

Instale a nova versão do pacote Expo:

<Terminal
  cmd={{
    npm: ['$ npm install expo@^58.0.0'],
    yarn: ['$ yarn add expo@^58.0.0'],
    pnpm: ['$ pnpm add expo@^58.0.0'],
    bun: ['$ bun install expo@^58.0.0'],
  }}
/>

Dependendo do SDK para o qual você está atualizando, substitua `expo@^58.0.0` pelo intervalo de versão do SDK do Expo que você quer. Por exemplo, `expo@^58.0.0` corresponde ao SDK 58.

</Step>

<Step label="2">

#### Atualize as dependências

Atualize todas as dependências para que correspondam à versão do SDK instalada. Em seguida, rode o comando [`expo-doctor`](/develop/tools/#expo-doctor) para verificar problemas comuns.

<Terminal
  cmd={['$ npx expo install --fix', '', '$ npx expo-doctor']}
  cmdCopy="npx expo install --fix && npx expo-doctor"
/>

</Step>

<Step label="3">

#### Atualize os projetos nativos

- **Se você usa a [Geração Nativa Contínua](/workflow/continuous-native-generation/)**: apague os diretórios **android** e **ios** caso você os tenha gerado para uma versão anterior do SDK no diretório do projeto local. Eles serão gerados de novo na próxima vez que você fizer um build, seja com `npx expo run:ios`, `npx expo prebuild` ou com o Expo Build.
- **Se você não usa a [Geração Nativa Contínua](/workflow/continuous-native-generation/)**: rode `npx pod-install` se tiver um diretório **ios**. Aplique as alterações relevantes do [assistente de atualização de projetos nativos](/bare/upgrade/). Como alternativa, considere [adotar o prebuild](/guides/adopting-prebuild/) para facilitar as atualizações no futuro.

</Step>

<Step label="4">

#### Siga as notas de versão para outras instruções

Leia os [changelogs do SDK](#sdk-changelogs) da versão para a qual você está atualizando. Eles trazem informações importantes sobre quebras de compatibilidade, descontinuações e outras mudanças que podem afetar o seu app. Consulte a seção "Upgrading your app" no final da página de notas de versão para instruções adicionais.

</Step>
