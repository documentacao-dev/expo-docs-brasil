Gestos são uma ótima forma de oferecer uma experiência de usuário intuitiva em um app. A biblioteca [React Native Gesture Handler](https://docs.swmansion.com/react-native-gesture-handler/docs/) oferece componentes nativos integrados que sabem tratar gestos. Ela reconhece arrastar, toque, rotação e outros gestos usando o sistema de toque nativo da plataforma. Neste capítulo, vamos adicionar dois gestos diferentes com essa biblioteca:

- Toque duplo para aumentar o tamanho do adesivo de emoji e reduzir a escala quando o usuário tocar duas vezes novamente.
- Arrastar para mover o adesivo de emoji, para que o usuário possa posicioná-lo em qualquer lugar da imagem. O adesivo permanece dentro da imagem.

Também vamos usar a biblioteca [Reanimated](https://docs.swmansion.com/react-native-reanimated/docs/fundamentals/handling-gestures/) para animar a transição entre os estados dos gestos. O template padrão já inclui as duas bibliotecas.

## Adicione o GestureHandlerRootView

Para que as interações por gestos funcionem no app, vamos renderizar o [`<GestureHandlerRootView>`](https://docs.swmansion.com/react-native-gesture-handler/docs/core-components/root-view) do `react-native-gesture-handler` na raiz do app. Os gestos são reconhecidos somente dentro dessa view. Em **src/app/\_layout.tsx**, envolva o `<Stack>` com `<GestureHandlerRootView>`:

{/* prettier-ignore */}
```tsx src/app/_layout.tsx
import { Stack } from 'expo-router';
/* @tutinfo Import `GestureHandlerRootView` from `react-native-gesture-handler`. */
import { GestureHandlerRootView } from 'react-native-gesture-handler';
/* @end */

export default function RootLayout() {
  return (
    /* @tutinfo Wrap the `Stack` with `GestureHandlerRootView`. */
    <GestureHandlerRootView>
    /* @end */
      <Stack>
        <Stack.Screen name="(tabs)" options={{ headerShown: false }} />
      </Stack>
    /* @tutinfo */
    </GestureHandlerRootView>
    /* @end */
  );
}
```

Por padrão, o `<GestureHandlerRootView>` tem o estilo `flex: 1`, então ocupa toda a tela.

</Step>

<Step label="2">

## Use componentes animados

Um componente `Animated` observa a prop `style` do componente e determina quais valores animar e quais atualizações aplicar para criar a animação. O Reanimated exporta componentes animados, como `<Animated.View>`, `<Animated.Text>` ou `<Animated.ScrollView>`. Vamos usar `<Animated.View>` para animar o adesivo de emoji.

O adesivo também precisa permanecer sobre a imagem. No capítulo anterior, um valor negativo de `top` posicionava o adesivo sobre a imagem. Em vez disso, vamos posicionar o adesivo em relação à imagem:

1. Em **src/app/(tabs)/index.tsx**, envolva os componentes `ImageViewer` e `EmojiSticker` com um `<View>`. Esse `<View>` tem o mesmo tamanho da imagem.
2. Abra o arquivo **emoji-sticker.tsx**, no diretório **src/components**. Dentro dele, importe `Animated` da biblioteca `react-native-reanimated` para usar componentes animados.
3. Substitua o componente `<View>` por `<Animated.View>` e posicione-o no canto superior esquerdo da imagem com `position: 'absolute'`. A `Image` preenche o `<Animated.View>`.

{/* prettier-ignore */}
```tsx src/app/(tabs)/index.tsx
// ...rest of the import statements remain same

export default function Index() {
  // ...rest of the code remains same

  return (
    <SafeAreaView style={styles.container}>
      <View style={styles.imageContainer}>
        /* @tutinfo Wrap the `ImageViewer` and `EmojiSticker` components with a `View`. */
        <View>
          <ImageViewer imgSource={PlaceholderImage} selectedImage={selectedImage} />
          {pickedEmoji && <EmojiSticker imageSize={40} stickerSource={pickedEmoji} />}
        </View>
        /* @end */
      </View>
      {/* ...rest of the code remains same */}
    </SafeAreaView>
  );
}
```

{/* prettier-ignore */}
```tsx src/components/emoji-sticker.tsx
import { StyleSheet } from 'react-native';
/* @tutinfo Import `Animated` from `react-native-reanimated`. */
import Animated from 'react-native-reanimated';
/* @end */
import { Image, type ImageSource } from 'expo-image';

type Props = {
  imageSize: number;
  stickerSource: ImageSource;
};

export default function EmojiSticker({ imageSize, stickerSource }: Props) {
  return (
    /* @tutinfo Replace the `View` component with `Animated.View`. */
    <Animated.View style={[styles.sticker, { width: imageSize, height: imageSize }]}>
    /* @end */
      <Image source={stickerSource} style={styles.image} />
    /* @tutinfo */
    </Animated.View>
    /* @end */
  );
}

const styles = StyleSheet.create({
  /* @tutinfo Place the sticker at the top-left corner of the image, and make the image fill the sticker. */
  sticker: {
    position: 'absolute',
    top: 0,
    left: 0,
  },
  image: {
    width: '100%',
    height: '100%',
  },
  /* @end */
});
```

> Para a referência completa da API de componentes animados, consulte a documentação do [React Native Reanimated](https://docs.swmansion.com/react-native-reanimated/docs/core/createAnimatedComponent).

## Adicione um gesto de toque

O React Native Gesture Handler permite adicionar comportamentos quando ele detecta uma entrada de toque, como um evento de toque duplo.

No arquivo **src/components/emoji-sticker.tsx**:

1. Importe `GestureDetector` e `useTapGesture` do `react-native-gesture-handler`.
2. Para reconhecer o toque no adesivo, importe `useAnimatedStyle`, `useSharedValue` e `withSpring` do `react-native-reanimated` para animar o estilo do `<Animated.View>`.
3. Dentro do componente `EmojiSticker`, crie uma referência chamada `scaleImage` usando o hook `useSharedValue()`. Ela vai receber o valor de `imageSize` como valor inicial.

{/* prettier-ignore */}
```tsx src/components/emoji-sticker.tsx
// ...rest of the import statements remain same
/* @tutinfo Import `GestureDetector` and `useTapGesture` from `react-native-gesture-handler`. */import { GestureDetector, useTapGesture } from 'react-native-gesture-handler';/* @end */
/* @tutinfo Import `useAnimatedStyle`, `useSharedValue`, and `withSpring` from `react-native-reanimated`. */import Animated, { useAnimatedStyle, useSharedValue, withSpring } from 'react-native-reanimated';/* @end */

export default function EmojiSticker({ imageSize, stickerSource }: Props) {
  /* @tutinfo Create a `scaleImage` shared value and set `imageSize` as its initial value. */const scaleImage = useSharedValue(imageSize);/* @end */

  return (
    // ...rest of the code remains same
  )
}
```

Criar um valor compartilhado com o hook `useSharedValue()` tem várias vantagens. Ele ajuda a alterar dados e executa animações com base no valor atual. Lemos um valor compartilhado com o método `get()` e o alteramos com o método `set()`. O template padrão ativa o [React Compiler](/guides/react-compiler/) e, com o React Compiler, o Reanimated recomenda [`get()` e `set()`](https://docs.swmansion.com/react-native-reanimated/docs/core/useSharedValue) em vez da propriedade `value`.

Vamos criar um gesto `doubleTap` com o hook `useTapGesture()`. A opção `numberOfTaps` define quantos toques são necessários, e o callback `onActivate` é executado quando o gesto é reconhecido. Ele dobra o tamanho do adesivo ou o faz voltar ao tamanho inicial.

Crie o gesto a seguir no componente `EmojiSticker`:

```tsx src/components/emoji-sticker.tsx
const doubleTap = useTapGesture({
  numberOfTaps: 2,
  onActivate: () => {
    scaleImage.set(scaleImage.get() === imageSize ? imageSize * 2 : imageSize);
  },
});
```

Para animar a transição, vamos usar uma animação baseada em mola. Isso deixa o movimento mais vivo, porque segue a física real de uma mola. Vamos usar a função `withSpring()` do `react-native-reanimated`.

No adesivo, vamos usar o hook `useAnimatedStyle()` para criar um objeto de estilo. Isso nos ajuda a atualizar os estilos com valores compartilhados quando a animação acontece. Também vamos alterar o tamanho do adesivo manipulando as propriedades `width` e `height`. Os valores iniciais dessas propriedades são definidos como `imageSize`.

Crie uma variável `stickerStyle` e adicione-a ao componente `EmojiSticker`:

```tsx src/components/emoji-sticker.tsx
const stickerStyle = useAnimatedStyle(() => {
  return {
    width: withSpring(scaleImage.get()),
    height: withSpring(scaleImage.get()),
  };
});
```

Em seguida, envolva o componente `<Animated.View>` com o `<GestureDetector>` e substitua o tamanho na prop `style` do `<Animated.View>` por `stickerStyle`.

{/* prettier-ignore */}
```tsx src/components/emoji-sticker.tsx
import { StyleSheet } from 'react-native';
import { GestureDetector, useTapGesture } from 'react-native-gesture-handler';
import Animated, { useAnimatedStyle, useSharedValue, withSpring } from 'react-native-reanimated';
import { Image, type ImageSource } from 'expo-image';

type Props = {
  imageSize: number;
  stickerSource: ImageSource;
};

export default function EmojiSticker({ imageSize, stickerSource }: Props) {
  const scaleImage = useSharedValue(imageSize);

  const doubleTap = useTapGesture({
    numberOfTaps: 2,
    onActivate: () => {
      scaleImage.set(scaleImage.get() === imageSize ? imageSize * 2 : imageSize);
    },
  });

  const stickerStyle = useAnimatedStyle(() => {
    return {
      width: withSpring(scaleImage.get()),
      height: withSpring(scaleImage.get()),
    };
  });

  return (
    /* @tutinfo Wrap the `Animated.View` component with `GestureDetector`. */
    <GestureDetector gesture={doubleTap}>
    /* @end */
      <Animated.View style={/* @tutinfo Replace the size with `stickerStyle`. */[styles.sticker, stickerStyle]/* @end */}>
        <Image source={stickerSource} style={styles.image} />
      </Animated.View>
    /* @tutinfo */
    </GestureDetector>
    /* @end */
  );
}

const styles = StyleSheet.create({
  sticker: {
    position: 'absolute',
    top: 0,
    left: 0,
  },
  image: {
    width: '100%',
    height: '100%',
  },
});
```

No trecho acima, a prop `gesture` recebe o valor de `doubleTap` para disparar o gesto quando o usuário dá um toque duplo no adesivo.

## Adicione um gesto de arrastar

Para reconhecer um gesto de arrastar no adesivo e acompanhar o movimento dele, vamos usar um gesto de arrastar (pan). O adesivo precisa permanecer dentro da imagem, então também vamos limitar a posição dele. No arquivo **src/components/emoji-sticker.tsx**:

1. Crie dois novos valores compartilhados: `translateX` e `translateY`. Eles guardam a posição do adesivo. O valor inicial `0` mantém o adesivo no canto superior esquerdo da imagem.
2. Crie um gesto `drag` com o hook `usePanGesture()`. O callback `onUpdate` é executado enquanto o dedo se move. As propriedades `changeX` e `changeY` do `event` guardam a mudança de posição desde o último evento.
3. Passe cada nova posição para a função [`clamp()`](https://docs.swmansion.com/react-native-reanimated/docs/utilities/clamp) do Reanimated. Ela limita um valor entre um mínimo e um máximo. A imagem tem 320 de largura e 440 de altura, como definido em **image-viewer.tsx**. A maior posição possível é o tamanho da imagem menos o tamanho do adesivo.
4. No gesto `doubleTap`, limite a posição depois que o tamanho mudar. Assim, um adesivo que dobra de tamanho perto de uma borda continua dentro da imagem.
5. Combine os dois gestos com o hook [`useSimultaneousGestures()`](https://docs.swmansion.com/react-native-gesture-handler/docs/composition/use-simultaneous-gestures), para que o adesivo reconheça os dois gestos ao mesmo tempo.
6. Adicione uma propriedade `transform` ao `stickerStyle` para mover o adesivo com os valores de `translateX` e `translateY`.
7. Defina `pointerEvents` como `'none'` na `Image`. Na web, o navegador inicia o próprio arrastar quando o usuário pressiona uma imagem e move o ponteiro, o que cancela o gesto de arrastar. Com esse estilo, o `<Animated.View>` recebe os eventos de ponteiro.

{/* prettier-ignore */}
```tsx src/components/emoji-sticker.tsx
import { StyleSheet } from 'react-native';
/* @tutinfo Import `usePanGesture` and `useSimultaneousGestures`. */
import {
  GestureDetector,
  usePanGesture,
  useSimultaneousGestures,
  useTapGesture,
} from 'react-native-gesture-handler';
/* @end */
/* @tutinfo Import `clamp` from `react-native-reanimated`. */import Animated, { clamp, useAnimatedStyle, useSharedValue, withSpring } from 'react-native-reanimated';/* @end */
import { Image, type ImageSource } from 'expo-image';

type Props = {
  imageSize: number;
  stickerSource: ImageSource;
};

/* @tutinfo The size of the image, from `image-viewer.tsx`. */
const IMAGE_WIDTH = 320;
const IMAGE_HEIGHT = 440;
/* @end */

export default function EmojiSticker({ imageSize, stickerSource }: Props) {
  const scaleImage = useSharedValue(imageSize);
  /* @tutinfo Add `translateX` and `translateY` shared values. */
  const translateX = useSharedValue(0);
  const translateY = useSharedValue(0);
  /* @end */

  const doubleTap = useTapGesture({
    numberOfTaps: 2,
    onActivate: () => {
      const size = scaleImage.get() === imageSize ? imageSize * 2 : imageSize;
      scaleImage.set(size);
      /* @tutinfo Keep the sticker inside the image after its size changes. */
      translateX.set(clamp(translateX.get(), 0, IMAGE_WIDTH - size));
      translateY.set(clamp(translateY.get(), 0, IMAGE_HEIGHT - size));
      /* @end */
    },
  });

  /* @tutinfo Move the sticker with the finger, and keep it inside the image. */
  const drag = usePanGesture({
    onUpdate: event => {
      translateX.set(clamp(translateX.get() + event.changeX, 0, IMAGE_WIDTH - scaleImage.get()));
      translateY.set(clamp(translateY.get() + event.changeY, 0, IMAGE_HEIGHT - scaleImage.get()));
    },
  });
  /* @end */

  /* @tutinfo Recognize both gestures at the same time. */
  const gesture = useSimultaneousGestures(drag, doubleTap);
  /* @end */

  const stickerStyle = useAnimatedStyle(() => {
    return {
      width: withSpring(scaleImage.get()),
      height: withSpring(scaleImage.get()),
      /* @tutinfo Move the sticker with the `translateX` and `translateY` values. */
      transform: [{ translateX: translateX.get() }, { translateY: translateY.get() }],
      /* @end */
    };
  });

  return (
    <GestureDetector gesture={/* @tutinfo Pass the combined gesture. */gesture/* @end */}>
      <Animated.View style={[styles.sticker, stickerStyle]}>
        <Image source={stickerSource} style={styles.image} />
      </Animated.View>
    </GestureDetector>
  );
}

const styles = StyleSheet.create({
  sticker: {
    position: 'absolute',
    top: 0,
    left: 0,
  },
  image: {
    width: '100%',
    height: '100%',
    /* @tutinfo On web, the pan gesture receives the pointer events instead of the image. */
    pointerEvents: 'none',
    /* @end */
  },
});
```
