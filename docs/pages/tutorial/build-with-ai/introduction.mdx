Neste tutorial, você vai criar um app completo para Android, iOS e web sem escrever código. Em vez disso, vai comandar um agente de IA para programação, como o Claude Code, o Codex ou o Cursor, e conferir os resultados ao vivo no seu próprio celular a cada etapa.

Este tutorial é para **construtores**: pessoas que têm uma ideia de app, mas não têm formação em programação. Se você prefere aprender a escrever o código por conta própria, siga o [tutorial do Expo](/tutorial/introduction/). Ele constrói o mesmo app, um trecho de código por vez.

## O que você vai criar \{#what-youll-build}

Você vai criar o **StickerSmash**, um app que permite escolher uma foto, colocar um adesivo de emoji nela, mover e redimensionar o adesivo com os dedos e salvar o resultado na sua galeria de fotos:

## Como este tutorial funciona \{#how-this-tutorial-works}

Todo capítulo segue o mesmo ciclo:

1. **Peça**: cole um prompt sugerido no seu agente de IA.
2. **Construa**: o agente escreve o código, e o app atualiza no seu celular em poucos segundos.
3. **Verifique**: confira se o app faz o que você pediu, direto no seu celular.
4. **Peça de novo**: se algo parecer errado, diga ao agente o que você vê e deixe que ele corrija o problema.

Você é o dono do produto e o testador. O agente é o programador.

Agentes de IA não produzem resultados idênticos a cada vez, então seu app não vai bater com as nossas capturas de tela pixel por pixel. Isso é esperado. Os prompts descrevem o resultado que você quer, e as capturas mostram aproximadamente o que você deve ver. Sinta-se à vontade para editar os prompts do seu jeito: escolha outras cores, mude o texto dos botões, deixe do seu jeito.

## O que você vai precisar \{#what-youll-need}

- Um computador com macOS, Windows ou Linux.
- Um celular Android ou iOS.
- Cerca de uma hora. O primeiro capítulo mostra como instalar cada ferramenta do zero, então você não precisa deixar nada configurado antes.
