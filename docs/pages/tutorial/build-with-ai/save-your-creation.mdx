Neste capítulo, você vai adicionar o último recurso central: salvar a foto, com o adesivo e tudo, na biblioteca de fotos do seu celular.

<Step label="1">

## Salve na biblioteca de fotos \{#save-to-your-photo-library}

Cole o prompt a seguir no seu agente:

```text Prompt|wrap
Add a "Save" option to the row of options, with a download icon. When I tap it, capture just the photo with the sticker on it (not the whole screen) using the react-native-view-shot library, and save the result to my phone's photo library using the Asset.create() method from the expo-media-library library. Ask for permission to add photos the first time if needed, and show an alert confirming that the image was saved.
```

**O que você deve ver**: na primeira vez que tocar em **Save**, seu celular pode pedir permissão para adicionar fotos. Toque em **Allow**, e o app mostra uma confirmação. Abra a galeria de fotos do celular: sua foto está lá, com o adesivo incorporado, pronta para compartilhar onde quiser.

</Step>

<Step label="2">

## Faça funcionar na web (opcional) \{#make-it-work-on-the-web-optional}

Seu app não é só um app de celular. O mesmo projeto roda em um navegador. Na janela do terminal que está rodando o servidor de desenvolvimento, pressione <kbd>W</kbd> e o app abre no navegador. Tudo funciona, exceto **Save**: navegadores não dão aos apps acesso à biblioteca de fotos, então o app não consegue salvar a imagem ali.

<Collapsible summary="Quer corrigir a opção Save na web?">

Cole o prompt a seguir no seu agente:

```text Prompt|wrap
Make the Save option also work when the app runs in a web browser. When the platform is web, capture the image with the react-native-view-shot library as a data URI, and download it as a JPEG file instead of saving it to the photo library.
```

**O que você deve ver**: no navegador, escolha uma foto, adicione um adesivo e clique em **Save**. A imagem é baixada como arquivo. É assim que as diferenças entre plataformas são tratadas em apps Expo: um único app, com pequenos trechos específicos de plataforma quando necessário.

</Collapsible>

</Step>

> Se um resultado não bater com o que você esperava, diga ao agente o que você vê. A seção [Quando algo parece errado](/tutorial/build-with-ai/create-your-first-app/#when-something-looks-wrong) tem o passo a passo.
