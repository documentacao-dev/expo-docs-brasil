Neste capítulo, seu agente cria um novo app Expo, você o coloca para rodar no celular e faz sua primeira mudança. Este é o ciclo que você vai repetir no resto do tutorial.

<Step label="1">

## Inicie seu agente em uma pasta nova \{#start-your-agent-in-a-new-folder}

Seu agente trabalha dentro de uma pasta por vez, então crie uma pasta exclusiva para este projeto e inicie o agente nela. No terminal, rode:

<Terminal
  cmd={['$ mkdir StickerSmash', '', '$ cd StickerSmash']}
  cmdCopy={['$ mkdir StickerSmash && cd StickerSmash']}
/>

Depois, inicie seu agente nessa pasta: rode `claude` ou `codex`. Se estiver usando o Cursor, crie uma nova pasta chamada **StickerSmash**, abra-a com **File** > **Open Folder** e abra o painel do agente.

</Step>

<Step label="2">

## Crie o app \{#create-the-app}

Cole o prompt a seguir no seu agente:

```text Prompt|wrap
Create a new Expo app in this folder (the current directory) by running npx create-expo-app@latest and choosing the SDK 58 template — I will test the app with Expo Go on my phone, which uses SDK 58. After it is created, run the project's reset-project script so we start from a minimal app, and delete the example folder that the script leaves behind. Don't start the development server; I will run that myself.
```

O agente leva alguns minutos para baixar o template e instalar as dependências. Quando terminar, ele deve informar que o projeto está pronto, com uma pasta **src/app** mínima contendo alguns arquivos.

</Step>

<Step label="3">

## Rode o app no seu celular \{#run-the-app-on-your-phone}

Este é o único comando que você vai rodar manualmente ao longo do tutorial. Ele inicia o servidor de desenvolvimento que transmite o seu app para o celular. Abra uma **nova janela de terminal** (deixe o agente rodando na primeira) e rode:

<Terminal
  cmd={['$ cd StickerSmash', '', '$ npx expo start']}
  cmdCopy={['$ cd StickerSmash && npx expo start']}
/>

Um QR code aparece no terminal. Para abrir o app:

- **Android**: abra o Expo Go e toque em **Scan QR code**.
- **iOS**: abra o app de câmera padrão e aponte para o QR code.

> **info** Em um dispositivo iOS físico, o Expo Go só abre o seu projeto quando o Expo CLI e o Expo Go estão conectados à mesma conta da Expo. Você fez as duas coisas no capítulo anterior. Se aparecer um erro de conta, veja [Login no Expo Go necessário](/troubleshooting/expo-go-sign-in-required/).

Você deve ver uma tela quase vazia no seu celular. Esse é o seu app. Mantenha esta janela do terminal aberta e o celular por perto pelo resto do tutorial.

<Collapsible summary="O celular não conecta?">

Seu celular e seu computador precisam estar na mesma rede Wi-Fi. Se estiverem e o app ainda não carregar, pare o servidor com <kbd>Ctrl</kbd> + <kbd>C</kbd> e reinicie-o no modo tunnel, que funciona entre redes diferentes:

<Terminal cmd={['$ npx expo start --tunnel']} />

Você também pode encontrar seu projeto na aba **Projects** do Expo Go, quando estiver conectado à mesma conta da Expo no celular e no terminal.

</Collapsible>

</Step>

<Step label="4">

## Faça sua primeira mudança \{#make-your-first-change}

Agora feche o ciclo: peça ao agente uma mudança visível e veja ela chegar no seu celular. Cole o prompt a seguir no seu agente:

```text Prompt|wrap
Change the home screen so it shows the text "Home screen" in white, centered on a dark background with the color #25292e.
```

**O que você deve ver**: em poucos segundos após o agente terminar, o app no celular recarrega para uma tela escura, com o texto branco "Home screen" no centro:

<ContentSpotlight
  alt="App com o texto e a cor de fundo atualizados"
  src="/static/images/tutorial/create-your-first-app-home-screen.webp"
  className="max-w-[720px]"
/>

É esse o fluxo inteiro: você pede, o agente constrói, e o celular mostra o resultado.

</Step>

## Quando algo parece errado \{#when-something-looks-wrong}

Mais cedo ou mais tarde, um resultado não vai bater com o que você pediu. Isso é normal, e corrigir faz parte do fluxo:

- **Descreva, não diagnostique.** Diga ao agente exatamente o que você vê e o que esperava: "O texto está centralizado, mas o fundo ainda está branco." Você não precisa adivinhar o motivo.
- **Cole os erros exatamente como aparecem.** Se o celular mostrar uma tela vermelha de erro ou o terminal imprimir um erro, copie a mensagem inteira para o agente. Mensagens de erro são escritas para programadores, e o seu agente é um.
- **Peça ao agente para revisar o trabalho.** Um prompt como "Algo está quebrado: revise a mudança que você acabou de fazer, encontre o problema e corrija" ajuda muito.
- **Se o app travar**, balance o celular e toque em **Reload** no menu que aparecer. Se isso não resolver, pare o servidor de desenvolvimento com <kbd>Ctrl</kbd> + <kbd>C</kbd> e rode `npx expo start` de novo.
