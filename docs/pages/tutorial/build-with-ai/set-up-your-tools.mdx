Neste capítulo, você vai instalar tudo o que precisa, partindo do zero. Este é o capítulo mais longo. Depois que suas ferramentas estiverem configuradas, a parte divertida começa, e o resto do tutorial avança rápido.

<Prerequisites>
  <Requirement title="Um computador">Um computador com macOS, Windows ou Linux.</Requirement>
  <Requirement title="Um celular">
    Um celular Android ou iOS, conectado à mesma rede Wi-Fi do seu computador.
  </Requirement>
  <Requirement title="Um agente de IA e sua conta">
    Um agente de IA para programação e uma conta no serviço que você escolher.
  </Requirement>
  <Requirement title="Cerca de 20 minutos">A configuração não deve levar mais que isso.</Requirement>
</Prerequisites>

<Step label="1">

## Abra um terminal \{#open-a-terminal}

O terminal é o app onde você vai conversar com o seu agente de IA.

- No macOS, abra o app **Terminal**, que já vem no sistema. Você o encontra abrindo a Pesquisa Spotlight (<kbd>Cmd ⌘</kbd> + <kbd>Space</kbd>) e digitando "Terminal".
- No Windows, abra o **PowerShell** pelo menu Iniciar. Você vai digitar alguns comandos nele neste capítulo. Cada um já vem pronto para você copiar e colar.

<ContentSpotlight
  alt="Uma janela de terminal vazia no macOS."
  caption="Seu terminal pode parecer diferente dependendo do sistema operacional e das configurações, mas vai funcionar do mesmo jeito."
  src="/static/images/tutorial/terminal.webp"
  className="max-w-[640px]"
/>

> Se você pretende usar o **Cursor**, vai trabalhar na interface visual dele, e não em um terminal, na maior parte deste tutorial. Mesmo assim, deixe um terminal à mão, porque você ainda vai usá-lo para rodar o seu app.

</Step>

<Step label="2">

## Instale um agente de IA \{#install-an-ai-agent}

Se você já usa um agente de IA para programação, pule para a próxima etapa. Caso contrário, escolha um abaixo. Este tutorial funciona igual com qualquer um deles.

<Tabs>

<Tab label="Claude Code">

Execute o comando a seguir na sua janela de terminal para instalar o [Claude Code](https://claude.com/claude-code):

<Terminal cmd={['$ curl -fsSL https://claude.ai/install.sh | bash']} />

> **No Windows:** execute `irm https://claude.ai/install.ps1 | iex` se estiver usando o PowerShell para instalar o Claude Code.

Depois, execute `claude` no terminal e siga as instruções para entrar na sua conta. Veja o [guia de configuração do Claude Code](https://code.claude.com/docs/en/setup) se encontrar problemas.

</Tab>

<Tab label="Codex">

Execute o comando a seguir na sua janela de terminal para instalar o [Codex](https://developers.openai.com/codex/cli):

<Terminal cmd={['$ curl -fsSL https://chatgpt.com/codex/install.sh | sh']} />

Depois, execute `codex` no terminal e siga as instruções para entrar com a sua conta do ChatGPT. Veja a [documentação do Codex CLI](https://developers.openai.com/codex/cli) se encontrar problemas.

</Tab>

<Tab label="Cursor">

Baixe o [Cursor](https://cursor.com) e instale como qualquer outro app. O Cursor é um editor de código visual com um agente de IA embutido, onde você vai digitar os prompts no painel do agente em vez de em um terminal.

</Tab>

</Tabs>

Outros agentes também funcionam. Desde que seu agente consiga editar arquivos e executar comandos no seu computador, você pode acompanhar o tutorial.

</Step>

<Step label="3">

## Instale o Node.js \{#install-nodejs}

Vamos rodar seu primeiro prompt e instalar o Node.js.

O Node.js é o runtime que faz funcionar as ferramentas de desenvolvimento do Expo. Rode o prompt a seguir, que vai instruir seu agente a baixar a versão **Long-Term Support (LTS)** do [nodejs.org](https://nodejs.org/en).

```text Prompt|wrap
I'm following the Expo "Build with AI" tutorial on a brand-new setup and I have no programming experience. Please install the latest LTS version of Node.js on my computer.

- First, tell me in one or two plain sentences what you're about to do.
- Detect my operating system and use the most reliable method for it.
- When you're done, verify it worked by showing me the output of `node --version` and `npm --version`, and tell me if I need to reopen anything for it to take effect.
```

Para confirmar que deu certo, execute o comando a seguir abrindo uma nova janela de terminal. Ele deve mostrar o número da versão do Node.js instalada:

<Terminal cmd={['$ node --version']} />

</Step>

<Step label="4">

## Instale o Expo Go e crie uma conta na Expo \{#install-expo-go-and-create-an-expo-account}

O Expo Go é um app gratuito que permite testar seu projeto no celular enquanto você constrói, sem precisar publicar nada em uma store. Toda vez que seu agente mudar o código, o app no seu celular atualiza em poucos segundos.

1. Instale o [Expo Go](https://expo.dev/go) pela Google Play Store ou pela Apple App Store no seu celular.
2. Crie uma conta gratuita em [expo.dev/signup](https://expo.dev/signup) no seu computador.
3. Abra o Expo Go no celular e entre com a mesma conta.

Em um dispositivo iOS físico, o Expo Go só abre o seu projeto quando o Expo CLI está conectado à mesma conta. Entre no Expo CLI agora:

<Terminal cmd={['$ npx expo login']} />

</Step>

<Step label="5">

## Ensine seu agente sobre o Expo \{#teach-your-agent-about-expo}

As Expo Skills são arquivos de instrução que ensinam agentes de IA a construir bons apps Expo: quais bibliotecas usar, como organizar as telas e como evitar erros comuns. Instalá-las é a coisa mais importante que você pode fazer para obter bons resultados do seu agente.

<Tabs>

<Tab label="Claude Code">

Inicie o `claude` e, dentro dele, execute o comando a seguir:

<Terminal cmd={['$ /plugin install expo@claude-plugins-official']} />

</Tab>

<Tab label="Codex">

Execute o comando a seguir no seu terminal:

<Terminal cmd={['$ codex plugin add expo@openai-curated']} />

</Tab>

<Tab label="Cursor">

Execute o comando a seguir no seu terminal:

<Terminal cmd={['$ npx skills add expo/skills']} />

{/* vale off */}

Depois, reabra o Cursor e confirme que as skills aparecem em **Settings** > **Rules, Skills, Subagents** > **Skills**.

{/* vale on */}

</Tab>

</Tabs>

<Step label="6">

## Conecte o servidor MCP do Expo \{#connect-the-expo-mcp-server}

O servidor MCP do Expo dá ao seu agente acesso direto às ferramentas do Expo: ele consegue ler a documentação mais recente, instalar os pacotes certos e inspecionar o seu projeto.

<Tabs>

<Tab label="Claude Code">

Execute o comando a seguir no seu terminal:

<Terminal cmd={['$ claude mcp add --transport http expo https://mcp.expo.dev/mcp']} />

Depois, inicie o `claude` e execute `/mcp` dentro dele para entrar com a conta da Expo que você criou na etapa anterior.

</Tab>

<Tab label="Codex">

Execute o comando a seguir no seu terminal e, quando solicitado, entre com a conta da Expo que você criou na etapa anterior:

<Terminal cmd={['$ codex mcp add expo --url https://mcp.expo.dev/mcp']} />

</Tab>

<Step label="7">

## Teste sua configuração \{#test-your-setup}

Vamos confirmar que tudo está conectado. Cole o prompt a seguir no seu agente:

```text Prompt|wrap
Use the Expo MCP server to search the Expo documentation for "expo-image-picker" and tell me in one sentence what it does.
```

**O que você deve ver**: o agente chama uma ferramenta de documentação do Expo e responde com uma frase sobre escolher imagens da biblioteca de fotos do dispositivo. Se ele informar um erro de conexão ou de autenticação, repita a parte de login da etapa anterior.

</Step>
