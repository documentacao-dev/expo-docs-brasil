Neste capítulo, o app começa a parecer com o StickerSmash: duas abas de navegação, um visualizador de fotos e um botão que abre a biblioteca de fotos do seu celular.

<Step label="1">

## Adicione abas de navegação

A maioria dos apps tem mais de uma tela, com abas na parte de baixo para alternar entre elas. Cole o prompt a seguir no seu agente:

```text Prompt|wrap
Add a tab bar to the app with two tabs: a Home tab showing the current home screen, and an About tab with a screen that says "About screen" for now. Use native tabs from Expo Router, so the tab bar looks native on each platform. Style everything with a dark theme: the color #25292e for the screen backgrounds and the tab bar, white text, and yellow (#ffd33d) as the color of the selected tab. Give each tab a fitting icon, such as a house for Home and an info circle for About, using SF Symbols on iOS and Material Symbols on Android.
```

**O que você deve ver**: uma barra de abas na parte de baixo do app, com as abas Home e About. A aba em que você está fica destacada em amarelo, e tocar na outra troca de tela:

## Adicione o visualizador de fotos

Em seguida, dê à tela inicial o conteúdo principal: uma foto grande e dois botões. Preparamos um pacote de recursos com a foto de exemplo e os adesivos de emoji que você vai usar mais tarde. Cole o prompt a seguir no seu agente:

```text Prompt|wrap
Download the image assets for this app from https://docs.expo.dev/static/images/tutorial/sticker-smash-assets.zip and extract them into the assets/images folder, replacing any files with the same names. Then build out the Home screen: show the background-image.png photo large in the center of the screen with rounded corners, and below it two buttons stacked vertically: a prominent "Choose a photo" button with a yellow (#ffd33d) background, a dark label, and a small picture icon, and a plain "Use this photo" button with white text. Use native buttons from Expo UI (@expo/ui) on Android and iOS, and React Native components on the web. Use the expo-image library to display the image.
```

<Collapsible summary="Prefere baixar os recursos por conta própria?">

Se o seu agente não conseguir baixar ou extrair o arquivo, faça manualmente: baixe o [sticker-smash-assets.zip](/static/images/tutorial/sticker-smash-assets.zip), descompacte e copie as imagens para a pasta **assets/images** dentro da sua pasta **StickerSmash**, substituindo os arquivos com o mesmo nome. Depois, peça ao agente para montar a tela com o prompt acima, sem a primeira frase.

</Collapsible>

**O que você deve ver**: uma foto de um filhote de corgi ocupando a maior parte da tela, com os dois botões abaixo dela:

<Step label="3">

## Escolha uma foto da sua biblioteca

Chegou a hora do primeiro recurso de verdade: escolher a sua própria foto. Cole o prompt a seguir no seu agente:

```text Prompt|wrap
Add the expo-image-picker library. When I tap "Choose a photo", open my phone's photo library so I can pick an image, and show the one I pick in place of the placeholder photo. If I cancel without picking anything, keep showing the current photo.
```

**O que você deve ver**: ao tocar em **Choose a photo**, a biblioteca de fotos do seu celular abre. A foto que você escolher substitui a foto de exemplo.

</Step>

> Se um resultado não bater com o que você esperava, diga ao agente o que você vê. A seção [Quando algo parece errado](/tutorial/build-with-ai/create-your-first-app/#when-something-looks-wrong) do capítulo anterior tem o passo a passo.
