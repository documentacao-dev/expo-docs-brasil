## Sobre este tutorial

Este tutorial vai dar a você domínio dos principais serviços do [Expo Services](https://expo.dev/services): [Build](/build/introduction/), [Submit](/deploy/submit-to-app-stores/) e [Update](/eas-update/introduction/). Ao concluir o tutorial, você saberá como montar um pipeline profissional de Integração Contínua (CI) e Entrega Contínua (CD) para seus projetos individuais e de equipe.

Este tutorial aborda os seguintes tópicos:

- Use o Expo Build para criar e instalar um development build e, depois, rodá-lo em um dispositivo, emulador ou simulador.
- Veja as vantagens de usar um development build em vez do Expo Go.
- Implemente fluxos para compartilhar development builds com a equipe ou com partes externas interessadas.
- Incremente automaticamente as versões de build do app.
- Instale, ao mesmo tempo, variantes diferentes do app, como development e preview, em um mesmo dispositivo.
- Use o Expo Update para criar e publicar atualizações rapidamente durante a fase de desenvolvimento.
- Automatize os processos de build integrando com um repositório no GitHub.

Esses tópicos vão nos dar a base necessária para usar o Expo Services com eficiência e para avançar em temas mais complexos quando precisar.

Este tutorial é prático e foi feito para ser concluído em cerca de duas horas.

## Ferramentas

[Expo Orbit](https://expo.dev/orbit) para gerenciar e abrir builds com um clique no macOS, Windows e Linux.

Se você quiser instalar e rodar o build localmente na sua máquina ao mesmo tempo, pode usar o Android Emulator ou o iOS Simulator. Para configurá-los, veja a seguir:

- [Android Emulator](/workflow/android-studio-emulator/)
- [iOS Simulator](/workflow/ios-simulator/) (disponível apenas no macOS)
