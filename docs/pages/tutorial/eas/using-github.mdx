O [Expo GitHub App](/build/building-from-github/) dispara automaticamente builds dos nossos projetos do GitHub com o Expo Build. Podemos disparar builds de qualquer perfil de build, de acordo com as preferências da equipe de desenvolvimento. Ele também permite disparar builds para um `git` push feito diretamente em um repositório ou para um pull request.

Neste capítulo, vamos configurar essa funcionalidade. Já temos um repositório no GitHub para o nosso app de exemplo, para demonstrar isso.

<Step label="1">

## Configure o Expo GitHub App

Para usar essa funcionalidade, precisamos conectar nossa conta do GitHub:

- No painel da Expo, acesse [expo.dev/settings](https://expo.dev/settings#connections) e, em **Connections** > **GitHub**, clique em **Connect**. Isso abre a página **Connect GitHub** de contas.
- Clique no botão **Get started**, que abre um pop-up para autorizar o Expo GitHub App. Clique em **Install and Authorize**.
- Depois que o app for instalado na nossa conta do GitHub, precisamos vinculá-lo à nossa conta Expo. No pop-up seguinte, clique em **Link installation**.
- Quando a conta estiver vinculada, ela vai aparecer em **GitHub**.

</Step>

<Step label="2">

## Conecte o repositório do GitHub

Para permitir disparar builds a partir de um repositório no GitHub, precisamos conectá-lo ao nosso projeto no painel da Expo:

- No painel da Expo, acesse **Projects** > selecione seu projeto > **Project settings** > **GitHub**.
- Em **Connect a GitHub repository**, vamos ver uma lista dos nossos repositórios do GitHub. Precisamos conectar o correto. No exemplo, estamos procurando nosso repositório **sticker-smash.**
- Clique em **Connect** no repositório do projeto.

  src="/static/images/tutorial/eas/using-github-connect-repository.webp"

</Step>

<Step label="3">

## Use as configurações padrão do repositório

O Expo GitHub App precisa saber onde encontrar o código-fonte do nosso projeto. Por padrão, ele seleciona o diretório raiz usando `/`. No nosso projeto de exemplo, o código-fonte também está na raiz do repositório. Podemos deixar essa configuração padrão no painel da Expo.

</Step>

<Step label="4">

## Dispare um build usando uma label de PR do GitHub

O Expo GitHub App nos oferece [várias opções](/build/building-from-github/#trigger-a-build-from-github) para disparar um build, como:

- Manualmente, na página Builds de uma plataforma específica
- Automaticamente quando um código novo é enviado ao repositório
- Automaticamente usando labels de PR do GitHub

Para disparar um build automaticamente usando uma label de PR do GitHub, vamos usar a terceira opção da lista acima:

- Precisamos especificar a imagem de build que vamos usar. Abra o **eas.json** e, no perfil `development`, adicione as propriedades [`android.image`](/eas/json/#image) e [`ios.image`](/eas/json/#image-1) e defina o valor delas como [`latest`](/build-reference/infrastructure/#configuring-build-environment).

  ```json eas.json
  {
    "build": {
      "development": {
        /* @hide ... */ /* @end */
        /* @info */
        "android": {
          "image": "latest"
        },
        "ios": {
          "image": "latest"
        }
        /* @end */
      }
    }
    /* @hide ... */ /* @end */
  }
  ```

- Em seguida, vamos criar uma nova branch chamada `dev`, fazer uma alteração no código JavaScript do app, fazer o commit da alteração, enviar a branch e criar um PR a partir dela.
- No link do PR, em **Labels**, crie uma label chamada `eas-build-all:development`.

<ContentSpotlight
  alt="Criando uma label em um PR do GitHub"
  src="/static/images/tutorial/eas/using-github-create-label.webp"
  className="max-w-[320px]"
/>

- Clique no botão **Create pull request** para criar o PR. O Expo GitHub App vai iniciar o processo de criação de um development build.

- No painel da Expo, na página **Builds**, podemos verificar que os builds para Android e iOS foram disparados.

<ContentSpotlight
  alt="Builds disparados no painel da Expo para as plataformas Android e iOS"
  src="/static/images/tutorial/eas/using-github-builds-list.webp"
  className="max-w-[800px]"
/>

- Se verificarmos os detalhes de um build específico, veremos em **Created by** que o build foi criado pelo app do GitHub.

<ContentSpotlight
  alt="Detalhes de um build específico no painel da Expo"
  src="/static/images/tutorial/eas/using-github-build-details.webp"
  className="max-w-[760px]"
/>

</Step>
