Neste capítulo, vamos criar um development build que roda em Android usando o Expo Build.

O processo de criar e rodar um build em dispositivos ou emuladores Android é idêntico, com diferenças só na instalação do development build.

## Crie um build para o perfil development

No Android, o development build precisa estar no formato **.apk**. O formato padrão do Android é o **.aab**, ideal para publicar na Google Play Store, mas ele não pode ser instalado em dispositivos ou emuladores.

Para criar um **.apk**:

- No **eas.json**, confirme que `developmentClient` está como `true` no perfil `build.development`.
- Depois, rode o comando `eas build` com `android` como plataforma e `development` como perfil de build:

  <Terminal cmd={['$ eas build --platform android --profile development']} />

  > **info** **Dica**: Na próxima vez que rodar o comando `eas build`, você também pode usar `-p` para especificar a plataforma. É a forma abreviada de `--platform`.

Esse comando nos faz as seguintes perguntas:

- **What would you like your Android application id to be?** Pressione <kbd>Return</kbd> para escolher o valor padrão sugerido nesta pergunta. Isso vai adicionar o [`android.package`](/versions/latest/config/app/#package) no **app.json**.
- **Generate a new Android Keystore**? Pressione <kbd>Y</kbd>.

Depois de responder, o build entra na fila, e podemos acompanhar o progresso pelo link fornecido pela EAS CLI no painel da Expo:

<Collapsible summary="Quais informações a página de detalhes do build mostra?">

A página de detalhes do build mostra o tipo de build, o perfil, o ambiente, a versão do Expo SDK, a versão do app e o version code. Ela também mostra o fingerprint, o hash do último commit e a identidade do dev ou do dono da conta que iniciou o build.

Na imagem acima, o status atual do **Build artifact** mostra que o build está em andamento. Ao terminar, essa seção vai oferecer a opção de baixar o build. Os **Logs** detalham cada etapa do processo de build Android no Expo Build. Para não nos estendermos, não vamos explorar cada etapa aqui. Para saber mais, veja [processo de build Android](/build-reference/android-builds/).

</Collapsible>

<Collapsible summary="O que é o application ID de um app Android?">

Também conhecido como nome do pacote do nosso app Android, ele guarda o valor em notação DNS reversa (`com.owner.appname`). Cada parte dessa notação deve começar com uma letra minúscula.

Por exemplo, nosso app de exemplo tem `com.owner.stickersmash`, em que `com.owner` é o domínio e `stickersmash` é o nome do app.

</Collapsible>

## Dispositivo Android

<Step label="1">

### Instale o development build

Quando o build terminar, a seção **Build artifact** é atualizada, indicando que o build foi concluído:

<ContentSpotlight
  alt="O Build artifact oferece a opção de baixar o development build para dispositivos e emuladores Android"
  src="/static/images/tutorial/eas/android-development-build-artifact.webp"
/>

Esta seção mostra os métodos disponíveis para rodar o development build em um dispositivo Android: o Expo Orbit e o botão Install.

O [Expo Orbit](https://expo.dev/orbit) permite instalar o development build em um dispositivo Android sem complicações. Para usar esse método:

- Conecte o dispositivo Android à nossa máquina por USB.
- Abra o app Orbit.
- Selecione o **Device** no app Orbit.

<ContentSpotlight
  alt="Interface do app Expo Orbit conectado a um dispositivo Android"
  src="/static/images/tutorial/eas/android-orbit.png"
  className="max-w-[300px]"
/>

- No painel da Expo, em **Build artifact**, clique em **Open with Orbit**.

Depois que o build é instalado, o app Orbit abre o development build no dispositivo.

<Collapsible summary="Alternativa: use o botão Install e o QR code">

O botão **Install** em **Build artifact** gera um QR code para a instalação:

- Clique em **Install** para exibir um pop-up com o QR code.

<ContentSpotlight
  alt="O botão Install gera um QR code para instalar facilmente em dispositivos e emuladores Android"
  src="/static/images/tutorial/eas/android-development-build-qr-code.webp"
  className="max-w-[480px]"
/>

- Escaneie o QR code com a câmera do dispositivo Android para abrir o link do build no navegador padrão.
- Toque no botão **Install** na página para baixar o arquivo **.apk**.
- Quando o download terminar, abra o **.apk** para iniciar a instalação.
- Se aparecer a mensagem **Unsafe app blocked**, selecione **Install anyway**. Esse aviso pode ser ignorado com segurança, já que a origem do **.apk** (que geramos nós mesmos) é confiável.

<ContentSpotlight
  alt="Caixa de diálogo de app não seguro no dispositivo Android ao instalar o development build"
  src="/static/images/tutorial/eas/android-unsafe-dialog.webp"
  className="max-w-[300px]"
/>

</Collapsible>

</Step>

<Step label="2">

### Rode o development build

Inicie o servidor de desenvolvimento rodando `npx expo start` no diretório do projeto. Depois que o servidor estiver em execução, pressione <kbd>A</kbd> na janela do terminal para abrir o projeto:

<Terminal
  cmd={{
    npm: ['$ npx expo start'],
    yarn: ['$ yarn expo start'],
    pnpm: ['$ pnpm expo start'],
    bun: ['$ bun expo start'],
  }}
/>

</Step>

## Android Emulator

<Step label="1">

### Instale o development build

No terminal, quando o build terminar, a EAS CLI nos pergunta se queremos rodar o build em um Android Emulator. Pressione <kbd>Y</kbd>.

<ContentSpotlight
  alt="A EAS CLI oferece automaticamente rodar o build no Android Emulator"
  src="/static/images/tutorial/eas/android-development-build-emulator-cli.webp"
  className="max-w-[600px]"
/>

<Collapsible summary="Alternativa: use o Expo Orbit">

Como alternativa, o [Expo Orbit](/build/orbit/) pode ser usado para a instalação. Em **Build artifact** no painel da Expo, clique em **Open with Orbit** para instalar o development build no Android Emulator.

</Collapsible>

</Step>

### Rode o development build

<Terminal
  cmd={{
    npm: ['$ npx expo start'],
    yarn: ['$ yarn expo start'],
    pnpm: ['$ pnpm expo start'],
    bun: ['$ bun expo start'],
  }}
/>

</Step>
