## Exiba a imagem \{#display-the-image}

Vamos usar a biblioteca `expo-image` para exibir a imagem no app. Ela fornece um componente `<Image>` multiplataforma para carregar e renderizar uma imagem. Ela já vem incluída no template padrão de projeto que estamos usando.

O componente Image recebe a origem da imagem como valor. A origem pode ser um [asset estático](https://reactnative.dev/docs/images#static-image-resources) ou uma URL. Por exemplo, a origem vinda do diretório **assets/images** é estática. Ela também pode vir da [rede](https://reactnative.dev/docs/images#network-images) como propriedade `uri`.

<ContentSpotlight
  alt="Imagem de fundo que vamos usar como placeholder no tutorial."
  src="/static/images/tutorial/background-image.webp"
  className="max-w-[250px]"
/>

Para usar o componente Image no arquivo **src/app/(tabs)/index.tsx**:

1. Importe `Image` da biblioteca `expo-image`.
2. Crie uma variável `PlaceholderImage` para usar o arquivo **assets/images/background-image.png** como prop `source` do componente `Image`.
3. Substitua o `View` externo pelo `SafeAreaView` de `react-native-safe-area-context`. As abas nativas não adicionam um cabeçalho, então o `SafeAreaView` mantém o conteúdo da tela abaixo da barra de status no Android e no iOS. O template padrão inclui essa biblioteca.
4. Adicione um `paddingTop` ao contêiner da imagem com [`Platform.select()`](https://reactnative.dev/docs/platform#select). Na web, a lista de abas fica no topo da página, então a imagem precisa de mais espaço ali.

{/* prettier-ignore */}
```tsx src/app/(tabs)/index.tsx|collapseHeight=380
import { Platform, View, StyleSheet } from 'react-native';
/* @tutinfo Import the `Image` component. */ import { Image } from 'expo-image'; /* @end */
/* @tutinfo Import the `SafeAreaView` component. It replaces the outer `View`. */ import { SafeAreaView } from 'react-native-safe-area-context'; /* @end */

/* @tutinfo Import the image from the "assets/images/" directory. Since this picture is a static resource, you have to reference it using `require`. */
const PlaceholderImage = require('@/assets/images/background-image.png');
/* @end */

export default function Index() {
  return (
    <SafeAreaView style={styles.container}>
      /* @tutinfo Wrap the `Image` component inside a container. Also, add the image component to display the placeholder image. */
      <View style={styles.imageContainer}>
        <Image source={PlaceholderImage} style={styles.image} />
      </View>
      /* @end */
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#25292e',
    /* @tutinfo Modify container styles to remove `justifyContent` property. */
    alignItems: 'center',
    /* @end */
  },
  /* @tutinfo Add styles for the image container and image. `Platform.select()` returns `20` on Android and iOS, and `96` on web. */
  imageContainer: {
    flex: 1,
    paddingTop: Platform.select({ web: 96, default: 20 }),
  },
  image: {
    width: 320,
    height: 440,
    borderRadius: 18,
  },
  /* @end */
});
```

## Divida os componentes em arquivos \{#divide-components-into-files}

Vamos dividir o código em vários arquivos conforme adicionarmos mais componentes a esta tela. Ao longo deste tutorial, vamos usar o diretório components para criar componentes personalizados.

1. Crie um diretório **components** dentro de **src** e, dentro dele, crie o arquivo **image-viewer.tsx**.
2. Mova o código que exibe a imagem para esse arquivo, junto com os estilos `image`.

{/* prettier-ignore */}
```tsx src/components/image-viewer.tsx|collapseHeight=280
import { StyleSheet } from 'react-native';
import { Image, type ImageSource } from 'expo-image';

type Props = {
  /* @tutinfo The `ImageSource` type from `expo-image` describes the values that the `source` prop accepts. */imgSource: ImageSource;/* @end */
};

export default function ImageViewer({ imgSource }: Props) {
  return <Image source={imgSource} style={styles.image} />;
}

const styles = StyleSheet.create({
  image: {
    width: 320,
    height: 440,
    borderRadius: 18,
  },
});
```

> **info** Como **ImageViewer** é um componente personalizado, colocamos ele em um diretório separado, e não no diretório **src/app**. Cada arquivo dentro de **src/app** é um arquivo de layout ou de rota. Para mais informações, veja [Componentes que não são de navegação ficam fora do diretório src/app](/router/basics/core-concepts/#6-non-navigation-components-live-outside-the-srcapp-directory).

Importe `ImageViewer` e use-o em **src/app/(tabs)/index.tsx**:

{/* prettier-ignore */}
```tsx src/app/(tabs)/index.tsx|collapseHeight=320
import { Platform, StyleSheet, View } from 'react-native';
import { SafeAreaView } from 'react-native-safe-area-context';

/* @tutinfo */import ImageViewer from '@/components/image-viewer'; /* @end */

const PlaceholderImage = require('@/assets/images/background-image.png');

export default function Index() {
  return (
    <SafeAreaView style={styles.container}>
      <View style={styles.imageContainer}>
        /* @tutinfo Replace `Image` component with `ImageViewer`. */
        <ImageViewer imgSource={PlaceholderImage} />
        /* @end */
      </View>
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#25292e',
    alignItems: 'center',
  },
  imageContainer: {
    flex: 1,
    paddingTop: Platform.select({ web: 96, default: 20 }),
  },
});
```

<Collapsible summary={<>O que é o <CODE>@</CODE> na instrução import?</>}>

O símbolo `@` é um [alias de caminho](/guides/typescript/#path-aliases-optional) personalizado para importar componentes e outros módulos no lugar de caminhos relativos. O Expo CLI o configura automaticamente no **tsconfig.json**.

</Collapsible>

</Step>

<Step label="4">

## Crie botões com Pressable \{#create-buttons-using-pressable}

O React Native inclui alguns componentes diferentes para tratar eventos de toque, mas o [`<Pressable>`](https://reactnative.dev/docs/pressable) é recomendado pela flexibilidade. Ele detecta toques simples e toques longos, dispara eventos separados quando o botão é pressionado e quando é solto, entre outros recursos.

No design, há dois botões que precisamos criar. Cada um tem um estilo e um rótulo diferentes. Vamos começar criando um componente reutilizável para esses botões. Crie um arquivo **button.tsx** dentro do diretório **src/components** com o código a seguir:

{/* prettier-ignore */}
```tsx src/components/button.tsx|collapseHeight=280
import { StyleSheet, View, Pressable, Text } from 'react-native';

type Props = {
  label: string;
  /* @tutinfo The screen that renders the button passes a function to run on each press. */onPress?: () => void;/* @end */
};

export default function Button({ label, onPress }: Props) {
  return (
    <View style={styles.buttonContainer}>
      <Pressable style={styles.button} onPress={onPress}>
        <Text style={styles.buttonLabel}>{label}</Text>
      </Pressable>
    </View>
  );
}

const styles = StyleSheet.create({
  buttonContainer: {
    width: 320,
    height: 68,
    alignItems: 'center',
    justifyContent: 'center',
  },
  button: {
    height: 48,
    paddingHorizontal: 20,
    borderRadius: 24,
    alignItems: 'center',
    justifyContent: 'center',
    flexDirection: 'row',
    gap: 8,
  },
  buttonLabel: {
    color: '#fff',
    fontSize: 16,
  },
});
```

A prop `onPress` permite que a tela decida o que acontece quando o usuário pressiona o botão. Vamos importar esse componente no arquivo **src/app/(tabs)/index.tsx**. Passe a cada botão uma função `onPress` que chama `alert()`. Depois, adicione estilos para o `<View>` que envolve os botões:

{/* prettier-ignore */}
```tsx src/app/(tabs)/index.tsx
import { Platform, View, StyleSheet } from 'react-native';
import { SafeAreaView } from 'react-native-safe-area-context';

/* @tutinfo */import Button from '@/components/button'; /* @end */
import ImageViewer from '@/components/image-viewer';

const PlaceholderImage = require('@/assets/images/background-image.png');

export default function Index() {
  return (
    <SafeAreaView style={styles.container}>
      <View style={styles.imageContainer}>
        <ImageViewer imgSource={PlaceholderImage} />
      </View>
      /* @tutinfo Use the reusable `Button` component to create two buttons and encapsulate them inside a `View` component. */
      <View style={styles.footerContainer}>
        <Button label="Choose a photo" onPress={() => alert('You pressed a button.')} />
        <Button label="Use this photo" onPress={() => alert('You pressed a button.')} />
      </View>
      /* @end */
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#25292e',
    alignItems: 'center',
  },
  imageContainer: {
    flex: 1,
    paddingTop: Platform.select({ web: 96, default: 20 }),
  },
  /* @tutinfo Add the following styles. */
  footerContainer: {
    flex: 1 / 3,
    alignItems: 'center',
  },
  /* @end */
});
```

O app exibe um alerta quando o usuário toca em qualquer um dos botões da tela. Vamos ver nosso app no Android, no iOS e na web:

## Aprimore o componente de botão reutilizável \{#enhance-the-reusable-button-component}

O botão "Choose a photo" precisa de um estilo diferente do botão "Use this photo". Vamos adicionar uma prop `theme` para aplicar a ele um tema `primary`. Esse botão também tem um ícone antes do rótulo. Vamos usar o componente `SymbolView` do [`expo-symbols`](/versions/latest/sdk/symbols/) para exibi-lo. No Android e na web, o `SymbolView` exibe um ícone do [Material Symbols](https://fonts.google.com/icons). No iOS, ele exibe um ícone do [SF Symbols](https://developer.apple.com/sf-symbols/). O template padrão já inclui o `expo-symbols`.

Modifique **src/components/button.tsx** para adicionar o trecho de código a seguir:

{/* prettier-ignore */}
```tsx src/components/button.tsx
import { StyleSheet, View, Pressable, Text } from 'react-native';
/* @tutinfo Import SymbolView. */import { SymbolView } from 'expo-symbols';/* @end */

type Props = {
  label: string;
  /* @tutinfo Add theme prop. */theme?: 'primary';/* @end */
  onPress?: () => void;
};

export default function Button({ label, /* @tutinfo The prop `theme` to detect the button variant. */theme/* @end */, onPress }: Props) {
  /* @tutinfo Conditionally render the primary themed button. */
  if (theme === 'primary') {
  /* @end */
  /* @tutinfo */
    return (
      <View style={styles.buttonContainer}>
        <Pressable style={[styles.button, styles.primaryButton]} onPress={onPress}>
          <SymbolView
            name={{ ios: 'photo', android: 'image', web: 'image' }}
            size={18}
            tintColor="#25292e"
          />
          <Text style={[styles.buttonLabel, { color: '#25292e' }]}>{label}</Text>
        </Pressable>
      </View>
    );
  /* @end */
  /* @tutinfo */
  }
  /* @end */

  return (
    <View style={styles.buttonContainer}>
      <Pressable style={styles.button} onPress={onPress}>
        <Text style={styles.buttonLabel}>{label}</Text>
      </Pressable>
    </View>
  );
}

const styles = StyleSheet.create({
  buttonContainer: {
    width: 320,
    height: 68,
    alignItems: 'center',
    justifyContent: 'center',
  },
  button: {
    height: 48,
    paddingHorizontal: 20,
    borderRadius: 24,
    alignItems: 'center',
    justifyContent: 'center',
    flexDirection: 'row',
    gap: 8,
  },
  /* @tutinfo Add a style for the primary theme. */
  primaryButton: {
    backgroundColor: '#ffd33d',
  },
  /* @end */
  buttonLabel: {
    color: '#fff',
    fontSize: 16,
  },
});
```

Vamos entender o que o código acima faz:

- O botão com o tema primary passa um array para a prop `style` do `<Pressable>`. O React Native aplica os estilos em ordem, então o `backgroundColor` de `styles.primaryButton` se aplica só ao botão primary.
- O rótulo do botão primary usa um **estilo inline**, um objeto passado diretamente na prop `style`. Ele muda a cor do rótulo para `#25292e` e sobrescreve o `color` de `styles.buttonLabel`.
- A prop `name` do `SymbolView` recebe um nome de ícone para cada plataforma: `image` para Android e web, e `photo` para iOS.

Agora, modifique o arquivo **src/app/(tabs)/index.tsx** para usar a prop `theme="primary"` no primeiro botão.

{/* prettier-ignore */}
```tsx src/app/(tabs)/index.tsx
import { Platform, View, StyleSheet } from 'react-native';
import { SafeAreaView } from 'react-native-safe-area-context';

import Button from '@/components/button';
import ImageViewer from '@/components/image-viewer';

export default function Index() {
  return (
    <SafeAreaView style={styles.container}>
      <View style={styles.imageContainer}>
        <ImageViewer imgSource={PlaceholderImage} />
      </View>
      <View style={styles.footerContainer}>
        /* @tutinfo Add `"primary"` theme on the first button. */
        <Button
          theme="primary"
          label="Choose a photo"
          onPress={() => alert('You pressed a button.')}
        />
        /* @end */
        <Button label="Use this photo" onPress={() => alert('You pressed a button.')} />
      </View>
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#25292e',
    alignItems: 'center',
  },
  imageContainer: {
    flex: 1,
    paddingTop: Platform.select({ web: 96, default: 20 }),
  },
  footerContainer: {
    flex: 1 / 3,
    alignItems: 'center',
  },
});
```

## Use botões nativos com o Expo UI \{#use-native-buttons-with-expo-ui}

Nosso botão usa componentes do React Native, então ele tem a mesma aparência em todas as plataformas. O [Expo UI](/versions/latest/sdk/ui/) oferece componentes nativos: views do Jetpack Compose no Android e views do SwiftUI no iOS. O template padrão já inclui o Expo UI (`@expo/ui`). O Expo UI funciona no Expo Go.

Vamos substituir o botão no Android e no iOS por um botão nativo e manter o botão do React Native para a web. Para isso, vamos usar extensões específicas de plataforma. Quando **button.android.tsx** e **button.ios.tsx** existem ao lado de **button.tsx**, o Metro usa o arquivo da plataforma atual ao importarmos `@/components/button`. A web continua usando **button.tsx**. Para mais informações, veja [Extensões específicas de plataforma](/router/advanced/platform-specific-modules/#platform-specific-extensions).

O botão do Android exibe um ícone do [`@expo/material-symbols`](https://www.npmjs.com/package/@expo/material-symbols), um conjunto de ícones Material Symbols para o Jetpack Compose. Para instalá-lo, pare o servidor de desenvolvimento pressionando <kbd>Ctrl</kbd> + <kbd>C</kbd> no terminal e depois execute o comando a seguir:

<Terminal
  cmd={{
    npm: ['$ npx expo install @expo/material-symbols'],
    yarn: ['$ yarn expo install @expo/material-symbols'],
    pnpm: ['$ pnpm expo install @expo/material-symbols'],
    bun: ['$ bun expo install @expo/material-symbols'],
  }}
/>

Mantenha o servidor de desenvolvimento parado até que os dois novos arquivos existam. Se você adicioná-los com o servidor rodando, o Metro pode continuar usando **button.tsx**. Nesse caso, reinicie o servidor.

Crie um arquivo **button.android.tsx** dentro do diretório **src/components**:

{/* prettier-ignore */}
```tsx src/components/button.android.tsx
import { StyleSheet, View } from 'react-native';
/* @tutinfo Import Jetpack Compose components from Expo UI. */import { Host, Button as ComposeButton, TextButton, Icon, Row, Text } from '@expo/ui/jetpack-compose';/* @end */

type Props = {
  label: string;
  theme?: 'primary';
  onPress?: () => void;
};

export default function Button({ label, theme, onPress }: Props) {
  if (theme === 'primary') {
    return (
      <View style={styles.buttonContainer}>
        /* @tutinfo The `colors` prop sets the container and content colors of the button. `Row` places the icon and the label next to each other, with 8 dp of space between them. */
        <Host matchContents>
          <ComposeButton
            onClick={onPress}
            colors={{ containerColor: '#ffd33d', contentColor: '#25292e' }}>
            <Row verticalAlignment="center" horizontalArrangement={{ spacedBy: 8 }}>
              <Icon source={require('@expo/material-symbols/image.xml')} size={18} tint="#25292e" />
              <Text color="#25292e">{label}</Text>
            </Row>
          </ComposeButton>
        </Host>
        /* @end */
      </View>
    );
  }

  return (
    <View style={styles.buttonContainer}>
      <Host matchContents>
        /* @tutinfo `TextButton` displays a button with no background. */
        <TextButton onClick={onPress} colors={{ contentColor: '#fff' }}>
          <Text color="#fff">{label}</Text>
        </TextButton>
        /* @end */
      </Host>
    </View>
  );
}

const styles = StyleSheet.create({
  buttonContainer: {
    width: 320,
    height: 68,
    alignItems: 'center',
    justifyContent: 'center',
  },
});
```

<Collapsible summary={<>O que é o <CODE>Host</CODE>?</>}>

O `Host` é a ponte entre o React Native e o Expo UI. Os componentes do Jetpack Compose no Android e os componentes do SwiftUI no iOS só são renderizados dentro de um `Host`. A prop `matchContents` faz o `Host` ter o tamanho do seu conteúdo, que aqui é o botão. Para mais informações, veja o `Host` do [Jetpack Compose](/versions/latest/sdk/ui/jetpack-compose/host/) e do [SwiftUI](/versions/latest/sdk/ui/swift-ui/host/).

</Collapsible>

Depois, crie um arquivo **button.ios.tsx** dentro do diretório **src/components**:

{/* prettier-ignore */}
```tsx src/components/button.ios.tsx
import { StyleSheet, View } from 'react-native';
/* @tutinfo Import SwiftUI components and modifiers from Expo UI. */
import { Host, Button as SwiftUIButton } from '@expo/ui/swift-ui';
import { buttonStyle, controlSize, foregroundStyle, tint } from '@expo/ui/swift-ui/modifiers';
/* @end */

type Props = {
  label: string;
  theme?: 'primary';
  onPress?: () => void;
};

export default function Button({ label, theme, onPress }: Props) {
  if (theme === 'primary') {
    return (
      <View style={styles.buttonContainer}>
        <Host matchContents>
          /* @tutinfo `systemImage` displays an SF Symbols icon before the label. Modifiers change the style of the button. `tint` sets the button color, and `foregroundStyle` sets the color of the icon and label. */
          <SwiftUIButton
            label={label}
            systemImage="photo"
            onPress={onPress}
            modifiers={[
              buttonStyle('borderedProminent'),
              controlSize('large'),
              tint('#ffd33d'),
              foregroundStyle('#25292e'),
            ]}
          />
          /* @end */
        </Host>
      </View>
    );
  }

  return (
    <View style={styles.buttonContainer}>
      <Host matchContents>
        /* @tutinfo `borderless` displays the button with no background. */
        <SwiftUIButton
          label={label}
          onPress={onPress}
          modifiers={[buttonStyle('borderless'), controlSize('large'), foregroundStyle('#fff')]}
        />
        /* @end */
      </Host>
    </View>
  );
}

const styles = StyleSheet.create({
  buttonContainer: {
    width: 320,
    height: 68,
    alignItems: 'center',
    justifyContent: 'center',
  },
});
```

<Collapsible summary="O que são modificadores?">

Modificadores personalizam a aparência e o comportamento dos componentes do Expo UI, como estilo, tamanho e cores. Importe-os de `@expo/ui/jetpack-compose/modifiers` para o Jetpack Compose e de `@expo/ui/swift-ui/modifiers` para o SwiftUI. Depois, passe-os em um array para a prop `modifiers` de um componente, como faz o **button.ios.tsx**. Para mais informações, veja os modificadores do [Jetpack Compose](/versions/latest/sdk/ui/jetpack-compose/modifiers/) e do [SwiftUI](/versions/latest/sdk/ui/swift-ui/modifiers/).

</Collapsible>

Os dois arquivos mantêm as mesmas props de **button.tsx**, então **src/app/(tabs)/index.tsx** não muda. O diretório **src/components** agora contém três versões do botão:
