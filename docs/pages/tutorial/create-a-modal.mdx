Um modal apresenta conteúdo acima do restante do app. Em geral, modais são usados para chamar a atenção do usuário para informações críticas ou para guiá-lo a tomar uma ação. Uma bottom sheet é um tipo de modal que desliza de baixo para cima, a partir da parte inferior da tela.

Neste capítulo, vamos criar um seletor de emoji com o componente [`BottomSheet`](/versions/latest/sdk/ui/universal/bottomsheet/) do Expo UI. No Android e no iOS, ele exibe a bottom sheet nativa da plataforma. Na web, ele exibe uma folha na parte inferior da página.

## Declare uma variável de estado para mostrar os botões \{#declare-a-state-variable-to-show-buttons}

Antes de implementar a bottom sheet, vamos adicionar três botões novos. Esses botões ficam visíveis depois que o usuário escolhe uma imagem da biblioteca de mídia ou usa a imagem de placeholder. Um desses botões vai abrir o seletor de emoji.

No arquivo **src/app/(tabs)/index.tsx**:

1. Declare uma variável de estado booleana, `showAppOptions`, para mostrar ou esconder os botões que abrem o seletor de emoji, junto com algumas outras opções. Quando a tela do app carregar, vamos defini-la como `false`, para que as opções não apareçam antes de escolher uma imagem. Quando o usuário escolher uma imagem ou usar a imagem de placeholder, vamos defini-la como `true`.
2. Atualize a função `pickImageAsync()` para definir o valor de `showAppOptions` como `true` depois que o usuário escolher uma imagem.
3. Na prop `onPress` do botão sem tema, substitua o `alert()` por uma função que define `showAppOptions` como `true`.

{/* prettier-ignore */}

import { SafeAreaView } from 'react-native-safe-area-context';
import * as ImagePicker from 'expo-image-picker';

const PlaceholderImage = require('@/assets/images/background-image.png');

  /* @tutinfo Create a state variable inside the `Index` component. */
  const [showAppOptions, setShowAppOptions] = useState<boolean>(false);
  /* @end */

      mediaTypes: ['images'],

      quality: 1,

      alert('You did not select any image.');
    }

    <SafeAreaView style={styles.container}>
      <View style={styles.imageContainer}>
        <ImageViewer imgSource={PlaceholderImage} selectedImage={selectedImage} />

        <View />
      /* @end */
      ) : (
        <View style={styles.footerContainer}>
          <Button theme="primary" label="Choose a photo" onPress={pickImageAsync} />
          /* @tutinfo Replace the `alert()` with a function that sets `showAppOptions` to `true`. */

          /* @end */
        </View>
      /* @tutinfo */)}/* @end */

## Crie um seletor de emoji com uma bottom sheet \{#create-an-emoji-picker-with-a-bottom-sheet}

A bottom sheet permite que o usuário escolha um emoji de uma lista de emojis disponíveis. Crie um arquivo **emoji-picker.tsx** dentro do diretório **src/components**. Esse componente aceita três props:

- `isVisible`: um booleano que determina se a bottom sheet está visível.
- `onClose`: uma função para fechar a bottom sheet.
- `children`: usada mais adiante para exibir uma lista de emojis.

{/* prettier-ignore */}
```tsx src/components/emoji-picker.tsx
import { PropsWithChildren } from 'react';
import { StyleSheet, Text, View } from 'react-native';
/* @tutinfo Import `BottomSheet` and `RNHostView` from Expo UI. */
import { BottomSheet, RNHostView } from '@expo/ui';
/* @end */

type Props = PropsWithChildren<{
  isVisible: boolean;
  onClose: () => void;
}>;

export default function EmojiPicker({ isVisible, children, onClose }: Props) {
  return (
    <BottomSheet
      isPresented={isVisible}
      onDismiss={onClose}
      snapPoints={/* @tutinfo Open the bottom sheet at about half of the screen height. */['half']/* @end */}
      containerColor="#25292e">
      /* @tutinfo `RNHostView` displays React Native views inside the bottom sheet. */
      <RNHostView>
        <View>
          <Text style={styles.title}>Choose a sticker</Text>
          {children}
        </View>
      </RNHostView>
      /* @end */
    </BottomSheet>
  );
}

const styles = StyleSheet.create({
  title: {
    color: '#fff',
    fontSize: 16,
    marginBottom: 20,
  },
});
```

Vamos entender o que o código acima faz:

- O componente `BottomSheet` vem de `@expo/ui`, que o template padrão já inclui. No Android, ele exibe uma bottom sheet do Material 3. No iOS, exibe uma sheet do SwiftUI. Na web, exibe uma folha na parte inferior da página.
- Sua prop `isPresented` recebe o valor de `isVisible` e controla se a bottom sheet está aberta ou fechada.
- Sua prop `onDismiss` chama `onClose` quando o usuário fecha a bottom sheet. O usuário pode arrastar a bottom sheet para baixo ou tocar fora dela. No Android, o botão voltar também a fecha. Na web, a tecla <kbd>Esc</kbd> também a fecha.
- Sua prop `snapPoints` define as alturas em que a bottom sheet pode parar. O valor `'half'` abre a bottom sheet em cerca de metade da altura da tela.
- Sua prop `containerColor` define a cor de fundo da bottom sheet, para combinar com o fundo do app.
- O componente `RNHostView` exibe views do React Native, como `<View>` e `<Text>`, dentro da bottom sheet.

<Collapsible summary={<>O que é <CODE>RNHostView</CODE>?</>}>

No Android e no iOS, `BottomSheet` é uma view nativa do Jetpack Compose e do SwiftUI. Para exibir views do React Native dentro dela, envolva-as em `RNHostView`. Ele funciona na direção oposta do `Host`, que usamos no [terceiro capítulo](/tutorial/build-a-screen/#use-native-buttons-with-expo-ui) para exibir componentes do Expo UI dentro de views do React Native. O `BottomSheet` cria o próprio `Host`, então não o envolvemos em um. Para mais informações, veja [`RNHostView`](/versions/latest/sdk/ui/universal/rnhostview/).

</Collapsible>

## Exiba uma lista de emojis \{#display-a-list-of-emoji}

Vamos adicionar uma grade de emojis ao conteúdo da bottom sheet. Para isso, vamos usar o componente [`<FlatList>`](https://reactnative.dev/docs/flatlist) do React Native.

Crie um arquivo **emoji-list.tsx** dentro do diretório **src/components** e adicione o código a seguir:

{/* prettier-ignore */}
```tsx src/components/emoji-list.tsx
import { FlatList, Pressable, StyleSheet } from 'react-native';
import { Image, type ImageSource } from 'expo-image';

type Props = {
  onSelect: (image: ImageSource) => void;
  onCloseModal: () => void;
};

/* @tutinfo The emoji images from the `assets/images` directory. */
const emoji: ImageSource[] = [
  require('@/assets/images/emoji1.png'),
  require('@/assets/images/emoji2.png'),
  require('@/assets/images/emoji3.png'),
  require('@/assets/images/emoji4.png'),
  require('@/assets/images/emoji5.png'),
  require('@/assets/images/emoji6.png'),
];
/* @end */

export default function EmojiList({ onSelect, onCloseModal }: Props) {
  return (
    <FlatList
      data={emoji}
      numColumns={/* @tutinfo Display the list as a grid with three columns. */3/* @end */}
      columnWrapperStyle={styles.row}
      renderItem={({ item }) => (
        <Pressable
          onPress={() => {
            onSelect(item);
            onCloseModal();
          }}>
          <Image source={item} style={styles.image} />
        </Pressable>
      )}
    />
  );
}

const styles = StyleSheet.create({
  row: {
    justifyContent: 'space-around',
    marginBottom: 20,
  },
  image: {
    width: 100,
    height: 100,
  },
});
```

Vamos entender o que o código acima faz:

- O array `emoji` guarda as imagens dos emojis. Ele fica fora do componente porque o valor dele nunca muda.
- O componente `<FlatList>` recebe o array `emoji` como valor da prop `data`. A prop `renderItem` pega cada item de `data` e retorna um componente `Image`, envolvido por um `<Pressable>`. Quando o usuário pressiona um emoji, `onSelect` o recebe, e `onCloseModal` fecha a bottom sheet.
- A prop `numColumns` exibe a lista como uma grade de três colunas. A prop `columnWrapperStyle` estiliza cada linha da grade.
