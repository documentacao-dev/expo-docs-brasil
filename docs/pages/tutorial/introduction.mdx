## Sobre o tutorial de React Native e Expo

O objetivo deste tutorial é começar a usar o Expo e se familiarizar com o SDK do Expo. Ele vai cobrir os seguintes tópicos:

- Criar um app usando o template padrão com TypeScript habilitado
- Implementar um layout de duas telas com abas nativas do Expo Router
- Decompor o layout do app e implementá-lo com flexbox
- Criar botões nativos com Expo UI e usar arquivos específicos de cada plataforma para Android, iOS e web
- Usar a interface do sistema de cada plataforma para selecionar uma imagem da biblioteca de mídia
- Criar um seletor de emojis com o bottom sheet do Expo UI e o componente `<FlatList>` do React Native
- Adicionar gestos de toque para interagir com um adesivo
- Usar bibliotecas de terceiros para capturar uma captura de tela, salvá-la na biblioteca de mídia no Android e no iOS e baixá-la na web
- Por fim, passar pelo processo de configurar a barra de status, a splash screen e um ícone para concluir o app

Esses tópicos formam a base para aprender os fundamentos de criar um app Expo. O tutorial é no seu próprio ritmo e pode levar até duas horas para ser concluído.

O app usa a interface nativa de cada plataforma. O [Expo UI](/versions/latest/sdk/ui/) traz componentes do Jetpack Compose e do SwiftUI para o React Native, e funciona no Expo Go. No Android, a barra de abas, os botões e o bottom sheet usam o Material 3. No iOS 26 em diante, a barra de abas usa o Liquid Glass. Na web, o app usa componentes do React Native.

Para ser fácil para iniciantes, dividimos o tutorial em oito capítulos, para que você possa acompanhar ou parar e voltar depois. Cada capítulo traz os trechos de código necessários para concluir os passos, então você pode acompanhar criando um app do zero ou copiar e colar o código.

## Como usar este tutorial

Acreditamos em [aprender fazendo](https://en.wikipedia.org/wiki/Learning-by-doing), por isso este tutorial dá mais ênfase à prática do que à explicação. Você pode acompanhar a jornada de criar um app construindo-o do zero.

Ao longo do tutorial, todo código importante, ou código que mudou entre os exemplos, aparece <span className="tutorial-code-annotation">destacado em verde</span>.
