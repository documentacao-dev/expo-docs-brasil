Agora que o app de exemplo está pronto, vamos aprender mais sobre as tecnologias que usamos para construí-lo.

## Transforme seu projeto em um app

Para começar a criar um novo app na sua máquina, você pode usar `npx create-expo-app@latest` e [configurar seu ambiente de desenvolvimento](/get-started/set-up-your-environment/) em sequência.

### Recursos recomendados

Depois de criar seu novo projeto, você pode aprender mais sobre diferentes ferramentas e conceitos que vão ajudar na sua jornada de desenvolvimento de apps:

- [Ferramentas de desenvolvimento](/develop/tools/): uma referência das ferramentas do Expo que vão ajudar em vários aspectos da sua jornada de criação de apps.
- [Development builds](/develop/development-builds/introduction/): usar um development build permite ter controle total sobre o processo de build do seu app e testá-lo em um dispositivo ou simulador.
- [Visão geral do desenvolvimento](/workflow/overview/): uma visão geral de alto nível com detalhes sobre os conceitos principais para desenvolver um app com Expo e o fluxo do ciclo principal de desenvolvimento.
- [Expo Router](/router/introduction/): passamos pelos conceitos básicos do Expo Router e implementamos um navegador de abas. Veja a documentação dele para saber mais sobre a biblioteca.
- [Expo UI](/versions/latest/sdk/ui/): usamos o Expo UI para criar botões nativos com Jetpack Compose no Android e SwiftUI no iOS. Também usamos o bottom sheet dele, que funciona em todas as plataformas. Veja as referências de [componentes universais](/versions/latest/sdk/ui/universal/), [Jetpack Compose](/versions/latest/sdk/ui/jetpack-compose/) e [SwiftUI](/versions/latest/sdk/ui/swift-ui/) para conhecer outros componentes e modificadores.
- [Ícone do app](/develop/user-interface/splash-screen-and-app-icon/#app-icon) e [splash screen](/develop/user-interface/splash-screen-and-app-icon/#splash-screen): você pode saber mais sobre a personalização do ícone do app e da splash screen nos guias. Também vale dar uma olhada na [referência de configuração do app](/workflow/configuration) para as propriedades que você pode configurar no arquivo **app.json**.
- [Distribuição do app](/deploy/build-project/) e [envio](/deploy/submit-to-app-stores/) para as lojas de apps: leia estes recursos para saber mais sobre como lançar e enviar seu app para as lojas quando ele estiver pronto.
- [Debugging](/debugging/runtime-issues/): às vezes as coisas dão errado e, quando isso acontece, você pode usar as ferramentas de debug para encontrar e corrigir erros.

## Aprendizado

### React

Usamos componentes e APIs do React. Ter um bom entendimento de React é essencial para usar o Expo e criar seu app. Recomendamos ler a [seção Quick Start](https://react.dev/learn) e a [seção Hooks](https://react.dev/reference/react/hooks) da documentação do React.

### React Native

Ao desenvolver o app do tutorial, usamos muito o React Native. Você pode começar pelo [guia de conceitos básicos do React Native](https://reactnative.dev/docs/getting-started) para aprender mais. Também vale conferir a documentação a seguir:

- [Referência da API de View](https://reactnative.dev/docs/view)
- [Referência da API de Text](https://reactnative.dev/docs/text)
- [Código específico de plataforma](https://reactnative.dev/docs/platform-specific-code)
- [Como apresentar dados em uma lista](https://reactnative.dev/docs/using-a-listview)

Usamos Flexbox para organizar os componentes. Confira as recomendações a seguir para aprender mais sobre ele:

- [Altura e largura](https://reactnative.dev/docs/height-and-width)
- [Layout com Flexbox](https://reactnative.dev/docs/flexbox)

### Gestos e animações

Para aprender mais sobre como implementar diferentes tipos de gestos e animações, recomendamos a documentação a seguir:

- [React Native Gesture Handler](https://docs.swmansion.com/react-native-gesture-handler/docs/)
- [React Native Reanimated](https://docs.swmansion.com/react-native-reanimated/docs/fundamentals/getting-started)
