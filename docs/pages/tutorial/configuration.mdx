## Configure a barra de status

A biblioteca [`expo-status-bar`](/versions/latest/sdk/status-bar/) já vem instalada em todo projeto criado com `create-expo-app`. Ela fornece o componente `StatusBar` para configurar o estilo da barra de status do app.

Dentro de **src/app/\_layout.tsx**:

1. Importe `StatusBar` de `expo-status-bar`.
2. Adicione o componente `StatusBar` depois do componente `Stack`, dentro de `GestureHandlerRootView`. Defina a prop `style` como `light`, para que o texto e os ícones da barra de status fiquem claros sobre o fundo escuro.

{/* prettier-ignore */}
```tsx src/app/_layout.tsx
import { Stack } from 'expo-router';
import { GestureHandlerRootView } from 'react-native-gesture-handler';
/* @tutinfo */
import { StatusBar } from 'expo-status-bar';
/* @end */

export default function RootLayout() {
  return (
    <GestureHandlerRootView>
      <Stack>
        <Stack.Screen name="(tabs)" options={{ headerShown: false }} />
      </Stack>
      /* @tutinfo Add the `StatusBar` component with the `light` style. */<StatusBar style="light" />/* @end */
    </GestureHandlerRootView>
  );
}
```

## Ícone do app

Dentro do projeto, há um arquivo **icon.png** no diretório **assets/images**. Esse é o ícone do nosso app. É uma imagem de 1024 px por 1024 px e fica como mostrado abaixo:

<ContentSpotlight
  alt="O ícone padrão do app: um quadrado escuro com cantos arredondados, mostrando um símbolo branco de foto com um smiley amarelo."
  src="/static/images/tutorial/icon.webp"
  className="max-w-[150px]"
/>

Assim como na imagem da splash screen, a propriedade `"icon"` no arquivo **app.json** configura o caminho do ícone do app. Por padrão, um novo projeto Expo já define o caminho correto como `"./assets/images/icon.png"`.

Um novo projeto Expo também tem propriedades de ícone específicas de cada plataforma, que têm prioridade sobre `"icon"`:

- No Android, a propriedade `"android.adaptiveIcon"` usa os arquivos **android-icon-foreground.png**, **android-icon-background.png** e **android-icon-monochrome.png** do diretório **assets/images**. Os [assets baixados](/tutorial/create-your-first-app/#download-assets) substituíram esses arquivos pelo ícone do StickerSmash, então não precisamos mudar nada.
- No iOS, a propriedade `"ios.icon"` usa o ícone padrão do Expo, do arquivo **assets/expo.icon**. Para usar nosso **icon.png** no iOS, remova a propriedade `"ios"` a seguir do **app.json**:

```json app.json
{
  "expo": {
    "icon": "./assets/images/icon.png",
    /* @hide ... */ /* @end */
    "ios": {
      "icon": "./assets/expo.icon"
    }
    /* @hide ... */ /* @end */
  }
}
```

O Expo Go não mostra o ícone do nosso app. Vamos vê-lo no dispositivo depois que fizermos a build do app. Para saber mais, veja o guia de [ícone do app](/develop/user-interface/splash-screen-and-app-icon/#app-icon).

> Quando você for fazer a build do app para as lojas, os [Expo Services](/eas/) vão usar esta imagem e criar ícones otimizados para cada dispositivo.

</Step>

<Step label="3">

## Splash screen

A splash screen fica visível antes que o conteúdo do app seja carregado. Ela usa uma imagem menor, como o ícone do app, centralizada. Ela some assim que o conteúdo do app estiver pronto para ser exibido.

O plugin [`expo-splash-screen`](/versions/latest/sdk/splash-screen/) já vem instalado em todo projeto criado com `create-expo-app`. Essa biblioteca fornece um config plugin para configurar a splash screen.

No **app.json**, o plugin `expo-splash-screen` já está configurado para usar o ícone do app como imagem da splash screen (fornecida nos [assets para download](/tutorial/create-your-first-app/#download-assets)). Seu `backgroundColor` é o azul padrão do Expo (`#208AEF`). Mude para `#25292e`, para que a splash screen tenha o mesmo fundo escuro do app e do ícone:

```json app.json
{
  "plugins": [
    /* @hide ... */ /* @end */
    [
      "expo-splash-screen",
      {
        "backgroundColor": "#25292e",
        "image": "./assets/images/splash-icon.png",
        "imageWidth": 76
      }
    ]
  ]
}
```

No entanto, **para testar a splash screen, não podemos usar o Expo Go nem um [development build](/develop/development-builds/introduction/)**. Para testá-la, precisamos criar uma build de preview ou de produção do app. Recomendamos ler os recursos a seguir para saber mais sobre a configuração da splash screen e como testá-la:

- Guia de [criação do ícone da splash screen](/develop/user-interface/splash-screen-and-app-icon/#splash-screen) para entender como esse ícone é configurado.
- Para aprender a criar uma build de preview, veja o guia [Distribuição interna](/tutorial/eas/internal-distribution-builds/) do tutorial dos Expo Services, ou, para criar builds de produção, veja os guias para [Android](/tutorial/eas/android-production-build/) e [iOS](/tutorial/eas/ios-production-build/).

</Step>
