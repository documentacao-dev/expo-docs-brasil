Neste capítulo, vamos aprender a capturar uma tela usando uma biblioteca de terceiros e salvá-la na biblioteca de mídia do dispositivo. Vamos usar [`react-native-view-shot`](https://github.com/gre/react-native-view-shot) para tirar a captura e [`expo-media-library`](/versions/latest/sdk/media-library/) para salvar a imagem na biblioteca de mídia do dispositivo. Navegadores web não dão aos apps acesso a uma biblioteca de mídia, então, na web, vamos baixar a captura como um arquivo de imagem.

> **info** Até agora, usamos bibliotecas de terceiros, como `react-native-gesture-handler` e `react-native-reanimated`. Há centenas de outras bibliotecas de terceiros no [React Native Directory](https://reactnative.directory/), para diferentes casos de uso.

## Instale as bibliotecas

Na web, o `react-native-view-shot` usa o `html2canvas-pro` para capturar a tela. Para instalar `react-native-view-shot`, `html2canvas-pro` e `expo-media-library`, execute os comandos a seguir:

<Terminal
  cmd={{
    npm: ['$ npx expo install react-native-view-shot html2canvas-pro expo-media-library'],
    yarn: ['$ yarn expo install react-native-view-shot html2canvas-pro expo-media-library'],
    pnpm: ['$ pnpm expo install react-native-view-shot html2canvas-pro expo-media-library'],
    bun: ['$ bun expo install react-native-view-shot html2canvas-pro expo-media-library'],
  }}
/>

<Step label="2">

## Solicite permissões

Um app que acessa informações sensíveis, como a biblioteca de mídia do dispositivo, precisa pedir permissão para permitir ou negar o acesso. O hook [`usePermissions()`](/versions/latest/sdk/media-library/#usepermissionsoptions) do `expo-media-library` retorna a resposta de permissão `permissionResponse` e o método `requestPermission()` para pedir acesso. Nosso app só salva imagens na biblioteca de mídia, então vamos passar a opção `writeOnly: true` para pedir acesso de escrita sem acesso de leitura.

Quando o app carrega pela primeira vez e o status da permissão não está concedido nem negado, o valor de `permissionResponse` é `null`. Ao pedir permissão, o usuário pode concedê-la ou negá-la. Podemos adicionar uma condição para verificar se ela não foi concedida. Se não foi, chamamos o método `requestPermission()`. Depois de obter o acesso, o valor de `permissionResponse.granted` muda para `true`.

Adicione o trecho de código a seguir dentro de **src/app/(tabs)/index.tsx**:

{/* prettier-ignore */}
```tsx src/app/(tabs)/index.tsx
import { /* @tutinfo */useEffect/* @end */, useState } from 'react';
/* @tutinfo Import `MediaLibrary` from `expo-media-library`. */import * as MediaLibrary from 'expo-media-library';/* @end */

// ...rest of the code remains same

export default function Index() {
  /* @tutinfo Add this statement to get the permission response and the `requestPermission()` method from the hook. */const [permissionResponse, requestPermission] = MediaLibrary.usePermissions({ writeOnly: true });/* @end */
  // ...rest of the code remains same

  /* @tutinfo Add an if statement to check the permission status. The requestPermission() method will trigger a dialog box for the user to grant or deny the permission. */
  useEffect(() => {
    if (!permissionResponse?.granted) {
      requestPermission();
    }
  }, []);
  /* @end */

  // ...rest of the code remains same
}
```

</Step>

<Step label="3">

## Crie uma ref para salvar a view atual

Vamos usar o `react-native-view-shot` para permitir que o usuário tire uma captura de tela dentro do app. Essa biblioteca captura a tela de uma `<View>` como imagem, usando o método `captureRef()`. Ele retorna a URI do arquivo de imagem capturado.

No capítulo anterior, envolvemos os componentes `<ImageViewer>` e `<EmojiSticker>` dentro de uma `<View>`. Vamos capturar essa `<View>`:

1. Importe `captureRef` de `react-native-view-shot`, e importe `useRef` e o tipo `ComponentRef` do React.
2. Crie uma variável de referência `imageRef` para guardar a referência da `<View>`.
3. Passe a variável de referência para a prop `ref` da `<View>` que envolve os componentes `<ImageViewer>` e `<EmojiSticker>`.

{/* prettier-ignore */}
```tsx src/app/(tabs)/index.tsx|collapseHeight=440
import { useEffect, /* @tutinfo Import `useRef` hook and `ComponentRef` type from `react`. */useRef/* @end */, useState, /* @tutinfo */type ComponentRef/* @end */ } from 'react';
/* @tutinfo Import `captureRef` from `react-native-view-shot`. */import { captureRef } from 'react-native-view-shot';/* @end */

export default function Index() {
  /* @tutinfo Create an imageRef variable. */const imageRef = useRef<ComponentRef<typeof View>>(null);/* @end */

  // ...rest of the code remains same

  return (
    <SafeAreaView style={styles.container}>
      <View style={styles.imageContainer}>
        /* @tutinfo Pass the reference variable to the `ref` prop and set `collapsable` to `false`. */<View ref={imageRef} collapsable={false}>/* @end */
          <ImageViewer imgSource={PlaceholderImage} selectedImage={selectedImage} />
          {pickedEmoji && <EmojiSticker imageSize={40} stickerSource={pickedEmoji} />}
        </View>
      </View>
      {/* ...rest of the code remains same */}
    </SafeAreaView>
  );
}
```

No trecho acima, a prop `collapsable` está definida como `false`. Isso permite que o componente `<View>` capture apenas a imagem de fundo e o adesivo de emoji.

</Step>

<Step label="4">

## Capture a tela e salve-a

Podemos capturar a tela da view chamando o método `captureRef()` do `react-native-view-shot` dentro da função `onSaveImageAsync()`. Ele aceita um argumento opcional, no qual podemos passar a `width` e a `height` da área de captura. Podemos ler mais sobre as opções disponíveis na [documentação da biblioteca](https://github.com/gre/react-native-view-shot#capturerefview-options-lower-level-imperative-api).

O método `captureRef()` também retorna uma promise que é resolvida com a URI da captura. Vamos passar essa URI como parâmetro para [`MediaLibrary.Asset.create()`](/versions/latest/sdk/media-library/#createfilepath-album), que salva a captura na biblioteca de mídia do dispositivo.

Dentro de **src/app/(tabs)/index.tsx**, atualize a função `onSaveImageAsync()` com o código a seguir:

{/* prettier-ignore */}
```tsx src/app/(tabs)/index.tsx|collapseHeight=440
import { useEffect, useRef, useState, type ComponentRef } from 'react';
import { Platform, View, StyleSheet } from 'react-native';
import { SafeAreaView } from 'react-native-safe-area-context';
import * as ImagePicker from 'expo-image-picker';
import * as MediaLibrary from 'expo-media-library';
import { captureRef } from 'react-native-view-shot';
import type { ImageSource } from 'expo-image';

import Button from '@/components/button';
import ImageViewer from '@/components/image-viewer';
import IconButton from '@/components/icon-button';
import CircleButton from '@/components/circle-button';
import EmojiPicker from '@/components/emoji-picker';
import EmojiList from '@/components/emoji-list';
import EmojiSticker from '@/components/emoji-sticker';

const PlaceholderImage = require('@/assets/images/background-image.png');

export default function Index() {
  const [selectedImage, setSelectedImage] = useState<string | undefined>(undefined);
  const [showAppOptions, setShowAppOptions] = useState<boolean>(false);
  const [isModalVisible, setIsModalVisible] = useState<boolean>(false);
  const [pickedEmoji, setPickedEmoji] = useState<ImageSource | undefined>(undefined);
  const [permissionResponse, requestPermission] = MediaLibrary.usePermissions({ writeOnly: true });
  const imageRef = useRef<ComponentRef<typeof View>>(null);

  useEffect(() => {
    if (!permissionResponse?.granted) {
      requestPermission();
    }
  }, []);

  const pickImageAsync = async () => {
    const result = await ImagePicker.launchImageLibraryAsync({
      mediaTypes: ['images'],
      allowsEditing: true,
      quality: 1,
    });

    if (!result.canceled) {
      setSelectedImage(result.assets[0].uri);
      setShowAppOptions(true);
    } else {
      alert('You did not select any image.');
    }
  };

  const onReset = () => {
    setShowAppOptions(false);
  };

  const onAddSticker = () => {
    setIsModalVisible(true);
  };

  const onModalClose = () => {
    setIsModalVisible(false);
  };

  /* @tutinfo Replace the comment with the code to capture the screenshot and save the image. */
  const onSaveImageAsync = async () => {
    try {
      const localUri = await captureRef(imageRef, {
        height: 440,
        quality: 1,
      });

      await MediaLibrary.Asset.create(localUri);
      alert('Saved!');
    } catch (e) {
      console.log(e);
    }
  };
  /* @end */

  return (
    <SafeAreaView style={styles.container}>
      <View style={styles.imageContainer}>
        <View ref={imageRef} collapsable={false}>
          <ImageViewer imgSource={PlaceholderImage} selectedImage={selectedImage} />
          {pickedEmoji && <EmojiSticker imageSize={40} stickerSource={pickedEmoji} />}
        </View>
      </View>
      {showAppOptions ? (
        <View style={styles.footerContainer}>
          <View style={styles.optionsRow}>
            <IconButton
              icon={{
                android: require('@expo/material-symbols/refresh.xml'),
                ios: 'arrow.counterclockwise',
                web: 'refresh',
              }}
              label="Reset"
              onPress={onReset}
            />
            <CircleButton onPress={onAddSticker} />
            <IconButton
              icon={{
                android: require('@expo/material-symbols/download.xml'),
                ios: 'square.and.arrow.down',
                web: 'download',
              }}
              label="Save"
              onPress={onSaveImageAsync}
            />
          </View>
        </View>
      ) : (
        <View style={styles.footerContainer}>
          <Button theme="primary" label="Choose a photo" onPress={pickImageAsync} />
          <Button label="Use this photo" onPress={() => setShowAppOptions(true)} />
        </View>
      )}
      <EmojiPicker isVisible={isModalVisible} onClose={onModalClose}>
        <EmojiList onSelect={setPickedEmoji} onCloseModal={onModalClose} />
      </EmojiPicker>
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#25292e',
    alignItems: 'center',
  },
  imageContainer: {
    flex: 1,
    paddingTop: Platform.select({ web: 96, default: 20 }),
  },
  footerContainer: {
    flex: 1 / 3,
    alignItems: 'center',
  },
  optionsRow: {
    alignItems: 'center',
    flexDirection: 'row',
  },
});
```

## Salve a captura de tela na web

O `react-native-view-shot` também consegue capturar a tela na web. No entanto, o `expo-media-library` funciona apenas no Android e no iOS. Na web, vamos baixar a captura como um arquivo de imagem.

Usando o módulo `Platform` do React Native, podemos implementar comportamentos específicos de cada plataforma. Na web, o `captureRef()` retorna a captura como uma [data URL](https://developer.mozilla.org/en-US/docs/Web/URI/Reference/Schemes/data) quando definimos a opção `result` como `'data-uri'`. Podemos passar essa data URL para um elemento de link e clicar nele para baixar a imagem.

Dentro de **src/app/(tabs)/index.tsx**, atualize a função `onSaveImageAsync()` para verificar se a plataforma atual é `'web'`, com a propriedade `Platform.OS`:

1. Se não for `'web'`, continuamos usando a mesma lógica adicionada para Android e iOS.
2. Se for `'web'`, usamos o método `captureRef()` para capturar a `<View>` atual como uma imagem JPEG. Depois, criamos um elemento de link com a data URL e clicamos nele para baixar a imagem.

O módulo `Platform` já está importado de `react-native`, porque o estilo `imageContainer` o usa.

    setIsModalVisible(true);
  };

    setIsModalVisible(false);
  };

  const onSaveImageAsync = async () => {
    /* @tutinfo Add the if condition here to check whether the current platform is web or not. */
