## Inicialize um novo app Expo

Vamos usar o [`create-expo-app`](/more/create-expo/) para inicializar um novo app Expo. É uma ferramenta de linha de comando para criar um novo projeto React Native. Execute o comando a seguir no seu terminal:

<Terminal
  cmd={{
    npm: [
      '# Create a project named StickerSmash',
      '$ npx create-expo-app@latest StickerSmash',
      '',
      '# The CLI asks for an Expo SDK version. Select Latest (SDK 58).',
      '$ Select an Expo SDK version > Latest (SDK 58)',
      '',
      '# Navigate to the project directory',
      '$ cd StickerSmash',
    ],
    yarn: [
      '# Create a project named StickerSmash',
      '$ yarn create expo-app StickerSmash',
      '',
      '# The CLI asks for an Expo SDK version. Select Latest (SDK 58).',
      '$ Select an Expo SDK version > Latest (SDK 58)',
      '',
      '# Navigate to the project directory',
      '$ cd StickerSmash',
    ],
    pnpm: [
      '# Create a project named StickerSmash',
      '$ pnpm create expo-app StickerSmash',
      '',
      '# The CLI asks for an Expo SDK version. Select Latest (SDK 58).',
      '$ Select an Expo SDK version > Latest (SDK 58)',
      '',
      '# Navigate to the project directory',
      '$ cd StickerSmash',
    ],
    bun: [
      '# Create a project named StickerSmash',
      '$ bun create expo StickerSmash',
      '',
      '# The CLI asks for an Expo SDK version. Select Latest (SDK 58).',
      '$ Select an Expo SDK version > Latest (SDK 58)',
      '',
      '# Navigate to the project directory',
      '$ cd StickerSmash',
    ],
  }}
/>

Esse comando cria um diretório de projeto chamado StickerSmash, usando o [template padrão](/more/create-expo/#--template). Esse template traz o código inicial e as bibliotecas essenciais para construir nosso app, incluindo o Expo Router e o Expo UI. Ele também nos permite testar o app com o Expo Go instalado nos nossos dispositivos. Vamos adicionar mais bibliotecas ao longo do tutorial, conforme necessário.

<Collapsible summary="Vantagens de usar o template padrão">

- Cria um novo projeto React Native com o pacote `expo` instalado
- Inclui ferramentas recomendadas, como o Expo CLI
- Inclui um navegador de abas do Expo Router para fornecer um sistema básico de navegação
- Configurado automaticamente para rodar o projeto em várias plataformas: Android, iOS e web
- TypeScript configurado por padrão

## Execute o script reset-project

Neste tutorial, vamos construir o app do zero e entender os fundamentos de adicionar navegação baseada em arquivos. Vamos executar o script `reset-project` para remover o código inicial:

<Terminal
  cmd={{
    npm: ['$ npm run reset-project'],
    yarn: ['$ yarn run reset-project'],
    pnpm: ['$ pnpm run reset-project'],
    bun: ['$ bun run reset-project'],
  }}
/>

O script pergunta se deve mover os arquivos existentes para um diretório **example**, em vez de excluí-los. Pressione <kbd>Enter</kbd> para movê-los.

Quando o script terminar, restam dois arquivos (**index.tsx** e **\_layout.tsx**) dentro do diretório **src/app**. O script move os arquivos anteriores do diretório **src** (incluindo **components**, **constants** e **hooks**) e do diretório **scripts** para o diretório **example**. Vamos criar nossos próprios diretórios e arquivos de componentes conforme avançamos.

<Collapsible summary={<>O que o script <CODE>reset-project</CODE> faz?</>}>

O script `reset-project` redefine a estrutura do diretório **src/app** de um projeto. Ele move os arquivos de código inicial anteriores dos diretórios **src** e **scripts** do projeto para outro subdiretório chamado **example**. Podemos excluir **example**, já que ele não faz parte da estrutura principal do app. O próprio arquivo do script também é movido para **example**, então executar `reset-project` de novo não funciona.

</Collapsible>

</Step>

<Step label="4">

## Rode o app no celular e na web

No diretório do projeto, execute o comando a seguir para iniciar o [servidor de desenvolvimento](/more/glossary-of-terms/#development-server) pelo terminal:

<Terminal
  cmd={{
    npm: ['$ npx expo start'],
    yarn: ['$ yarn expo start'],
    pnpm: ['$ pnpm expo start'],
    bun: ['$ bun expo start'],
  }}
/>

Depois de executar o comando acima:

1. O servidor de desenvolvimento vai iniciar, e você verá um QR code dentro da janela do terminal.
2. Escaneie esse QR code para abrir o app no dispositivo. No Android, use a opção Expo Go > **Scan QR**. No iOS, use o app de câmera padrão.
3. Para rodar o app na web, pressione <kbd>W</kbd> no terminal. Ele vai abrir o app no navegador padrão.

> **info** Em um dispositivo iOS físico, o Expo Go só abre seu projeto quando o Expo CLI e o Expo Go estão logados na mesma conta Expo. Execute `npx expo login` no seu computador e, depois, entre no Expo Go com a mesma conta. Se o erro continuar, veja [Login obrigatório no Expo Go](/troubleshooting/expo-go-sign-in-required/).

Quando estiver rodando em todas as plataformas, o app deve ficar assim:

## Edite a tela index

O arquivo **src/app/index.tsx** define o texto exibido na tela do app. Ele é a primeira tela que nosso app mostra. Ele usa componentes principais do React Native, como `<View>` e `<Text>`, para exibir o fundo e o texto.

Os estilos aplicados a esses componentes usam objetos JavaScript, e não CSS, como na web. No entanto, muitas propriedades vão parecer familiares se você já usou CSS na web. A maioria dos componentes do React Native aceita uma prop `style` que recebe um objeto JavaScript como valor. Para mais detalhes, veja [Estilização no React Native](https://reactnative.dev/docs/style).

Vamos modificar a tela **src/app/index.tsx**:

1. Adicione a propriedade `backgroundColor` com o valor `#25292e` em `styles.container`. Isso muda a cor de fundo.
2. Substitua o valor padrão de `<Text>` por "Home screen".
3. Adicione um objeto `styles.text` com a propriedade `color` de valor `#fff` (branco). Passe-o para a prop `style` de `<Text>` para mudar a cor do texto.

{/* prettier-ignore */}
```tsx src/app/index.tsx|collapseHeight=340
import { Text, View, StyleSheet } from 'react-native';

export default function Index() {
  return (
    <View style={styles.container}>
      /* @tutinfo Apply `styles.text`. Replace "Edit src/app/index.tsx to edit this screen." with "Home screen". */
      <Text style={styles.text}>Home screen</Text>
      /* @end */
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    /* @tutinfo Add a `backgroundColor` property with the value of `'#25292e'`. */
    backgroundColor: '#25292e',
    /* @end */
    alignItems: 'center',
    justifyContent: 'center',
  },
  /* @tutinfo Add a `text` style with a `color` property of `'#fff'`. */
  text: {
    color: '#fff',
  },
  /* @end */
});
```

> O React Native usa o mesmo formato de cores da web. Ele aceita valores hexadecimais (é o caso de `#fff`), `rgba`, `hsl` e nomes de cores, como `red`, `green`, `blue`, `peru` e `papayawhip`. Para mais informações, veja [Cores no React Native](https://reactnative.dev/docs/colors).

Assim que você salvar as alterações, elas são enviadas e aplicadas aos apps em execução conectados ao servidor de desenvolvimento:

<Collapsible summary="O que é o ícone de engrenagem?">

O ícone de engrenagem é o **botão Tools** nas plataformas Android e iOS. É um atalho flutuante que abre o [menu do desenvolvedor](/debugging/tools/#developer-menu), que dá acesso a funções de debug, como recarregar o app e ativar ou desativar o Fast Refresh. Ele aparece só durante o desenvolvimento e nunca é incluído em um build de produção.

Nas demais capturas de tela deste tutorial, ele estará oculto. Para ocultá-lo:

1. Abra o menu do desenvolvedor. Sacuda seu dispositivo ou pressione <kbd>M</kbd> no terminal que roda o servidor de desenvolvimento, se você estiver usando um emulador, um simulador ou um dispositivo conectado por USB.
2. Encontre a opção **Tools button** e desative-a.

Ocultá-lo não desativa o menu do desenvolvedor. Você ainda pode abri-lo do jeito descrito no Passo 1 sempre que precisar.
