O React Native oferece componentes integrados como blocos básicos, como `<View>`, `<Text>` e `<Pressable>`. Estamos criando um recurso para selecionar uma imagem da biblioteca de mídia do dispositivo. Isso não é possível apenas com os componentes principais, então vamos precisar de uma biblioteca para adicionar esse recurso ao nosso app.

Vamos usar o [`expo-image-picker`](/versions/latest/sdk/imagepicker), uma biblioteca do [SDK do Expo](/versions/latest/).

> `expo-image-picker` dá acesso à interface do sistema para selecionar imagens e vídeos da biblioteca de mídia do dispositivo.

<Step label="1">

## Instale o expo-image-picker

Para instalar a biblioteca `expo-image-picker`, pare o servidor de desenvolvimento pressionando <kbd>Ctrl</kbd> + <kbd>C</kbd> no terminal e execute o comando a seguir:

<Terminal
  cmd={{
    npm: ['$ npx expo install expo-image-picker'],
    yarn: ['$ yarn expo install expo-image-picker'],
    pnpm: ['$ pnpm expo install expo-image-picker'],
    bun: ['$ bun expo install expo-image-picker'],
  }}
/>

O comando [`npx expo install`](/more/expo-cli/#installation) instala a biblioteca e a adiciona às dependências do projeto no **package.json**.

> **info** **Dica:** sempre que instalarmos uma nova biblioteca no projeto, pare o servidor de desenvolvimento pressionando <kbd>Ctrl</kbd> + <kbd>C</kbd> no terminal e depois execute o comando de instalação. Quando a instalação terminar, inicie o servidor de desenvolvimento novamente executando `npx expo start`.

</Step>

<Step label="2">

## Escolha uma imagem da biblioteca de mídia do dispositivo

`expo-image-picker` oferece o método `launchImageLibraryAsync()`, que abre a interface do sistema para selecionar uma imagem ou um vídeo da biblioteca de mídia do dispositivo. Vamos criar uma função que chama esse método e depois conectá-la ao botão principal do capítulo anterior.

No arquivo **src/app/(tabs)/index.tsx**, importe a biblioteca `expo-image-picker` e crie uma função `pickImageAsync()` dentro do componente `Index`:

{/* prettier-ignore */}
```tsx src/app/(tabs)/index.tsx|collapseHeight=440
// ...rest of the import statements remain unchanged
/* @tutinfo Import `ImagePicker`. */ import * as ImagePicker from 'expo-image-picker';/* @end */

export default function Index() {
  /* @tutinfo Pass image picker options to `launchImageLibraryAsync()` */
  const pickImageAsync = async () => {
    const result = await ImagePicker.launchImageLibraryAsync({
      mediaTypes: ['images'],
      allowsEditing: true,
      quality: 1,
    });

    if (!result.canceled) {
      /* @tutinfo If the image is picked, print its information in terminal window. */
      console.log(result);
      /* @end */
    } else {
      /* @tutinfo If the user does not pick an image, show an alert. */
      alert('You did not select any image.');
      /* @end */
    }
  };
  /* @end */

  // ...rest of the code remains same
}
```

Vamos entender o que o código acima faz:

- O método `launchImageLibraryAsync()` recebe um objeto para especificar diferentes opções. Esse objeto é o [`ImagePickerOptions`](/versions/latest/sdk/imagepicker/#imagepickeroptions), que passamos ao chamar o método.
- Quando `allowsEditing` é `true`, o usuário pode recortar a imagem durante a seleção no Android e no iOS. Na web, o seletor de arquivos do navegador abre sem uma etapa de recorte.

</Step>

<Step label="3">

## Conecte o botão ao seletor de imagens

O componente `Button` do capítulo anterior já aceita uma prop `onPress`. Em **src/app/(tabs)/index.tsx**, passe a função `pickImageAsync()` para a prop `onPress` do primeiro `<Button>`:

{/* prettier-ignore */}
```tsx src/app/(tabs)/index.tsx
import { Platform, View, StyleSheet } from 'react-native';
import { SafeAreaView } from 'react-native-safe-area-context';
import * as ImagePicker from 'expo-image-picker';

import Button from '@/components/button';
import ImageViewer from '@/components/image-viewer';

const PlaceholderImage = require('@/assets/images/background-image.png');

export default function Index() {
  const pickImageAsync = async () => {
    const result = await ImagePicker.launchImageLibraryAsync({
      mediaTypes: ['images'],
      allowsEditing: true,
      quality: 1,
    });

    if (!result.canceled) {
      console.log(result);
    } else {
      alert('You did not select any image.');
    }
  };

  return (
    <SafeAreaView style={styles.container}>
      <View style={styles.imageContainer}>
        <ImageViewer imgSource={PlaceholderImage} />
      </View>
      <View style={styles.footerContainer}>
        <Button theme="primary" label="Choose a photo" onPress={/* @tutinfo Replace the `alert()` function with `pickImageAsync`. */pickImageAsync/* @end */} />
        <Button label="Use this photo" onPress={() => alert('You pressed a button.')} />
      </View>
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#25292e',
    alignItems: 'center',
  },
  imageContainer: {
    flex: 1,
    paddingTop: Platform.select({ web: 96, default: 20 }),
  },
  footerContainer: {
    flex: 1 / 3,
    alignItems: 'center',
  },
});
```

A função `pickImageAsync()` chama `ImagePicker.launchImageLibraryAsync()` e depois trata o resultado. O método `launchImageLibraryAsync()` retorna um objeto com informações sobre a imagem selecionada.

<Step label="4">

## Use a imagem selecionada

O objeto `result` fornece o array `assets`, que contém o `uri` da imagem selecionada. Vamos pegar esse valor do seletor de imagens e usá-lo para exibir a imagem escolhida no app.

Modifique o arquivo **src/app/(tabs)/index.tsx**:

1. Declare uma variável de estado chamada `selectedImage` usando o hook [`useState`](https://react.dev/learn/state-a-components-memory#adding-a-state-variable) do React. Vamos usar essa variável para guardar a URI da imagem selecionada.
2. Atualize a função `pickImageAsync()` para salvar a URI da imagem na variável de estado `selectedImage`.
3. Passe `selectedImage` como prop para o componente `ImageViewer`.

{/* prettier-ignore */}
```tsx src/app/(tabs)/index.tsx
/* @tutinfo Import `useState` hook from `react`.*/
import { useState } from 'react';
/* @end */
import { Platform, View, StyleSheet } from 'react-native';
import { SafeAreaView } from 'react-native-safe-area-context';
import * as ImagePicker from 'expo-image-picker';

import Button from '@/components/button';
import ImageViewer from '@/components/image-viewer';

const PlaceholderImage = require('@/assets/images/background-image.png');

export default function Index() {
  /* @tutinfo Create a state variable that will hold the value of selected image. */
  const [selectedImage, setSelectedImage] = useState<string | undefined>(undefined);
  /* @end */

  const pickImageAsync = async () => {
    const result = await ImagePicker.launchImageLibraryAsync({
      mediaTypes: ['images'],
      allowsEditing: true,
      quality: 1,
    });

    if (!result.canceled) {
      /* @tutinfo Pick the first uri from the `assets` array. Also, there is only one image selected at a time so you don't have to change this. */
      setSelectedImage(result.assets[0].uri);
      /* @end */
    } else {
      alert('You did not select any image.');
    }
  };

  return (
    <SafeAreaView style={styles.container}>
      <View style={styles.imageContainer}>
        /* @tutinfo Pass the selected image URI to the `ImageViewer` component. */
        <ImageViewer imgSource={PlaceholderImage} selectedImage={selectedImage} />
        /* @end */
      </View>
      <View style={styles.footerContainer}>
        <Button theme="primary" label="Choose a photo" onPress={pickImageAsync} />
        <Button label="Use this photo" onPress={() => alert('You pressed a button.')} />
      </View>
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#25292e',
    alignItems: 'center',
  },
  imageContainer: {
    flex: 1,
    paddingTop: Platform.select({ web: 96, default: 20 }),
  },
  footerContainer: {
    flex: 1 / 3,
    alignItems: 'center',
  },
});
```

Passe a prop `selectedImage` para o componente `ImageViewer` para exibir a imagem selecionada no lugar da imagem provisória.

1. Modifique o arquivo **src/components/image-viewer.tsx** para aceitar a prop `selectedImage`.
2. A origem da imagem está ficando longa, então vamos movê-la também para uma variável separada chamada `imageSource`.
3. Passe `imageSource` como valor da prop `source` do componente `Image`.

{/* prettier-ignore */}
```tsx src/components/image-viewer.tsx
import { StyleSheet } from 'react-native';
import { Image, type ImageSource } from 'expo-image';

type Props = {
  imgSource: ImageSource;
  /* @tutinfo */
  selectedImage?: string;
  /* @end */
};

export default function ImageViewer({ imgSource, /* @tutinfo Pass the `selectedImage` prop.*/selectedImage/* @end */ }: Props) {
  /* @tutinfo If `selectedImage` has a value, show the image from the device. Otherwise, show the placeholder image. */
  const imageSource = selectedImage ? { uri: selectedImage } : imgSource;
  /* @end */

  /* @tutinfo `imgSource` replaced by `imageSource`. */
  return <Image source={imageSource} style={styles.image} />;
  /* @end */
}

const styles = StyleSheet.create({
  image: {
    width: 320,
    height: 440,
    borderRadius: 18,
  },
});
```

No trecho acima, o componente `Image` usa um operador condicional para carregar a origem da imagem. A imagem escolhida é uma [string `uri`](https://reactnative.dev/docs/images#network-images), e não um recurso local, como a imagem provisória.
